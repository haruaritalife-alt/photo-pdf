使えない文字

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • 名前を入れる
  • 文字を確かめる
  • 置き換える

Excelのシート名には、使えない文字があります。Excelのシート名を確かめる は、次の7文字が含まれていないかを調べます。

使えない7文字

  • \（バックスラッシュ）
  • /（スラッシュ）
  • ?（疑問符）
  • *（アスタリスク）
  • [（左の角かっこ）
  • ]（右の角かっこ）
  • :（コロン）

手順

  1. 「シート名」に、付けたい名前を入れる。
  2. 「使えない文字（\ / ? * [ ] :）があります」と出たら、該当の文字を確かめる。
  3. 「直したシート名」では、それらが「_」に置き換わる。
全角の「／」「？」「＊」「：」などは、使えます。半角の7文字だけが対象です。

例

  • 「売上/利益」→「売上_利益」
  • 「Q&A[新]」→「Q&A_新_」
  • 「会議：10月」（全角のコロン）→ そのまま使える

よく入ってしまう場面

  • 日付（2026/10/25）を、シート名に使おうとした
  • ファイル名を、そのままシート名にしようとした
  • 数式やURLを、シート名にしようとした

日付を使いたいとき

日付は、スラッシュをハイフンやピリオドに変えます。

  • 2026/10/25 → 2026-10-25 や 2026.10.25

向いている場面

  • 日付入りのシート名を、作りたい
  • 取引先名や商品名から、シート名を作りたい
  • データの文字を、シート名に使いたい

記号の代わりに

  • 「/」の代わりに「-」や「_」
  • 「:」の代わりに「-」
  • 「?」や「*」は、取り除く

例

「10/25売上」にしたかったが、エラーになった。スラッシュが使えないため。「10-25売上」に直して、付けられた。

つまずきやすい点

  • 全角と半角：使えないのは半角。全角は使えるが、見分けにくい。
  • ほかの記号：「&」「%」「#」などは、使える。

よくある質問

絵文字は使えますか？

多くの絵文字は使えますが、環境によって表示が異なります。共有する場合は、避けたほうが安全です。

Characters That Are Not Allowed

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Enter the name
  • Check the characters
  • Replace them

Some characters can't be used in Excel sheet names. Check an Excel Sheet Name checks for these seven characters.

The seven disallowed characters

  • \ (backslash)
  • / (slash)
  • ? (question mark)
  • * (asterisk)
  • [ (left square bracket)
  • ] (right square bracket)
  • : (colon)

Steps

  1. Enter the name you want in "Sheet name".
  2. If "Contains characters that are not allowed (\ / ? * [ ] :)" appears, check the characters.
  3. In "Fixed sheet name" they are replaced with "_".
Full-width "／", "？", "＊", "：" etc. are allowed. Only the half-width seven are targeted.

Examples

  • "Sales/Profit" → "Sales_Profit"
  • "Q&A[new]" → "Q&A_new_"
  • "Meeting：Oct" (full-width colon) → usable as is

Where they often sneak in

  • Trying to use a date (2026/10/25) as a sheet name
  • Using a file name as is
  • Using a formula or URL as a name

When you want a date

Change slashes to hyphens or periods.

  • 2026/10/25 → 2026-10-25 or 2026.10.25

Good for

  • Making sheet names containing dates
  • Making sheet names from client or product names
  • Using data text as sheet names

Substitutes for symbols

  • Use "-" or "_" for "/"
  • Use "-" for ":"
  • Remove "?" and "*"

Example

Wanted "10/25 Sales" but got an error because the slash is disallowed. Changing to "10-25 Sales" worked.

Common stumbling blocks

  • Full-width vs half-width: the disallowed ones are half-width. Full-width works but is hard to tell apart.
  • Other symbols: "&", "%" and "#" are fine.

Frequently asked questions

Can emoji be used?

Many emoji work, but display varies by environment. Safer to avoid when sharing.

Summary

The seven half-width characters are disallowed. Change dates to hyphens.
