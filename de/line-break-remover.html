Zeilenumbrüche in Text entfernen und bereinigen

Aus einem PDF kopierten Text bereinigen.

Anleitung

  1. Fügen Sie den Text unter „Vorher“ ein.
  2. Wählen Sie „Art der Bereinigung“.
  3. Kopieren Sie das unter „Nachher“ angezeigte Ergebnis mit „Ergebnis kopieren“.

So funktioniert es

  • Zeilenumbrüche werden entfernt und Zeilen zusammengefügt.
  • Bei „Absätze beibehalten“ bleiben durch Leerzeilen getrennte Absätze unverändert.

Hinweise

  • Aus PDFs kopierter Text bricht oft mitten im Satz um; die Bereinigung macht ihn lesbarer.
  • Das Entfernen von Zeilenumbrüchen ändert die Zeichenzahl.

FAQ

Wird mein Text irgendwohin gesendet?

Nein. Alles wird im Browser auf Ihrem Gerät verarbeitet.

Kann ich aus einem PDF kopierten Text bereinigen?

Ja. Wählen Sie „Absätze beibehalten“, um nur die Umbrüche mitten im Satz zu entfernen.
