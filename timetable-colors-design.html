見やすい時間割にするコツ：色分け・文字の長さ・余白

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • 色は、授業ごとに自動で分かれる
  • 授業名は短く、教室は2行目に
  • 空きコマは、白いままで目立たせる

同じ時間割でも、見やすさで、使い勝手が大きく変わります。

色分け

時間割・週間スケジュール表を作成では、1行目の文字が同じコマは、同じ色になります。

  • 同じ授業が週に2回あるときは、1行目の文字を、そろえてください。
  • 色の数は、8色のくり返しです。授業が9つ以上あると、色が重なります。
  • 色が気にならないときは、「同じ文字のコマを、同じ色にする」をオフにします。

文字の書き方

  1. 1行目に、授業名を書きます。長いときは、略さず書いて大丈夫です。枠に合わせて、文字の大きさが自動で変わります。
  2. 2行目に、教室や先生の名前を書きます。
  3. 長すぎて入らないときは、エラーが出ます。短くするか、行や列を減らしてください。

空きコマ

何も入れないコマは、白いままです。白いコマが、空きコマだとすぐにわかります。

日・土曜は、使うときだけ

曜日を増やすと、1コマの幅がせまくなって、文字が小さくなります。授業がある曜日だけ、選びましょう。

時限が多いとき

10限まで作れますが、行が増えると、1コマの高さが小さくなります。そのぶん、文字も小さくなるので、必要な数だけにしてください。

時間割・週間スケジュール表を作成を使う（無料）

あわせて使えるツール

  • 写真をPDFに変換：複数の写真を、順番どおりに1つのPDFへ。回転、並べ替え、サイズ指定ができます。
  • 画像の形式を変換（JPG・PNG・WebP）：画像をJPG・PNG・WebPに、まとめて変換します。
  • PDFを圧縮：PDFを、指定したサイズ以下に小さくします。提出先の容量制限に合わせたいときに。

Making a Readable Timetable: Colors, Text Length and Space

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Colors are assigned automatically per class
  • Keep class names short and put the room on line two
  • Leave free periods white so they stand out

Even for the same timetable, readability changes how useful it is.

Color coding

In Create a Timetable / Weekly Schedule, cells whose first line of text is the same get the same color.

  • If a class meets twice a week, match the first line exactly.
  • There are eight colors, repeated. With nine or more classes, colors overlap.
  • If you do not want colors, turn off "Give cells with the same text the same color".

Writing the text

  1. Put the class name on line one. Long names are fine; the text size adjusts to the cell.
  2. Put the room or teacher on line two.
  3. If it is too long to fit, an error appears. Shorten it, or use fewer rows or columns.

Free periods

Empty cells stay white, so free periods stand out at a glance.

Add Saturday and Sunday only if needed

More days make each cell narrower and the text smaller. Choose only the days you have classes.

With many periods

You can make up to 10 periods, but more rows make each cell shorter and the text smaller. Use only as many as you need.
