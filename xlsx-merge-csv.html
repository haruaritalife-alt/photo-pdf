    使い方

    1. 「Excelファイルを選ぶ」で、まとめたい.xlsxを、すべて選びます。
    2. 対象のシートと、見出しの扱いを決めます。
    3. 「まとめてCSVで保存」を押し、保存します。

    仕組み

    • 複数のExcelのデータを、上から順に、1つのCSVにまとめます。
    • 月ごとなど、同じ形のExcelをまとめるのに向いています。
    • 「元のファイル」「シート名」の列を足すと、どこのデータか分かります。

    注意

    • 保存されているセルの値だけを使います。書式や計算式は含まれません。
    • 列の並びが違うExcelは、先に並びをそろえてください。
    • 古い .xls 形式や、パスワード付きのファイルは開けません。

    よくある質問

    ファイルは外部に送信されますか？

    いいえ。処理はすべて、お使いの端末のブラウザの中で行われます。

    結果は、Excelで開けますか？

    開けます。「CSVを開く」でExcelに取り込めます。文字化けしないよう、UTF-8（BOM付き）で保存します。

    How to use

    1. Tap "Choose Excel files" and select all the .xlsx files to combine.
    2. Choose which sheets to use and how to treat the header.
    3. Tap "Merge and save as CSV" and save.

    How it works

    • Data from several Excel files is stacked into one CSV, top to bottom.
    • This suits files with the same layout, such as monthly reports.
    • Adding "source file" and "sheet" columns shows where each row came from.

    Notes

    • Only the stored cell values are used. Formatting and formulas are not included.
    • Excel files with different column layouts should be matched first.
    • Old .xls and password-protected files cannot be opened.

    FAQ

    Are my files uploaded anywhere?

    No. Everything is processed inside the browser on your device.

    Can I open the result in Excel?

    Yes. It is saved as UTF-8 with a BOM so that Excel does not garble it.
