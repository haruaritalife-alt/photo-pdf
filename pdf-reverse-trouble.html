PDFのページを逆順にできないときの対処

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • パスワードを確認
  • 別のブラウザで試す
  • ファイルを確認

PDFのページを逆順にしようとして、うまくいかない。思った順番にならない、動かない、エラーが出る。PDFのページを逆順にする で起こりやすい困りごとと、対処法をまとめました。

1. 逆順にしても、順番が合わない

原因：元の乱れ方が、単純な逆順ではない。

対処：

  • 「2ページずつ入れ替える」を試す。
  • 両面スキャンの乱れなら、別の解説も参考にする。
  • 一部のページだけなら、並べ替えツールで動かす。

2. 2ページずつ入れ替えると、最後のページがずれる

原因：奇数ページのPDFでは、最後の1ページが、入れ替わらず残る。

対処：最後のページを、前のページと入れ替えたい場合は、並べ替えツールを使う。

3. 逆順にしたら、ページ番号が逆になった

原因：PDFに印刷されたページ番号は、内容の一部なので、順番を変えても、番号は変わらない。

対処：逆順にして、正しい順番になっていれば、番号も順番どおりに並びます。順番が合わないときは、元の乱れ方を見直す。

4. 向きがおかしい

原因：ページの向きは、順番を変えても、変わらない。

対処：回転ツールで、向きを直す。

5. パスワード付きのPDFで、開けない

先にパスワードを解除してから、使います。

6. ファイルが大きくて、動作が遅い

  • ページ数が多いと、時間がかかります。
  • スマホの場合は、パソコンのほうが快適な場合があります。

7. 保存したPDFが、元の順番のまま

  • 新しく保存したPDFではなく、元のPDFを開いていないか確認する。
  • 並べ替えのボタンを押したか確認する。
  • 保存したPDFを、開き直す。

8. PDFが壊れている

開けない、または一部のページが表示されない場合は、PDF自体が壊れている可能性があります。別の方法で保存し直したPDFで試します。

手順（確認の順番）

  1. PDFを選び直す。
  2. 「並べ方」を選ぶ。
  3. 「並べ替えてPDFを作る」を押す。
  4. 「プレビュー」で確認する。
  5. 保存して、開き直す。
元のPDFは、別の名前で残しておきます。

つまずきやすい点

  • プレビューが見づらい：拡大して、ページの内容を確認します。
  • 2回押してしまった：二重に並べ替わることはありません。結果を確認します。
  • 元に戻したい：元のPDFから、やり直します。

よくある質問

並べ替えのやり直しは、できますか？

元のPDFが残っているので、何度でもできます。

スマホでもできますか？

できます。

まとめ

逆順と、2ページずつの入れ替えを試し、向きとパスワードを確認。順番に確認すれば、ほとんど解決します。

What to Do If You Can't Reverse a PDF

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Check for a password
  • Try another browser
  • Check the file

You tried to reverse PDF pages and it did not work: the order is not what you expected, it will not run, or an error appears. Here are the problems that commonly occur with Reverse the Page Order of a PDF and how to deal with them.

1. The order does not match even after reversing

Cause: the original disorder is not a simple reversal.

Fix:

  • Try "Swap two pages at a time".
  • For double-sided scan disorder, see the other guide too.
  • For only some pages, move them with the reorder tool.

2. After swapping two at a time, the last page is off

Cause: in an odd-page PDF, the last page is left as it is.

Fix: if you want to swap the last page with the one before it, use the reorder tool.

3. After reversing, the page numbers are reversed

Cause: page numbers printed in the PDF are part of the content, so they do not change when the order changes.

Fix: if reversing gives the correct order, the numbers also run in order. If the order is wrong, reconsider how the original was disordered.

4. The orientation is wrong

Cause: page orientation does not change when you change the order.

Fix: fix the orientation with the rotate tool.

5. A password-protected PDF cannot be opened

Remove the password first, then use it.

6. The file is large and operation is slow

  • With many pages, it takes time.
  • On a phone, a computer may be more comfortable.

7. The saved PDF is still in the original order

  • Check that you did not open the original PDF instead of the newly saved one.
  • Check that you pressed the reorder button.
  • Reopen the saved PDF.

8. The PDF is corrupt

If it will not open, or some pages do not display, the PDF itself may be corrupt. Try a PDF re-saved by another method.

Steps (the order to check)

  1. Choose the PDF again.
  2. Choose the "Arrangement".
  3. Press "Reorder and create PDF".
  4. Check in the "Preview".
  5. Save and reopen.
Keep the original PDF under a different name.

Common stumbling blocks

  • The preview is hard to see: zoom in and check the page contents.
  • You pressed twice: it will not be reordered twice. Check the result.
  • You want to go back: start again from the original PDF.

Frequently asked questions

Can I redo the reordering?

The original PDF remains, so you can any number of times.

Can I do it on a phone?

Yes.

Summary

Try reverse and swap-pairs, and check the orientation and password. Checking in order solves most problems.
