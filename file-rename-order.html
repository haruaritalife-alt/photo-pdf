並び順を指定して連番をつける

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • 並べる順番を選ぶ
  • 変更後の名前を確認する
  • 保存する

連番をつけるとき、「どの順番に番号をつけるか」で、できあがりが変わります。ファイル名を一括で変更する（連番・日付） では、「並べる順番」を選べます。

選べる順番

  • 選んだ順：ファイルを選んだ順に、番号をつける。
  • 元の名前順：元のファイル名の順（あいうえお順・数字順）に、番号をつける。
  • 更新日の古い順：ファイルの更新日が古いものから、番号をつける。

手順

  1. 「ファイルを選びます」で、ファイルを選ぶ。
  2. 「並べる順番」を選ぶ。
  3. 「変更後の名前（先頭）」で、1番目のファイルを確かめる。
  4. 「名前を変えてZIPで保存」を押す。
「連番の開始」を変えると、1以外の数字から始められます。

使い分けの例

  • 自分で順番を決めたい：「選んだ順」で、順に選ぶ。
  • IMG_0001〜の順に直したい：「元の名前順」。
  • 撮影した順にしたい：「更新日の古い順」。

「選んだ順」のコツ

  • 最初に番号1にしたいファイルから、順に選ぶ
  • まとめて選ぶと、OSによっては順番が変わることがある
  • 「何度でも追加できます」。追加した順に、並ぶ

「元の名前順」の注意

数字を含む名前は、並びに注意が必要です。「1, 2, 10」は「1, 10, 2」の順になることがあります。数字をそろえたいときは、先に0を付けた名前にしておくと、安全です。

連番の開始

  • 1から始める：普通の連番
  • 0から始める：プログラム用など
  • 続きから始める：既存の番号の続き（例：101から）

向いている場面

  • 資料の順番を、ファイル名で表したい
  • 提出するファイルに、順番どおりの番号をつけたい

例

10枚の資料ファイルを、読む順番に「01」〜「10」にしたかった。「選んだ順」で、読む順に選び、桁数を2にして保存した。

つまずきやすい点

  • 順番がばらばら：選び方を確かめる。または、並べる順番を変える。
  • 10が2より前に来る：桁数をそろえる。

よくある質問

あとから順番を入れ替えられますか？

やり直して、選び直します。

まとめ

用途に合わせて、並べる順番を選ぶ。選んだ順なら、自分で決められます。

ファイル名を一括で変更する（連番・日付）を使う（無料）

あわせて使えるツール

  • ファイルをZIPにまとめる：複数のファイルを、1つのZIPにまとめます。
  • ZIPを開く（解凍）：ZIPの中身を見て、ほしいファイルだけ取り出します。
  • 画像のサイズ（ピクセル）を変える：画像の大きさを、横幅・縦・割合で変えます。

同じツールの、ほかの解説

  • ファイル名を一括で変更する方法（連番つき・スマホでもOK）
  • 写真のファイル名を日付や連番にそろえる
  • 連番を001・002にそろえる（ゼロ埋め）
  • 元の名前を残して、前後に文字を足す
  • ZIPの中の名前が変わらない・うまくいかないとき

Numbering Files in a Chosen Order

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Choose the order
  • Check the new names
  • Save

When numbering, the result changes depending on "in what order to number". In Rename Many Files at Once (Numbers, Dates) you can choose "Order".

Selectable orders

  • Order chosen: number in the order the files were chosen.
  • Original name order: number in the order of original file names (alphabetical/numerical).
  • Oldest modified first: number from files with the oldest modified date.

Steps

  1. Choose files with "Choose files".
  2. Choose the "Order".
  3. Check the first file under "Name after change (first)".
  4. Press "Rename and save as ZIP".
Changing "Sequence start" lets you start from a number other than 1.

Examples of choosing

  • Want to decide the order yourself: "Order chosen", choosing in order.
  • Want to straighten IMG_0001... order: "Original name order".
  • Want shooting order: "Oldest modified first".

Tips for "Order chosen"

  • Choose in order, starting from the file you want as number 1
  • When choosing together, the order may change depending on the OS
  • "You can add any number of times". They line up in the order added

Note on "Original name order"

Names containing numbers need care in ordering. "1, 2, 10" may come out as "1, 10, 2". To align numbers, give names zero-padded forms beforehand to be safe.

Sequence start

  • Starting from 1: ordinary numbering
  • Starting from 0: for programs etc.
  • Starting from a continuation: continuing existing numbers (e.g. from 101)

Good for

  • Expressing document order in file names
  • Giving files for submission numbers in order

Example

Wanted 10 document files numbered "01"–"10" in reading order. Chose them in reading order with "Order chosen", set digits to 2 and saved.

Common stumbling blocks

  • The order is jumbled: check how you chose. Or change the order setting.
  • 10 comes before 2: align the digits.
