Sıkıştırırken Kalite Seçimi: Küçük, Normal veya Yüksek

Yayınlanma: 19 Eki 2026 | Güncellenme: 19 Eki 2026 | Hakkında (Japonca)

Önemli noktalar
  • Metin ağırlıklı belgeler genelde “Normal” ile iyidir
  • Fotoğraf ağırlıklı belgelerde boyutla dengeleyin
  • Emin değilseniz “Normal” ile başlayın

Compress PDF has quality options "Small file", "Normal" and "High", plus "Set a size limit". Here is a guide for choosing.

What each quality does

  • Small file: makes the file as small as possible. Documents with clear text remain readable, but fine text and photo details get rough.
  • Normal: a balanced setting suited to most documents. If unsure, start here.
  • High: keeps image quality. Good when small text, drawings or photos matter, but the file does not shrink much.
  • Set a size limit: adjusts to fit within a recipient's limit.

Nasıl seçilir

  • Contracts and applications, mostly text: Normal
  • Material with many photos: Normal or High
  • Old scanned material: try Small file first
  • A fixed limit: Set a size limit

Adımlar

  1. First compress with "Normal".
  2. Save and check that even small text is readable.
  3. If it is hard to read, try "High"; if it is still large, try "Small file" or "Set a size limit".
You can redo it any number of times. The original PDF is not changed.

Tips for "Set a size limit"

When you choose a size limit, quality is adjusted to fit under it. If the limit is too strict, quality can drop so far that text becomes unreadable. Always check readability after saving.

What to check visually

  • Can small text, such as notes and footnotes, be read?
  • Are the lines in figures and photos crushed?
  • Are the colour changes extreme?

Common stumbling blocks

  • Text got crushed with "Small file": go back to "Normal".
  • Still large even with "High": remove unneeded pages first.
  • The original is smaller: skip compression and use the original.

Frequently asked questions

Does compressing repeatedly lower the quality?

Compressing an already compressed PDF can lower quality. Redo it from the original PDF.

Is it still in colour?

Yes.

Özet

When unsure, use "Normal"; if that is not enough, "Set a size limit". Do not forget to check readability after saving.
