Özgün adı koruyup metin ekleme

Yayınlanma: 19 Eki 2026 | Güncellenme: 19 Eki 2026 | Hakkında (Japonca)

Önemli noktalar
  • Kurala {name} ekleyin
  • Öncesine veya sonrasına metin ekleyin
  • Kaydedin

Instead of renaming files entirely, you want to keep the original name and add text before or after. Using {name} in Rename Many Files at Once (Numbers, Dates) lets you add dates or words while keeping the original name.

Adımlar

  1. Choose files with "Choose files".
  2. In "New name rule", enter a form using {name}.
  3. Check the result under "Name after change (first)".
  4. Press "Rename and save as ZIP".
{name} is the original file name. The extension (.jpg etc.) is added automatically.

Rule examples

  • Add before: {date}_{name} → 20261023_originalname
  • Add after: {name}_final → originalname_final
  • Add both: submit_{name}_v2 → submit_originalname_v2
  • Combine with a sequence: {name}_{n} → originalname_1

Where to use it

  • Adding a date to the original name to manage versions
  • Adding markers such as "for submission" or "checked" before or after
  • Keeping the original information contained in file names

Benefits of keeping the original name

  • Contents can be guessed from the name
  • Correspondence with the original file is clear
  • Searchable by the original name too

Cautions

  • If you forget {name}, the original name is lost
  • Multiple files with the same name cause confusion. Add a sequence number to tell them apart
  • Names that are too long may not be handled by some systems

Tip for adding dates

{date} is today's date. The year, month and day are entered together, like "20261023". Handy for version management.

Şunlar için iyidir

  • Version management of documents (with dates)
  • Unifying file names before delivery
  • Marking received files

Örnek

Wanted to prefix "received_20261023_" to 20 documents from a client. Set the rule to "received_{date}_{name}" and saved with the original names kept.

Common stumbling blocks

  • The original name vanished: {name} wasn't included.
  • Names become identical: add the sequence {n}.

Frequently asked questions

Can I replace only part of the original name?

Not with this tool. It adds before and after.

Özet
