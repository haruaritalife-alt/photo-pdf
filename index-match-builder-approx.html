近い値を探す

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • LESSかGREATERを選ぶ
  • 範囲を入れる
  • 確かめる

ちょうど一致でなく、近い値を探したい。点数から評価、金額から段階を決める、といった場面です。INDEX・MATCHの式を作る の「LESS」と「GREATER」で作れます。

手順

  1. 「一致の種類」で「LESS」か「GREATER」を選ぶ。
  2. 「取り出す範囲」「探す列の範囲」「探す値のセル」を入れる。
  3. 式をコピーして貼る。
探す列は、LESSなら小さい順（昇順）、GREATERなら大きい順（降順）に並べておく必要があります。

例

LESS（以下で最大の値）の式です。

  • =INDEX($C$2:$C$100,MATCH(F2,$B$2:$B$100,1))

GREATER（以上で最小の値）の式です。

  • =INDEX($C$2:$C$100,MATCH(F2,$B$2:$B$100,-1))

一致の種類

  • EXACT：ちょうど一致（0）
  • LESS：以下で最大（1）。昇順に並べる
  • GREATER：以上で最小（-1）。降順に並べる

表の作り方（LESS）

B列に段階の下限を昇順に入れます。

  • 0 → 可
  • 60 → 良
  • 80 → 優

75点なら、60の行の「良」が返ります。

向いている場面

  • 点数から評価を決める
  • 売上から手数料率の段階を決める
  • 年齢から区分を決める

並び順を守る

並び順が違うと、結果が正しくなりません。エラーにならず、間違った値が返ることもあります。並び順を、必ず確かめます。

例

売上額から、手数料率の段階を引きたかった。下限を昇順に並べた表を作り、LESSの式で引くと、IFを重ねずに済んだ。

つまずきやすい点

  • 下限より小さい値：#N/Aになる。0の行を入れる。
  • 並び順が逆：結果が合わない。

よくある質問

XLOOKUPでもできますか？

できます。XLOOKUPなら、並び順を気にしなくて済みます。

まとめ

段階で決まる値は、LESSで引く。並び順に注意。

Finding the Nearest Value

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Choose LESS or GREATER
  • Enter the ranges
  • Check it

You want the nearest value rather than an exact match, such as a grade from a score or a tier from an amount. "LESS" and "GREATER" in Build an INDEX and MATCH Formula build it.

Steps

  1. Choose "LESS" or "GREATER" in "Match type".
  2. Enter the "Range to return", "Lookup column range" and "Cell with the value to find".
  3. Copy the formula and paste.
The lookup column must be sorted ascending for LESS and descending for GREATER.

Example

A LESS (largest value at or below) formula:

  • =INDEX($C$2:$C$100,MATCH(F2,$B$2:$B$100,1))

A GREATER (smallest value at or above) formula:

  • =INDEX($C$2:$C$100,MATCH(F2,$B$2:$B$100,-1))

Match types

  • EXACT: exact match (0)
  • LESS: largest at or below (1). Sort ascending
  • GREATER: smallest at or above (-1). Sort descending

Building the table (LESS)

Put each tier's lower bound in column B ascending.

  • 0 → C
  • 60 → B
  • 80 → A

A score of 75 returns the 60 row's "B".

Good for

  • Deciding grades from scores
  • Deciding fee-rate tiers from sales
  • Deciding brackets from age

Respect the sort order

With the wrong order the result is wrong. It may not error and can return a wrong value. Always check the order.

Example

Wanted a commission tier from the sales amount. A table of ascending lower bounds and a LESS formula avoided stacked IFs.

Common stumbling blocks

  • Value below the lowest bound: gives #N/A. Include a 0 row.
  • Order reversed: results don't match.

Frequently asked questions

Can XLOOKUP do this?

Yes. XLOOKUP spares you caring about the order.

Summary

Tier-based values are pulled with LESS. Mind the sort order.
