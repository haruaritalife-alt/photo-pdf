古い .xls ファイルを変換するには

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • 開く
  • 保存し直す

古い形式の.xlsファイルを変換しようとしたけれど、ExcelをCSV・JSONに変換する では開けない。そんなときの対処です。このツールが読み取れるのは、.xlsx（新しい形式）のExcelファイルです。

なぜ開けないのか

Excelのファイルには、2つの形式があります。

  • .xls：Excel 2003までの、古い形式。
  • .xlsx：Excel 2007以降の、新しい形式。

このツールは、.xlsxに対応しています。.xlsは、読み取れません。

手順（.xlsx に保存し直す）

  1. Excelで、.xlsファイルを開きます。
  2. 「ファイル」から「名前を付けて保存」を選びます。
  3. ファイルの種類で、「Excel ブック（.xlsx）」を選んで、保存します。
  4. 保存した.xlsxを、このツールの「.xlsx のExcelファイルを1つ選びます」で選びます。
  5. 「シート」と「形式」を選んで、変換します。
Excelがない場合は、Googleスプレッドシートや、LibreOfficeなどの、無料のソフトでも、.xlsxで保存し直せます。

Excelがない場合

  • Googleスプレッドシート：.xlsファイルをアップロードして開き、「ダウンロード」から.xlsxを選ぶ。
  • LibreOffice Calc：.xlsを開き、.xlsxで保存する。
  • スマホのExcelアプリ：開いて、.xlsxで保存できる場合がある。

保存し直すときの注意

  • 古い形式で使われていた、一部の機能は、新しい形式で変わる場合がある。
  • マクロ（VBA）は、.xlsxでは保存されない。マクロが必要なら、.xlsmを使う。
  • 元の.xlsファイルは、念のため残しておく。

拡張子の見分け方

ファイルの名前の最後（.xls か .xlsx か）で、見分けます。拡張子が表示されない場合は、ファイルの情報で確認します。

向いている対処

たくさんの古い.xlsファイルがある場合は、1つずつ保存し直すのが大変です。必要なファイルから、順に進めましょう。

例

10年前に作った名簿の.xlsファイルを、CSVにしたかった。ツールで開けなかったため、Excelで.xlsxに保存し直し、変換できた。

つまずきやすい点

  • 拡張子だけを書き換えた：中身は変わらず、開けない。必ず、保存し直す。
  • パスワード付きの.xls：先に、パスワードを外す。

よくある質問

.xlsのまま変換する方法はありますか？

このツールでは、できません。.xlsxに保存し直してください。

まとめ

.xlsは、Excelなどで.xlsxに保存し直す。拡張子の書き換えだけでは、直りません。

Converting an Old .xls File

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Open
  • Re-save

You tried to convert a file in the old .xls format but it can't be opened with Convert Excel to CSV or JSON. Here is what to do. This tool can read Excel files in .xlsx (the newer format).

Why it can't be opened

Excel files have two formats.

  • .xls: the old format up to Excel 2003.
  • .xlsx: the newer format from Excel 2007 onwards.

This tool supports .xlsx. It can't read .xls.

Steps (re-save as .xlsx)

  1. Open the .xls file in Excel.
  2. From "File", choose "Save As".
  3. For the file type choose "Excel Workbook (.xlsx)" and save.
  4. Choose the saved .xlsx in this tool's "Choose one .xlsx Excel file".
  5. Choose the "Sheet" and "Format" and convert.
If you don't have Excel, free software such as Google Sheets or LibreOffice can also re-save as .xlsx.

If you don't have Excel

  • Google Sheets: upload and open the .xls file, then choose .xlsx from "Download".
  • LibreOffice Calc: open the .xls and save as .xlsx.
  • Excel app on a phone: you may be able to open it and save as .xlsx.

Cautions when re-saving

  • Some features used in the old format may change in the new format.
  • Macros (VBA) are not saved in .xlsx. If you need macros, use .xlsm.
  • Keep the original .xls file just in case.

How to tell the extension

Tell by the end of the file name (.xls or .xlsx). If extensions aren't shown, check in the file's information.

A useful approach

If you have many old .xls files, re-saving one by one is tiring. Proceed in order from the files you need.

Example

Wanted to turn a roster .xls file made ten years ago into CSV. It couldn't be opened in the tool, so re-saved it as .xlsx in Excel and could convert.

Common stumbling blocks

  • Only rewrote the extension: the content doesn't change and it won't open. Always re-save.
  • A password-protected .xls: remove the password first.

Frequently asked questions

Is there a way to convert it as .xls?

Not with this tool. Re-save as .xlsx.

Summary

Re-save .xls as .xlsx in Excel or similar. Rewriting the extension alone won't fix it.
