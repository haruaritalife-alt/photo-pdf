Adakah sama dalam Google Sheets

Diterbitkan: 19 Okt 2026 | Dikemas kini: 19 Okt 2026 | Perihal (Jepun)

Perkara penting
  • Masukkan nombor
  • Lihat huruf
  • Bandingkan

In Google Sheets too, columns run "A, B, C… AA, AB…", the same lettering as Excel. Results converted with Excel Column Number and Letter Converter can be used as is in Google Sheets.

What's the same

  • How column letters are assigned: A–Z, AA–ZZ, AAA… continuing
  • Correspondence with numbers: A = 1, Z = 26, AA = 27
  • How cell references are written: C5 (row 5 of column C)
  • How COLUMN, ADDRESS and INDEX functions are used

What differs

  • Column limits: Excel goes to 16384 columns (XFD). Google Sheets starts with 26 columns (to Z) by default, and the limit to which you can add is set by things like the total cell count of a spreadsheet (10 million cells).
  • This tool's range: A–XFD (1–16384). It may not match Google Sheets' limit.
  • Macros: Excel uses VBA; Google Sheets uses Google Apps Script. How columns are specified differs.

Specifying columns in Apps Script

Google Apps Script specifies row and column as numbers, like getRange(row, column). The order is the same as Excel VBA's Cells(row, column).

  • getRange(5, 3): row 5, column 3 (C5)

Langkah

  1. Enter "Column number" or "Column letters" and convert.
  2. Use it in Google Sheets functions or Apps Script code.
For the number of columns at the sheet's edge, check Google Sheets' own settings.

Sesuai untuk

  • Specifying columns in Google Sheets' Apps Script
  • Matching "Col3" and "C" in the QUERY function
  • Work going back and forth between Excel and Google Sheets

Column specification in QUERY

The QUERY function has a form specifying columns by number as "Col1, Col2, Col3" and one by letters "A, B, C". This tool helps check the correspondence between numbers and letters.

Contoh

Wanted to specify column AB in a QUERY function. The tool showed AB = 28, so writing Col28 worked without problems.

Common stumbling blocks

  • Assuming Excel's limit: in Google Sheets, you may need to add columns.
  • Imported columns: reading with IMPORTRANGE and the like can change column positions.

Frequently asked questions

Can Google Sheets use columns up to XFD too?

The column limit differs from Excel's. Usable columns follow Google Sheets' specifications.

Ringkasan

The correspondence between column letters and numbers is the same in Excel and Google Sheets. Just watch the difference in limits.
