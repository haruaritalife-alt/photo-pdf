Hapus Data Lokasi dan Pengambilan dari Foto

Hapus data lokasi sebelum memposting secara online.

Gambar Anda tidak pernah diunggah. Semua diproses di perangkat ini.

  1. 1Pilih gambar
  2. 2Periksa data tersembunyi
  3. 3Simpan tanpa data tersebut

Format

Gambar digambar ulang lalu disimpan, sehingga lokasi (GPS), tanggal, dan model kamera semuanya terhapus.

Selesai

🔒 Berkas Anda tidak pernah dikirim ke server eksternal. Semuanya diproses dengan aman di dalam browser ini.

Jika PDF Mikata bermanfaat, tip kecil akan sangat berarti bagi kami.

Cara pakai

  1. Ketuk "Pilih gambar" lalu pilih gambar (boleh beberapa).
  2. Kamera, tanggal pengambilan, dan ada tidaknya lokasi GPS akan ditampilkan.
  3. Pilih format (JPG atau PNG).
  4. Ketuk "Hapus data dan simpan" lalu simpan.

Cara kerjanya

  • Gambar digambar ulang lalu disimpan, sehingga lokasi, tanggal, dan model kamera semuanya terhapus.
  • Tampilannya hampir persis sama.

Catatan

  • Gambar dikompresi ulang saat disimpan, sehingga kualitas mungkin berubah sangat sedikit.
  • Berkas HEIC harus diubah ke JPG terlebih dahulu dengan alat Ubah HEIC ke JPG.

Tanya Jawab

Mengapa foto memuat data lokasi?

Kamera ponsel dapat merekam tempat foto diambil. Memposting apa adanya dapat mengungkap tempat seperti rumah Anda.

Apakah gambar saya diunggah ke suatu tempat?

Tidak. Semuanya diproses di dalam browser pada perangkat Anda.

Apakah data terhapus saat saya mengunggah ke media sosial?

Beberapa layanan menghapusnya, tetapi tidak selalu. Menghapusnya terlebih dahulu lebih aman.
