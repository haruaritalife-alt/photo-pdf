Mengembalikan karakter yang di-escape

Diterbitkan: 19 Okt 2026 | Diperbarui: 19 Okt 2026 | Tentang (bahasa Jepang)

Poin penting
  • Masukkan teks yang sudah di-escape
  • Tekan Batalkan escape
  • Lihat hasilnya

In source code and data, have you seen incomprehensible characters like "<" and "&"? These are escaped characters. "Unescape" in HTML Escape and Unescape restores them to a readable form.

Langkah-langkah

  1. Paste the escaped text in the "String or HTML" field.
  2. Press "Unescape".
  3. The original text appears in "Result".
  4. Copy with "Copy result".
Example: <p>Hello</p> →

Hello

Characters it restores

  • & → &
  • < → <
  • > → >
  • " → "
  • ' and ' → '
  • Numeric character references (such as © or ©): the corresponding character

Numeric references are restored in decimal (©) and hexadecimal (©) alike.

Where it often appears

  • Viewing a web page's source
  • When an API response contains escaped characters
  • Reading the body of RSS or email
  • When data is stored escaped in a database

Cocok untuk

  • Making a hard-to-read string readable
  • Restoring text that was escaped by mistake

Contoh

An RSS title showed as "A & B". Pressing "Unescape" made it "A & B".

When it doesn't restore

  • Escaped twice: a form like "&lt;". One restoration gives "<", so restore once more.
  • Named character references: ones like "©" and " " may not be restored by this tool.

Common stumbling blocks

  • Pasting the result into HTML makes tags work: pasted directly into a page, the restored result acts as HTML. Take care.
  • Missing semicolon: without the trailing ";" as in "<", it doesn't restore.

Frequently asked questions

Is it safe to use after restoring?

The restored result may contain tags or scripts. Avoid pasting it directly into a web page.

Ringkasan

Restore escaped text to a readable form with "Unescape". But take care in handling it afterwards.
