Alat PDF yang tetap di perangkat Anda

PDF Mikata ("Mikata" berarti sekutu) menyediakan alat PDF gratis untuk saat Anda perlu menyiapkan dokumen atau materi.

Berkas Anda hanya diproses di dalam perangkat Anda. Foto dan dokumen Anda tidak pernah dikirim ke server luar.

Bagaimana berkas Anda tetap berada di perangkat Anda

Saat Anda membuka halaman, program alatnya dimuat ke browser Anda. Berkas yang Anda pilih hanya dibaca di memori browser, diubah atau diedit di sana, lalu disimpan ke perangkat Anda. Selama proses ini, isi berkas Anda tidak pernah dikirim ke server di internet. Itulah sebabnya Anda dapat menggunakannya untuk dokumen yang tidak ingin Anda lepaskan, seperti CV dan sertifikat.

Informasi pengelola dan kontak ada di halaman Tentang / Kontak (bahasa Jepang).

Tanya Jawab

Apakah berkas saya benar-benar tidak pernah diunggah?

Ya. Konversi dan penyuntingan hanya berjalan di dalam browser Anda, dan berkas tidak dikirim ke server mana pun. Di komputer, Anda dapat membuka tab "Network" pada developer tools saat menggunakan alat untuk memastikan tidak ada permintaan yang membawa berkas Anda.

Apakah gratis? Apakah saya perlu mendaftar?

Semuanya gratis dan tidak memerlukan pendaftaran atau login. Cukup buka halaman alat lalu gunakan.

Apakah berfungsi di ponsel (iPhone dan Android)?

Ya. Buka di browser ponsel Anda (Safari, Chrome, dan sebagainya), pilih berkas, proses, lalu simpan. Cara kerjanya sama di komputer.

Apakah ada batas ukuran berkas atau jumlah berkas?

Situs ini tidak menetapkan batas, tetapi karena pemrosesan terjadi di perangkat Anda, hasilnya bergantung pada perangkat Anda. Sebagai perkiraan kasar saja, di ponsel, PDF hingga beberapa puluh MB atau halaman serta sekitar 20–30 foto sekaligus cenderung stabil. Di atas itu, prosesnya bisa lambat atau berhenti. Jika demikian, coba lagi dalam beberapa kelompok yang lebih kecil.

Apakah berkas asli saya tetap tidak berubah?

Berkas asli Anda tetap seperti semula. Hasilnya disimpan sebagai berkas baru. Menggunakan kompresi atau batas ukuran dapat menurunkan kualitas atau membuat teks PDF tidak dapat dipilih.

Bisakah saya menggunakan PDF yang dilindungi kata sandi?

Tidak. Hapus kata sandinya terlebih dahulu.

Apakah saya harus memberi tip untuk menggunakan alatnya?

Tidak. Semua alat gratis digunakan tanpa batas. Tip (¥300) sepenuhnya opsional, hanya jika Anda merasa situs ini bermanfaat.
