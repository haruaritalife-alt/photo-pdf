사용 방법

  1. "PDF 선택"을 누르고 PDF를 하나 고르세요.
  2. PDF에 저장된 작성자, 제목, 소프트웨어, 날짜가 표시됩니다.
  3. "모두 제거" 또는 "위 값으로 바꾸기"를 고르세요. 댓글도 지우려면 "제거 (링크 유지)"를 고르세요.
  4. "PDF 만들기"를 누르고 저장하세요.

  • 페이지 안에 이름이나 주소가 적혀 있다면 PDF 일부 가리기 (검열)를 쓰세요.
