구글 파일을 PDF로 저장하는 링크

게시: 2026년 10월 19일 | 업데이트: 2026년 10월 19일 | 소개 (일본어)

핵심 포인트
  • 링크 붙여 넣기
  • PDF 링크 복사
  • 보내기

When handing Google Docs or Sheets over as PDF, going through "File", "Download", "PDF" each time is tedious. If you make a PDF export link, the recipient saves the PDF with one click. Make it with Google Docs, Sheets and Slides Export Link Maker.

순서

  1. Copy the link of the Google file (Docs, Sheets or Slides).
  2. Paste it into the "Docs, Sheets or Slides link" field.
  3. Press "Copy" for the "Link to export as PDF".
  4. Paste it into an email or chat and send it to them.
The person opening the link needs permission to view the file. Without it, the PDF can't be saved.

작동 방식

It changes the end of the ordinary link into the form for PDF export.

  • Docs and Sheets: …/export?format=pdf
  • Slides: …/export/pdf

Benefits of PDF

  • Reads with the same look regardless of the recipient's environment (computer, phone)
  • Hard to edit
  • Easy to print
  • Opens without a Google account (if they have permission to open the link)

Setting permissions

Check the file's sharing before handing out the link.

  • "Anyone with the link": anyone can save the PDF
  • "Restricted": only added people

알맞은 경우

  • Distributing minutes and reports as PDF
  • Sending quotes and invoices as PDF
  • Distributing slides as PDF materials

참고

  • What is exported is the latest content at the moment the link is opened
  • If you update the content, the PDF obtained by later openers is new too
  • To hand out finalised content, save the PDF and send that file

예

Distributed monthly reports (Google Docs) to stakeholders as PDF. With the PDF link pasted in the email, recipients could save with a click.

Common stumbling blocks

  • PDF layout of spreadsheets: print range and paper settings are reflected in the PDF.
  • Multiple sheets: spreadsheet PDFs generally cover the whole file.

Frequently asked questions

Can a password be added to the PDF?

Not with this link. If you need a password, save the PDF and set it with another tool.

요약

A PDF link reduces the recipient's effort. Note that the content is output as of the latest.
