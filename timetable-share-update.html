時間割を友だちと共有する・変更したときの直し方

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • PDFか画像にして、メッセージで送る
  • 変更は、保存した内容を直して作り直す
  • 古い版と新しい版を、見分けられるようにする

時間割は、友だち同士で共有したり、変更があるたびに直したりする機会が多いものです。時間割・週間スケジュール表を作成 で作った時間割を共有する方法と、変更したときの直し方を説明します。

共有する方法

  1. 「表を作る」で完成させます。
  2. 「画像（PNG）で保存」か「PDFを保存する」を選びます。
  3. 保存したファイルを、メッセージアプリやメールに添付して送ります。
画像のほうが、受け取った側がすぐ開けて、スマホで見やすいです。印刷して配るならPDFが向いています。

共有するときの注意

  • 時間割には、名前や教室など、人に知られたくない情報が入っていないか確認します。
  • 公開の場（SNSなど）に載せるときは、「名前（任意）」を空欄にして作ります。
  • 授業名や時間割が、個人の特定につながらないか考えます。

変更したときの直し方

  1. 「入力内容を、この端末に保存する（次回、続きから直せます）」を選んでいれば、ツールを開くと前回の内容が残っています。
  2. 変わった授業や時間だけを直します。
  3. 「表を作る」で作り直し、保存します。
  4. 古いファイルと間違えないよう、ファイル名に日付などを付けて、新しいものを共有します。
保存されるのは、この端末のブラウザの中だけです。共用のパソコンでは、チェックを外してください。

例

後期の途中で教室が変わった場合は、該当のコマの内容だけ直して、作り直し、新しい画像をグループに送ります。

変更の連絡をわかりやすく

  • 変更点を一言添える（例：「水曜2限の教室が変わりました」）
  • 日付を入れる
  • 古いものを削除してもらう

つまずきやすい点

  • 前回の内容が残っていない：別のブラウザや端末では見られません。同じ端末のブラウザで開きます。ブラウザのデータを消した場合も消えます。
  • 古い時間割が出回る：新しいファイルであることをはっきり伝えます。
  • 画像が作れない：もう一度「表を作る」を押します。

よくある質問

他の人が自分で直せるようにしたい

その人が自分の端末でこのツールを開いて入力すれば、自分用が作れます。ファイルを渡して直してもらうことはできません。

入力した内容はサーバーに送られますか？

送られません。処理は端末の中で行われます。

まとめ

画像かPDFで保存して送り、変更があれば、保存した入力から直して作り直す。ファイル名に日付を付けて、新旧を取り違えないようにしましょう。

  • 写真をPDFに変換：複数の写真を、順番どおりに1つのPDFへ。回転、並べ替え、サイズ指定ができます。
  • 画像の形式を変換（JPG・PNG・WebP）：画像をJPG・PNG・WebPに、まとめて変換します。

Sharing a Timetable with Friends and Updating It After Changes

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Send it as a PDF or image in a message
  • Edit the saved entries and recreate it for changes
  • Make old and new versions easy to tell apart

Timetables are often shared among friends and fixed whenever something changes. Here is how to share a timetable made with Create a Timetable / Weekly Schedule, and how to fix it when something changes.

How to share

  1. Finish it with "Make table".
  2. Choose "Save as image (PNG)" or "Save PDF".
  3. Attach the saved file to a messaging app or an email and send it.
An image can be opened right away by the recipient and is easy to see on a phone. A PDF suits printing and handing out.

Notes when sharing

  • Check that the timetable holds no information you do not want others to know, such as names or rooms.
  • When posting it in a public place such as social media, leave "Name (optional)" empty when making it.
  • Think about whether the class names or timetable could identify an individual.

How to fix it when something changes

  1. If you chose "Save the input on this device (so you can continue next time)", the previous content is still there when you open the tool.
  2. Fix only the classes or times that changed.
  3. Make it again with "Make table" and save.
  4. Add a date to the file name so you do not confuse it with the old file, and share the new one.
It is stored only inside this device's browser. On a shared computer, uncheck it.

Example

If a room changes in the middle of the second term, fix only the content of that cell, make it again and send the new image to the group.

Announcing changes clearly

  • Add a word about what changed (for example: "The room for Wednesday 2nd period has changed")
  • Include a date
  • Ask people to delete the old one

Common stumbling blocks

  • The previous content is gone: it cannot be seen in a different browser or device. Open it in the same browser on the same device. Clearing the browser's data also removes it.
  • An old timetable is circulating: make it clear that this is the new file.
  • The image cannot be made: press "Make table" again.

Frequently asked questions

I want others to be able to fix it themselves

If they open this tool on their own device and enter things, they can make their own. You cannot hand over a file for them to edit.

Is what I enter sent to a server?

No. Processing happens on your device.

Summary

Save as an image or PDF and send it. When something changes, fix it from the saved input and make it again. Put a date in the file name so old and new are not confused.
