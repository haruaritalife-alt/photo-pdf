Việc cần làm khi không hoạt động

Text doesn't split as expected. Here are common troubles with Split Text into Columns by a Delimiter and fixes.

Common troubles

  • "Please enter a delimiter." appears: the delimiter field is empty.
  • Stays one column: the delimiter isn't in the data, or is a different character (like a full-width comma).
  • Splits too much: the same character as the delimiter appears in the data, like "1,000" amounts.
  • Empty columns appear: delimiters repeat. Try "Treat consecutive delimiters as one".
  • Columns shift: item counts differ per row.

Steps (when it doesn't go well)

  1. Check the delimiter matches the character in the data.
  2. Compare full-width and half-width.
  3. Toggle "Treat consecutive delimiters as one" and compare.
  4. Check with "Rows × columns" that the size is as expected.
Tabs and spaces look similar but are different characters.

Delimiter candidates

  • Comma (,), full-width comma (，), Japanese comma (、)
  • Semicolon (;)
  • Tab
  • Space, full-width space
  • Vertical bar (|), slash (/)

Input examples

  • Correct: delimiter "," for "A,B,C"
  • Mismatch: delimiter "," for "A、B、C" (Japanese commas)

Uses it suits

  • Checks before splitting
  • Finding the cause of shifts

Ví dụ

Entered a comma but it stayed one column. The data's commas were full-width "，". Changing the delimiter to full-width split it correctly.

Common stumbling blocks

  • Cells containing line breaks: processed line by line, so breaks make separate rows.
  • Leading zeros: set the format to "Text" when pasting into Excel.

Frequently asked questions

Can commas inside quotes be ignored?

No. Quotes aren't considered. Use Excel's CSV import if needed.

Tóm tắt

Delimiter character, full-width vs half-width, consecutive setting. Check these three and it's usually solved.

Dùng “Tách văn bản thành cột theo dấu phân cách” (miễn phí)
