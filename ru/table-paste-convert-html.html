Преобразование таблицы Excel в таблицу HTML

Опубликовано: 19 окт. 2026 | Обновлено: 19 окт. 2026 | О сайте (на японском)

Главное
  • Скопируйте таблицу
  • Вставьте его
  • Выберите HTML

You want to put an Excel table on a web page. To turn it into an HTML table (table tag), set "Target format" to "HTML" in Excel Table to Markdown, HTML, CSV and JSON.

Шаги

  1. Copy the table in Excel and paste.
  2. Choose "HTML" in "Target format".
  3. Copy the HTML in "Result" with "Copy result".
  4. Paste it where you want the table on the web page.
Turning on "Use first row as header" makes the header row th tags.

Output structure

  • table: the whole table
  • tr: a row
  • th: a header cell
  • td: a normal cell

Подходит для

  • Putting a table on a blog or site
  • Putting a table in an HTML email body
  • Skipping hand-written HTML

Styling

The output is plain HTML without decoration. Style it with CSS.

  • Borders: border
  • Spacing: padding
  • Header background: background

Пример

Converted a product price table to HTML and pasted it into a blog post. Adding borders via CSS made it display nicely.

Common stumbling blocks

  • "<" and "&" characters: inside cells they may be misread as HTML. Check.
  • Site theme: the theme's CSS changes the look.

Frequently asked questions

Can I paste into WordPress?

Yes, into a "Custom HTML" block.

Итог

Choose HTML and your Excel table becomes a web table as is.
