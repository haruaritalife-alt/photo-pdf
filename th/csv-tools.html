PDFเก็บเฉพาะหน้าที่ต้องการ หรือลบหน้าที่ไม่ต้องการบีบอัด PDFย่อ PDF ให้เล็กกว่าขนาดที่คุณเลือก สำหรับขีดจำกัดการอัปโหลดPDF เป็นรูปภาพบันทึกแต่ละหน้าของ PDF เป็นรูปภาพ JPEG หรือ PNGแปลงรูปแบบรูปภาพ (JPG, PNG, WebP)แปลงรูปภาพเป็น JPG, PNG หรือ WebP ได้หลายไฟล์พร้อมกันหมุนและจัดเรียงหน้า PDF ใหม่แก้หน้าที่กลับด้าน เปลี่ยนลำดับหน้า หรือลบหน้าเพิ่มเลขหน้าลงใน PDFเพิ่มเลขหน้าลงใน PDF โดยเลือกตำแหน่งและรูปแบบบีบอัดและปรับขนาดรูปภาพทำให้ไฟล์รูปภาพเล็กลง และปรับขนาดได้หากต้องการแปลง HEIC เป็น JPGแปลงรูปถ่าย HEIC จาก iPhone เป็น JPG หรือ PNGแยก PDFแยก PDF เป็นหลายไฟล์: หน้าละไฟล์ ทุก เพื่อสร้างเรซูเม่แบบญี่ปุ่น (rirekisho) เป็น PDF พร้อมรูปถ่ายติดบัตรหากต้องการสร้างตารางเรียน / ตารางกิจกรรมรายสัปดาห์ใส่วิชาเรียน งาน และแผนต่าง ๆ เพื่อสร้างตารางเรียนหรือตารางรายสัปดาห์เป็น PDF หรือรูปภาพ พร้อมรหัสสีสร้างนามบัตร / ป้ายชื่อใส่ชื่อและรายละเอียดของคุณเพื่อสร้างนามบัตรหรือป้ายชื่อที่จัดวางบน A4 เป็น PDF ทำป้ายชื่อจำนวนมากจากรายชื่อก็ได้สร้าง QR Code (URL, Wi-Fi)สร้าง QR Code จาก ข้อความด้านล่างจึงหายไปดูและลบคุณสมบัติของ PDF (ผู้เขียน ชื่อเรื่อง)ดูผู้เขียน ชื่อเรื่อง ซอฟต์แวร์ และวันที่ที่เก็บไว้ใน PDF แล้วลบหรือแก้ไขกรอก PDF: เพิ่มข้อความ วันที่ ลายเซ็น และเครื่องหมายเพิ่มข้อความ วันที่ เครื่องหมายถูก วงกลม ลายเซ็นเขียนด้วยมือ หรือรูปภาพ (เช่น ตราประทับ) ที่ตำแหน่งใดก็ได้บน PDFปรับขนาดหน้า PDF เป็น A4 หรือขนาดกระดาษอื่นทำให้หน้า PDF ที่มีหลายขนาดมีขนาดเท่ากันทั้งหมด เช่น A4, A3, B5 หรือ Letter ข้อความและกราฟิกยังคงคมชัดลบหน้าออกจาก PDFเลือกและลบหน้าที่ไม่ต้องการออกจาก PDFดึงหน้าออกจาก PDFเลือกหน้าที่ต้องการแล้วบันทึกเป็น PDF ใหม่กลับลำดับหน้าของ PDFกลับลำดับหน้าของ PDFแทรกหน้าว่างลงใน PDFแทรกหน้าว่างที่ตำแหน่งใดก็ได้ใน PDFแยกหน้าคู่ของ PDF เป็นหน้าเดี่ยวแยกหน้าคู่ใน PDF เป็นหน้าเดี่ยวเพิ่มส่วนหัวและส่วนท้ายลงใน PDFเพิ่มชื่อเรื่อง วันที่ หรือเลขหน้าที่ด้านบนและด้านล่างของ PDFจัดเรียง PDF เป็นเล่มเล็กสำหรับพิมพ์จัดลำดับ PDF ใหม่ให้พิมพ์และพับเป็นเล่มเล็กได้ค้นหาและลบหน้าว่างใน PDFค้นหาหน้าว่างใน PDF โดยอัตโนมัติและลบออกเปลี่ยน PDF เป็นรูปภาพยาวรูปเดียวต่อทุกหน้าของ PDF เป็นรูปภาพยาวรูปเดียวรวมสแกนด้านหน้าและด้านหลังเป็น PDF เดียวสลับ PDF ด้านหน้าและ PDF ด้านหลังเป็น PDF เดียวปรับขนาดรูปภาพตามพิกเซลปรับขนาดรูปภาพตามความกว้าง ความสูง หรือเปอร์เซ็นต์หมุนและพลิกรูปภาพหมุนรูปภาพและพลิกในแนวนอนหรือแนวตั้งเพิ่มลายน้ำข้อความลงในรูปภาพซ้อนข้อความลายน้ำ เช่น “สำเนา” บนรูปภาพทำโมเสกหรือเบลอบางส่วนของรูปภาพซ่อนบางส่วนของรูปภาพด้วยโมเสก เบลอ หรือกล่องสีดำลบข้อมูลตำแหน่งและการถ่ายภาพออกจากรูปถ่ายลบข้อมูล GPS วันที่ และกล้องออกจากรูปถ่ายแล้วบันทึกสำเนาที่สะอาดใช้ลุคขาวดำ ซีเปีย และอื่น ๆทำให้รูปภาพเป็นขาวดำหรือซีเปีย หรือเปลี่ยนความสว่างสร้างไอคอนเว็บไซต์ (Favicon)สร้างชุดไอคอนเว็บไซต์ครบชุดจากรูปภาพเดียวรวมรูปภาพหลายรูปเป็นรูปเดียวซ้อนหรือรวมรูปภาพหลายรูปเป็นรูปเดียวครอบตัดเป็นขนาดรูปถ่ายติดบัตรและจัดเรียงเพื่อพิมพ์ครอบตัดรูปถ่ายเป็นขนาดรูปติดบัตรและจัดเรียงบนแผ่นขนาด Lดึงรหัสสีจากรูปภาพอ่านรหัสสีจากรูปภาพและค้นหาสีหลักนับตัวอักษร (สำหรับใบสมัครและรายงาน)นับตัวอักษร บรรทัด และแผ่นกระดาษต้นฉบับของข้อความแปลงระหว่างปี ค.ศ. กับศักราชญี่ปุ่นแปลงระหว่างปี ค.ศ. กับศักราชญี่ปุ่นแปลงอักษรเต็มความกว้าง ครึ่งความกว้าง ฮิระงะนะ และคะตะกะนะแปลงอักษรเต็มความกว้าง/ครึ่งความกว้าง และฮิระงะนะ/คะตะกะนะลบและจัดระเบียบการขึ้นบรรทัดใหม่ในข้อความจัดระเบียบการขึ้นบรรทัดใหม่ในข้อความที่คัดลอกจาก PDF และที่อื่น ๆคำนวณภาษีการบริโภค (รวม / ไม่รวมภาษี)คำนวณราคารวมและไม่รวมภาษีคำนวณอายุ จำนวนวันระหว่างวันที่ และการเลื่อนวันที่คำนวณอายุและจำนวนวันระหว่างวันที่ลบรหัสผ่านออกจาก PDFลบรหัสผ่านและข้อจำกัดออกจาก PDF ที่คุณทราบรหัสผ่านเพิ่มรหัสผ่านให้ PDFเพิ่มรหัสผ่านที่ต้องใช้เปิด PDFอ่านข้อความจากรูปภาพและ PDF (OCR)แปลงข้อความในรูปภาพและ PDF ที่สแกนเป็นข้อความเปรียบเทียบ PDF สองไฟล์ (ค้นหาความแตกต่าง)แสดงความแตกต่างของข้อความระหว่าง PDF สองไฟล์ โดยแยกสีสร้างรหัสผ่านสุ่มที่รัดกุมสร้างรหัสผ่านสุ่มที่รัดกุมได้ทันทีคำนวณเปอร์เซ็นต์ ส่วนลด และการเปลี่ยนแปลงเป็น %คำนวณเปอร์เซ็นต์ ส่วนลด และการเปลี่ยนแปลงเป็น % ได้ทันทีลบบรรทัดซ้ำและเรียงลำดับรายการลบบรรทัดซ้ำและเรียงลำดับตัวแปลงหน่วย (ความยาว น้ำหนัก พื้นที่ อุณหภูมิ และอื่น ๆ)แปลงความยาว น้ำหนัก พื้นที่ อุณหภูมิ และอื่น ๆ ได้ทันทีสร้างไฟล์ ZIPรวมไฟล์หลายไฟล์เป็น ZIP เดียวเปิดไฟล์ ZIP (แตกไฟล์)ดูว่ามีอะไรอยู่ใน ZIP และดึงไฟล์ที่ต้องการตรวจสอบแฮชของไฟล์ (SHA-256)คำนวณแฮชของไฟล์และเปรียบเทียบแปลง CSV และ JSONแปลงระหว่าง CSV และ JSON ได้ทันทีแปลง SVG เป็น PNGแปลงไฟล์ SVG เป็นรูปภาพ PNGแปลงไฟล์และ Base64แปลงระหว่างไฟล์กับข้อความ Base64จัดรูปแบบและตรวจสอบ JSONจัดรูปแบบ ลดขนาด และตรวจสอบ JSONเปรียบเทียบข้อความสองชุด (Diff)แสดงความแตกต่างระหว่างข้อความสองชุดทีละบรรทัดแปลง Excel เป็น CSV หรือ JSONแปลงชีต Excel เป็น CSV, TSV หรือ JSONแปลง CSV เป็น Excel (.xlsx)แปลง CSV เป็นไฟล์ Excel (.xlsx)ดึงข้อความจากไฟล์ Wordดึงข้อความธรรมดาจากไฟล์ Wordดึงข้อความจาก PowerPointดึงข้อความของแต่ละสไลด์ PowerPointนำข้อความ PDF ไปใส่ใน Wordดึงข้อความ PDF ไปใส่ในไฟล์ Wordใส่รูปภาพลงในไฟล์ Wordใส่รูปภาพลงในไฟล์ Word หน้าละรูปแปลงสูตร Excel เป็นค่าแทนที่สูตร Excel ด้วยค่าของสูตรลบข้อมูลผู้เขียนออกจากไฟล์ Officeล้างข้อมูลผู้เขียนและข้อมูลอื่น ๆ ที่เก็บไว้ในไฟล์ Officeดึงรูปภาพจาก Word, Excel และ PowerPointดึงรูปภาพจากไฟล์ Office เป็นไฟล์ ZIPแปลง Word เป็น HTMLแปลงข้อความ Word เป็น HTMLแยกไฟล์ Excel ตามชีตแยกแต่ละชีต Excel เป็นไฟล์ CSV หรือ TSV ของตัวเองแปลงตาราง Excel เป็น HTML หรือ Markdownแปลงตาราง Excel เป็นตาราง HTML หรือ Markdownแปลงการเข้ารหัสข้อความ (แก้ข้อความเพี้ยน)แปลงไฟล์ข้อความระหว่าง Shift_JIS, UTF-8, EUC-JP และอื่น ๆ เพื่อแก้ข้อความเพี้ยนแบ่งรูปภาพเป็นตาราง (สำหรับโพสต์โซเชียล)แบ่งรูปภาพเป็นชิ้นเท่า ๆ กันตามแนวนอนและแนวตั้งแล้วบันทึกสร้าง GIF เคลื่อนไหวจากรูปภาพรวมรูปภาพหลายรูปตามลำดับเป็น GIF เคลื่อนไหวเปลี่ยนชื่อไฟล์จำนวนมากพร้อมกัน (ตัวเลข วันที่)เปลี่ยนชื่อไฟล์จำนวนมากพร้อมกันด้วยตัวเลขหรือวันที่ดึงรูปภาพออกจาก PDFดึงรูปภาพที่ฝังใน PDF ออกมาในคุณภาพต้นฉบับค้นหาไฟล์ซ้ำค้นหาไฟล์ที่มีเนื้อหาเหมือนกันแล้วบันทึก ZIP ที่ไม่มีไฟล์ซ้ำตรวจสอบประเภทจริงของไฟล์ (นามสกุลเทียบกับเนื้อหา)ตัดสินประเภทไฟล์จากเนื้อหาและตรวจสอบว่านามสกุลตรงกันหรือไม่เข้ารหัสและถอดรหัสไฟล์ด้วยรหัสผ่านเข้ารหัสและถอดรหัสไฟล์ใดก็ได้ด้วยรหัสผ่าน (AES-256)รวมและแยกไฟล์ข้อความรวมไฟล์ข้อความเป็นไฟล์เดียวหรือแยกตามบรรทัดหรือขนาดรวมไฟล์ Excel หลายไฟล์เป็น CSV เดียวนำข้อมูลจากไฟล์ Excel หลายไฟล์มาต่อกันเป็น CSV เดียวดูและเพิ่มบุ๊กมาร์ก PDFดูและเพิ่มบุ๊กมาร์ก (สารบัญ) ของ PDFตัดไฟล์เสียงตัดส่วนหนึ่งของไฟล์เสียงแล้วบันทึกเป็น WAVบันทึกเฟรมวิดีโอเป็นรูปภาพบันทึกช่วงใดก็ได้ของวิดีโอเป็นรูปภาพ
