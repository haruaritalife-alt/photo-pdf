กรอก PDF: เพิ่มข้อความ วันที่ และลายเซ็น

กรอกแบบฟอร์มและเซ็นได้ ตรงบน PDF เลย

PDF และลายเซ็นของคุณไม่เคยถูกอัปโหลด ทุกอย่างประมวลผลบนอุปกรณ์นี้

เสร็จสิ้น

หาก PDF Mikata มีประโยชน์ ทิปเล็ก ๆ น้อย ๆ จะเป็นกำลังใจอย่างมาก

ส่งทิป (¥300)ส่งของขวัญ (Amazon wishlist)

วิธีใช้

  1. แตะ “เลือก PDF” แล้วเลือก PDF หนึ่งไฟล์
  2. เลือก “สิ่งที่จะเพิ่ม”: ข้อความ วันที่ ✓ ○ × ลายเซ็น หรือรูปภาพ (เช่นตราประทับ)
  3. แตะ (คลิก) ตำแหน่งบนหน้าที่ต้องการ
  4. แก้ตำแหน่งและขนาดด้วยลูกศรและ “−” / “＋” เปิด “ลากเพื่อย้าย” เพื่อย้ายด้วยนิ้วหรือเมาส์
  5. แตะ “เพิ่มลงใน PDF และสร้าง” ตรวจสอบตัวอย่าง แล้วบันทึก PDF

ลายเซ็นและตราประทับ

  • ลายเซ็น: วาดในกล่องด้วยนิ้วหรือเมาส์ ใช้บนอุปกรณ์นี้เท่านั้น ไม่เคยถูกบันทึกหรือส่ง
  • รูปภาพ: เลือกรูปถ่ายตราประทับหรือลายเซ็นที่ประทับหรือเขียนบนกระดาษขาว “ทำให้โปร่งใส” ลบพื้นหลัง

หมายเหตุ

  • ข้อความที่เพิ่มถูกวางเป็นรูปภาพ เลือกหรือค้นหาไม่ได้
  • หลังบันทึก เลิกทำสิ่งที่เพิ่มไม่ได้ เก็บ PDF ต้นฉบับไว้
  • หากผู้รับระบุวิธีสำหรับลายเซ็นอิเล็กทรอนิกส์ ให้ทำตามคำแนะนำของเขา
  • ไม่รองรับ PDF ที่มีรหัสผ่าน

คู่มือของเครื่องมือนี้

วิธีพิมพ์ข้อความลงบน PDF โดยไม่ต้องพิมพ์ออกมา (ฟรี ใช้บนมือถือได้)วิธีเพิ่มลายเซ็นลายมือลงใน PDF (โทรศัพท์ ใช้นิ้วได้)วิธีเพิ่มรูปตราประทับหรือแสตมป์ลงใน PDFวิธีเพิ่มวันที่ปัจจุบันลงใน PDFวิธีเพิ่มเครื่องหมายถูก วงกลม และกากบาทลงใน PDFวิธีแก้ตำแหน่งของสิ่งที่คุณเพิ่มต้องทำอย่างไรหากข้อความไม่ปรากฏถูกต้องบน PDF

เครื่องมืออื่น ๆ

รูปภาพเป็น PDFรวมรูปถ่ายหลายรูปเป็น PDF เดียวตามลำดับที่คุณเลือก หมุน จัดลำดับ และกำหนดขีดจำกัดขนาดได้รวม PDFรวมไฟล์ PDF หลายไฟล์เป็นไฟล์เดียวตามลำดับที่คุณเลือกดึงหรือลบหน้า PDFเก็บเฉพาะหน้าที่ต้องการ หรือลบหน้าที่ไม่ต้องการบีบอัด PDFย่อ PDF ให้เล็กกว่าขนาดที่คุณเลือก สำหรับขีดจำกัดการอัปโหลดPDF เป็นรูปภาพบันทึกแต่ละหน้าของ PDF เป็นรูปภาพ JPEG หรือ PNGแปลงรูปแบบรูปภาพ (JPG, PNG, WebP)แปลงรูปภาพเป็น JPG, PNG หรือ WebP ได้หลายไฟล์พร้อมกันหมุนและจัดเรียงหน้า PDF ใหม่แก้หน้าที่กลับด้าน เปลี่ยนลำดับหน้า หรือลบหน้าเพิ่มเลขหน้าลงใน PDFเพิ่มเลขหน้าลงใน PDF โดยเลือกตำแหน่งและรูปแบบบีบอัดและปรับขนาดรูปภาพทำให้ไฟล์รูปภาพเล็กลง และปรับขนาดได้หากต้องการแปลง HEIC เป็น JPGแปลงรูปถ่าย HEIC จาก iPhone เป็น JPG หรือ PNGแยก PDFแยก PDF เป็นหลายไฟล์: หน้าละไฟล์ ทุก N หน้า หรือตามช่วงครอบตัดและหมุนรูปภาพครอบตัดรูปภาพตามพื้นที่หรืออัตราส่วนที่ต้องการ และหมุนได้ดึงข้อความจาก PDFดึงข้อความออกจาก PDF เพื่อคัดลอกหรือบันทึกสร้าง PDF ใบเสร็จรับเงินกรอกผู้จ่าย จำนวนเงิน และรายละเอียดเพื่อสร้าง PDF ใบเสร็จรับเงิน รายละเอียดภาษีและเลขทะเบียนใบกำกับภาษีเป็นตัวเลือกสร้าง PDF เรซูเม่ (rirekisho แบบญี่ปุ่น)กรอกรายละเอียด ประวัติการศึกษา ประวัติการทำงาน และแรงจูงใจ เพื่อสร้างเรซูเม่แบบญี่ปุ่น (rirekisho) เป็น PDF พร้อมรูปถ่ายติดบัตรหากต้องการสร้างตารางเรียน / ตารางกิจกรรมรายสัปดาห์ใส่วิชาเรียน งาน และแผนต่าง ๆ เพื่อสร้างตารางเรียนหรือตารางรายสัปดาห์เป็น PDF หรือรูปภาพ พร้อมรหัสสีสร้างนามบัตร / ป้ายชื่อใส่ชื่อและรายละเอียดของคุณเพื่อสร้างนามบัตรหรือป้ายชื่อที่จัดวางบน A4 เป็น PDF ทำป้ายชื่อจำนวนมากจากรายชื่อก็ได้สร้าง QR Code (URL, Wi-Fi)สร้าง QR Code จาก URL ข้อความ หรือข้อมูล Wi-Fi แล้วบันทึกเป็น PNG, SVG หรือ PDFรวมหน้า PDF ไว้บนแผ่นเดียว (2-up, 4-up)จัดหน้า PDF หลายหน้าบนแผ่น A4 แผ่นเดียว (2, 4, 6, 8 หรือ 9 หน้าต่อแผ่น) เพื่อประหยัดกระดาษเมื่อพิมพ์แปลง PDF เป็นโทนสีเทา (ขาวดำ)เปลี่ยน PDF สีเป็นโทนสีเทาหรือขาวดำล้วน พร้อมพิมพ์ ถ่ายเอกสาร หรือส่งแฟกซ์แบบขาวดำ เลือกความละเอียดได้เพิ่มลายน้ำข้อความลงใน PDFเพิ่มข้อความ เช่น “สำหรับยื่น” “สำเนา” หรือ “ลับ” แบบจาง ๆ ทั่วทุกหน้า PDF เลือกตำแหน่ง สี และความโปร่งใสได้ตัดขอบ PDFตัดขอบ PDF โดยอัตโนมัติหรือกำหนดแต่ละด้านเอง อ่านบนมือถือได้ง่ายขึ้นและพิมพ์ออกมาสะอาดขึ้นปิดทับสีดำ (ลบข้อมูล) บางส่วนของ PDFลากคลุมส่วนของ PDF ที่ต้องการซ่อนเพื่อปิดทับด้วยสีดำ หน้าที่ถูกปิดจะกลายเป็นรูปภาพ ข้อความด้านล่างจึงหายไปดูและลบคุณสมบัติของ PDF (ผู้เขียน ชื่อเรื่อง)ดูผู้เขียน ชื่อเรื่อง ซอฟต์แวร์ และวันที่ที่เก็บไว้ใน PDF แล้วลบหรือแก้ไขปรับขนาดหน้า PDF เป็น A4 หรือขนาดกระดาษอื่นทำให้หน้า PDF ที่มีหลายขนาดมีขนาดเท่ากันทั้งหมด เช่น A4, A3, B5 หรือ Letter ข้อความและกราฟิกยังคงคมชัดลบหน้าออกจาก PDFเลือกและลบหน้าที่ไม่ต้องการออกจาก PDFดึงหน้าออกจาก PDFเลือกหน้าที่ต้องการแล้วบันทึกเป็น PDF ใหม่กลับลำดับหน้าของ PDFกลับลำดับหน้าของ PDFแทรกหน้าว่างลงใน PDFแทรกหน้าว่างที่ตำแหน่งใดก็ได้ใน PDFแยกหน้าคู่ของ PDF เป็นหน้าเดี่ยวแยกหน้าคู่ใน PDF เป็นหน้าเดี่ยวเพิ่มส่วนหัวและส่วนท้ายลงใน PDFเพิ่มชื่อเรื่อง วันที่ หรือเลขหน้าที่ด้านบนและด้านล่างของ PDFจัดเรียง PDF เป็นเล่มเล็กสำหรับพิมพ์จัดลำดับ PDF ใหม่ให้พิมพ์และพับเป็นเล่มเล็กได้ค้นหาและลบหน้าว่างใน PDFค้นหาหน้าว่างใน PDF โดยอัตโนมัติและลบออกเปลี่ยน PDF เป็นรูปภาพยาวรูปเดียวต่อทุกหน้าของ PDF เป็นรูปภาพยาวรูปเดียวรวมสแกนด้านหน้าและด้านหลังเป็น PDF เดียวสลับ PDF ด้านหน้าและ PDF ด้านหลังเป็น PDF เดียวปรับขนาดรูปภาพตามพิกเซลปรับขนาดรูปภาพตามความกว้าง ความสูง หรือเปอร์เซ็นต์หมุนและพลิกรูปภาพหมุนรูปภาพและพลิกในแนวนอนหรือแนวตั้งเพิ่มลายน้ำข้อความลงในรูปภาพซ้อนข้อความลายน้ำ เช่น “สำเนา” บนรูปภาพทำโมเสกหรือเบลอบางส่วนของรูปภาพซ่อนบางส่วนของรูปภาพด้วยโมเสก เบลอ หรือกล่องสีดำลบข้อมูลตำแหน่งและการถ่ายภาพออกจากรูปถ่ายลบข้อมูล GPS วันที่ และกล้องออกจากรูปถ่ายแล้วบันทึกสำเนาที่สะอาดใช้ลุคขาวดำ ซีเปีย และอื่น ๆทำให้รูปภาพเป็นขาวดำหรือซีเปีย หรือเปลี่ยนความสว่างสร้างไอคอนเว็บไซต์ (Favicon)สร้างชุดไอคอนเว็บไซต์ครบชุดจากรูปภาพเดียวรวมรูปภาพหลายรูปเป็นรูปเดียวซ้อนหรือรวมรูปภาพหลายรูปเป็นรูปเดียวครอบตัดเป็นขนาดรูปถ่ายติดบัตรและจัดเรียงเพื่อพิมพ์ครอบตัดรูปถ่ายเป็นขนาดรูปติดบัตรและจัดเรียงบนแผ่นขนาด Lดึงรหัสสีจากรูปภาพอ่านรหัสสีจากรูปภาพและค้นหาสีหลักนับตัวอักษร (สำหรับใบสมัครและรายงาน)นับตัวอักษร บรรทัด และแผ่นกระดาษต้นฉบับของข้อความแปลงระหว่างปี ค.ศ. กับศักราชญี่ปุ่นแปลงระหว่างปี ค.ศ. กับศักราชญี่ปุ่นแปลงอักษรเต็มความกว้าง ครึ่งความกว้าง ฮิระงะนะ และคะตะกะนะแปลงอักษรเต็มความกว้าง/ครึ่งความกว้าง และฮิระงะนะ/คะตะกะนะลบและจัดระเบียบการขึ้นบรรทัดใหม่ในข้อความจัดระเบียบการขึ้นบรรทัดใหม่ในข้อความที่คัดลอกจาก PDF และที่อื่น ๆคำนวณภาษีการบริโภค (รวม / ไม่รวมภาษี)คำนวณราคารวมและไม่รวมภาษีคำนวณอายุ จำนวนวันระหว่างวันที่ และการเลื่อนวันที่คำนวณอายุและจำนวนวันระหว่างวันที่ลบรหัสผ่านออกจาก PDFลบรหัสผ่านและข้อจำกัดออกจาก PDF ที่คุณทราบรหัสผ่านเพิ่มรหัสผ่านให้ PDFเพิ่มรหัสผ่านที่ต้องใช้เปิด PDFอ่านข้อความจากรูปภาพและ PDF (OCR)แปลงข้อความในรูปภาพและ PDF ที่สแกนเป็นข้อความเปรียบเทียบ PDF สองไฟล์ (ค้นหาความแตกต่าง)แสดงความแตกต่างของข้อความระหว่าง PDF สองไฟล์ โดยแยกสีสร้างรหัสผ่านสุ่มที่รัดกุมสร้างรหัสผ่านสุ่มที่รัดกุมได้ทันทีคำนวณเปอร์เซ็นต์ ส่วนลด และการเปลี่ยนแปลงเป็น %คำนวณเปอร์เซ็นต์ ส่วนลด และการเปลี่ยนแปลงเป็น % ได้ทันทีลบบรรทัดซ้ำและเรียงลำดับรายการลบบรรทัดซ้ำและเรียงลำดับตัวแปลงหน่วย (ความยาว น้ำหนัก พื้นที่ อุณหภูมิ และอื่น ๆ)แปลงความยาว น้ำหนัก พื้นที่ อุณหภูมิ และอื่น ๆ ได้ทันทีสร้างไฟล์ ZIPรวมไฟล์หลายไฟล์เป็น ZIP เดียวเปิดไฟล์ ZIP (แตกไฟล์)ดูว่ามีอะไรอยู่ใน ZIP และดึงไฟล์ที่ต้องการตรวจสอบแฮชของไฟล์ (SHA-256)คำนวณแฮชของไฟล์และเปรียบเทียบแปลง CSV และ JSONแปลงระหว่าง CSV และ JSON
