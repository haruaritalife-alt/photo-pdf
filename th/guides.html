คู่มือทั้งหมด

วิธีใช้และการแก้ปัญหาของแต่ละเครื่องมือ

พื้นฐาน (รูปถ่ายและ PDF)

  • วิธีรวมรูปภาพเป็น PDF เดียวบน iPhone
  • วิธีรวมรูปภาพหลายรูปเป็น PDF เดียว (Windows, Mac, Android)
  • เคล็ดลับการถ่ายเอกสารให้ชัดเจนและเปลี่ยนเป็น PDF
  • ต้องทำอย่างไรเมื่อ PDF ที่สร้างจากรูปถ่ายใหญ่เกินไป
  • รายการตรวจสอบก่อนส่งเอกสารเป็น PDF
  • วิธีบันทึกใบเสร็จเป็น PDF ด้วยโทรศัพท์
  • JPEG หรือ PDF: ควรยื่นแบบไหน

รูปภาพเป็น PDF

  • วิธีทำ PDF จากภาพถ่ายขนาด A4
  • วิธีทำให้ PDF จากภาพถ่ายมีขนาดไม่เกิน 2 MB
  • วิธีแก้ลำดับหน้าของ PDF จากภาพถ่าย
  • แก้ภาพถ่ายที่ปรากฏตะแคงหรือกลับหัวใน PDF
  • ข้อควรทราบเมื่อทำ PDF จากภาพถ่ายบัตรประจำตัว
  • ทำไมข้อความใน PDF จากภาพถ่ายจึงเบลอและวิธีแก้
  • ทำไมการแปลงเป็น PDF โดยไม่อัปโหลดภาพถ่ายจึงปลอดภัยกว่า

รวม PDF

  • วิธีรวม PDF หลายไฟล์เป็นไฟล์เดียว (มือถือและคอมพิวเตอร์)
  • วิธีเลือกลำดับเมื่อรวม PDF และจัดเรียงใหม่ภายหลัง
  • ต้องทำอย่างไรเมื่อ PDF ที่รวมแล้วใหญ่เกินไป
  • ทำไมรวม PDF ไม่ได้หรือขึ้นข้อผิดพลาด
  • เคล็ดลับการรวมเอกสารสมัครงานเป็น PDF เดียว
  • วิธีรวมรูปถ่ายและ PDF เป็นไฟล์เดียว
  • จุดตรวจสอบความปลอดภัยเมื่อเลือกเครื่องมือรวม PDF

ดึงหรือลบหน้า PDF

  • วิธีดึงเฉพาะหน้าที่ต้องการจาก PDF
  • วิธีลบหน้าที่ไม่ต้องการจาก PDF
  • เคล็ดลับการลบหน้าว่างออกจาก PDF ที่สแกน
  • วิธีส่ง PDF โดยไม่มีหน้าที่มีข้อมูลส่วนบุคคล
  • ลดขนาด PDF ด้วยการตัดหน้า
  • ดึงหน้ากับแยก PDF: ต่างกันอย่างไร
  • วิธีดึงเฉพาะบางหน้าของ PDF เพื่อพิมพ์

บีบอัด PDF

  • วิธีบีบอัด PDF ให้พอดีกับขีดจำกัดขนาด
  • ต้องทำอย่างไรเมื่อ PDF ใหญ่เกินกว่าจะแนบอีเมล
  • ทำไมเลือกข้อความใน PDF ที่บีบอัดไม่ได้
  • การเลือกคุณภาพเมื่อบีบอัด: เล็ก ปกติ หรือสูง
  • ทำไม PDF ที่สแกนจึงหนัก และวิธีทำให้เบาลง
  • ขีดจำกัดการอัปโหลดทั่วไปในแบบฟอร์มสมัครและวิธีทำให้พอดี
  • วิธีบีบอัด PDF โดยไม่ต้องส่งไฟล์ออกไป

PDF เป็นรูปภาพ

  • วิธีเปลี่ยน PDF เป็นรูปภาพ JPEG หรือ PNG
  • JPEG หรือ PNG: แบบไหนดีกว่าเมื่อแปลง PDF เป็นรูปภาพ
  • การเปลี่ยนหน้า PDF เป็นรูปภาพสำหรับโซเชียลมีเดียหรือสไลด์
  • เคล็ดลับการส่งเอกสาร PDF เป็นรูปภาพ
  • ทำไม PDF จึงแปลงเป็นรูปภาพไม่ได้ และต้องทำอย่างไร
  • วิธีที่ปลอดภัยในการแปลง PDF เป็นรูปภาพโดยไม่ส่งออกไป
  • การเลือกขนาดเมื่อแปลง PDF เป็นรูปภาพ: เล็ก ปกติ หรือ ใหญ่

แปลงรูปแบบรูปภาพ (JPG, PNG, WebP)

  • วิธีแปลงรูปภาพระหว่าง JPG, PNG และ WebP
  • วิธีทำให้รูป PNG เบาลงโดยแปลงเป็น JPG
  • วิธีแปลงรูป WebP เป็น JPG หรือ PNG
  • ต้องทำอย่างไรเมื่อแบบฟอร์มปฏิเสธรูปแบบรูปภาพของคุณ
  • JPG, PNG และ WebP อธิบายสำหรับผู้เริ่มต้น
  • หมายเหตุการจัดการรูปพื้นหลังโปร่งใส (PNG เป็น JPG)
  • วิธีแปลง JPG เป็น PNG และเมื่อไรที่คุ้มค่า

หมุนและจัดเรียงหน้า PDF ใหม่

  • วิธีหมุนหน้า PDF เพื่อแก้ทิศทาง
  • วิธีจัดเรียงหน้าของ PDF ใหม่
  • ลำดับที่ดีที่สุดในการจัดระเบียบ PDF: หมุน เรียงลำดับ ลบ
  • ทำไม PDF ที่สแกนจึงออกมาตะแคง และวิธีแก้
  • วิธีแก้ทิศทางของ PDF ที่ทำบน iPhone
  • รายการตรวจสอบก่อนส่ง PDF: ทิศทาง ลำดับ และจำนวนหน้า
  • วิธีจัดระเบียบ PDF ที่มีหน้าแนวตั้งและแนวนอนปะปนกัน

เพิ่มเลขหน้าลงใน PDF

  • วิธีเพิ่มเลขหน้าลงใน PDF
  • ข้ามหน้าปกและเริ่มที่ 1 ในหน้าสอง
  • เมื่อการส่งต้องมีเลขหน้า
  • การเลือกตำแหน่งและรูปแบบของเลขหน้า
  • การเพิ่มเลขหน้าต่อเนื่องหลังรวม PDF
  • ต้องทำอย่างไรเมื่อเลขหน้ามองเห็นยากหรือทับกัน
  • วิธีเปลี่ยนเลขหน้าเริ่มต้น

บีบอัดและปรับขนาดรูปภาพ

  • วิธีลดขนาดไฟล์รูปภาพ (บีบอัดและปรับขนาด)
  • วิธีทำให้รูปภาพต่ำกว่า 1 MB หรือ 500 KB
  • ขนาดรูปภาพ (px) ที่แนะนำตามการใช้งาน
  • วิธีทำให้รูปเบาลงเมื่อส่งหลายรูปทางอีเมล
  • การปรับขนาดไฟล์และขนาดภาพของรูปถ่ายติดบัตรและรูปบุคคล
  • การบีบอัดรูปภาพทำให้คุณภาพลดลงหรือไม่ วิธีทำให้การสูญเสียไม่เป็นที่สังเกต
  • วิธีบีบอัดรูปภาพโดยไม่ส่งไปที่ใด

แปลง HEIC เป็น JPG

  • ต้องทำอย่างไรเมื่อรูป HEIC เปิดบน Windows ไม่ได้

  • การตั้งค่า iPhone ให้ถ่ายเป็น JPG ตั้งแต่แรก
  • HEIC กับ JPG: ต่างกันอย่างไรและควรใช้แบบไหน
  • วิธีเปลี่ยนรูป HEIC จาก iPhone เป็น PDF
  • เคล็ดลับการแปลงรูป HEIC จำนวนมากพร้อมกัน

  • การแยก PDF และประกอบใหม่เฉพาะส่วนที่ต้องการ

ครอบตัดและหมุนรูปภาพ

  • วิธีหมุนรูปถ่ายที่กลับด้าน
  • วิธีตัดส่วนที่ไม่จำเป็นออกจากรูปถ่าย (เอกสารและรูปติดบัตร)

  • ตัดก่อน: การครอบตัดก่อนย่อรูปภาพ

  • ทำไมจึงดึงข้อความจาก PDF ไม่ได้ (PDF ที่สแกน)
  • วิธีคัดลอกข้อความ PDF ไปยัง Word หรือโน้ต
  • ทำอย่างไรเมื่อข้อความ PDF ที่ดึงออกมาเพี้ยน
  • เคล็ดลับการใช้ข้อความ PDF สำหรับการเรียนและรายงาน
  • ควรเพิ่มตัวคั่นหน้าหรือไม่ เลือกระหว่างเปิดและปิด
  • วิธีดึงข้อความ PDF โดยไม่ส่งไฟล์ไปที่ใด

สร้าง PDF ใบเสร็จรับเงิน

  • วิธีสร้างใบเสร็จ PDF (ใช้บนโทรศัพท์ได้)
  • สิ่งที่ต้องมีในใบเสร็จ: หกรายการสำคัญ
  • ใบเสร็จต้องมีหมายเลขลงทะเบียนใบกำกับภาษีหรือไม่
  • ใบเสร็จอิเล็กทรอนิกส์ไม่ต้องติดอากรแสตมป์ใช่หรือไม่
  • มารยาทและเคล็ดลับการส่งใบเสร็จอิเล็กทรอนิกส์ทางอีเมล
  • ทำอย่างไรเมื่อใบเสร็จมีข้อผิดพลาดหรือหาย
  • ใบเสร็จ ใบเสร็จจากเครื่องคิดเงิน ใบกำกับภาษี และหลักฐานการชำระเงิน: ต่างกันอย่างไร

สร้าง PDF เรซูเม่ (rirekisho แบบญี่ปุ่น)

  • วิธีสร้างเรซูเม่ PDF ฟรี (ใช้บนโทรศัพท์ได้)
  • วิธีเขียนประวัติการศึกษาและการทำงานในเรซูเม่ญี่ปุ่น
  • รูปถ่ายติดบัตรสำหรับเรซูเม่: ขนาด วิธีถ่าย และการใช้รูปจากโทรศัพท์
  • การเขียนแรงจูงใจและการแนะนำตัว: แนวทางสามขั้น
  • มารยาทในการส่งเรซูเม่ PDF ทางอีเมล
  • เรซูเม่เขียนด้วยมือหรือพิมพ์: แบบไหนดีกว่า
  • การปกป้องข้อมูลส่วนบุคคลเมื่อทำเรซูเม่ออนไลน์

สร้างตารางเรียน / ตารางกิจกรรมรายสัปดาห์

  • วิธีทำตารางเรียนเป็น PDF หรือรูปภาพ (ฟรี ใช้บนโทรศัพท์ได้)
  • วางแผนตารางเรียนมหาวิทยาลัย: หกสิ่งที่ต้องตรวจสอบก่อนลงทะเบียน
  • วิธีทำตารางรายสัปดาห์: เห็นงาน เรียน และพักผ่อนได้ในพริบตา
  • วิธีพิมพ์ตารางเรียนหรือใช้เป็นวอลเปเปอร์โทรศัพท์
  • ทำตารางเรียนที่อ่านง่าย: สี ความยาวข้อความ และพื้นที่
  • การใช้คาบว่าง: สร้างแผนการเรียนจากตารางเรียนของคุณ
  • การแชร์ตารางเรียนกับเพื่อนและอัปเดตหลังมีการเปลี่ยนแปลง

สร้างนามบัตร / ป้ายชื่อ

  • วิธีทำและพิมพ์นามบัตรฟรี (ใช้บนโทรศัพท์ได้)
  • ขนาดนามบัตรและเคล็ดลับการพิมพ์และตัดที่บ้านหรือที่ร้าน
  • สิ่งที่นักศึกษาและชมรมควรใส่ในการ์ด และสิ่งที่ไม่ควรเปิดเผยมากเกินไป
  • เคล็ดลับนามบัตรที่อ่านง่าย: ขนาดข้อความ สี และพื้นที่ว่าง
  • วิธีทำป้ายชื่องานจำนวนมากจากรายชื่อ
  • มารยาทพื้นฐานของนามบัตร: หกข้อที่นักศึกษาควรรู้
  • การปกป้องข้อมูลส่วนบุคคลบนการ์ดและป้าย: ควรใส่อะไรและใครจะได้รับ

สร้าง QR Code (URL, Wi-Fi)

  • วิธีสร้างคิวอาร์โค้ดฟรี (URL ใช้บนโทรศัพท์ได้)
  • การสร้างคิวอาร์โค้ด Wi-Fi เพื่อให้แขกเชื่อมต่อได้โดยไม่ต้องพิมพ์
  • เคล็ดลับเรื่องขนาด ขอบ และสีเมื่อพิมพ์คิวอาร์โค้ด
  • วิธีใส่คิวอาร์โค้ดบนใบปลิว นามบัตร หรือโปสเตอร์
  • ทำไมคิวอาร์โค้ดสแกนไม่ได้และต้องทำอย่างไร
  • การใช้คิวอาร์โค้ดอย่างปลอดภัย: โค้ดปลอมและข้อควรระวังสำหรับผู้สร้าง
  • PNG, SVG หรือ PDF: ควรบันทึกคิวอาร์โค้ดในรูปแบบใด

รวมหน้า PDF ไว้บนแผ่นเดียว (2-up, 4-up)

  • วิธีพิมพ์ PDF 2 หรือ 4 หน้าต่อแผ่น (ใช้บนโทรศัพท์ได้)

  • 2-up, 4-up, 6-up หรือ 9-up: แบบไหนดีที่สุด? แนวทางขนาดข้อความ
  • ประหยัดกระดาษด้วยการรวมหน้าและพิมพ์สองหน้า
  • เคล็ดลับการพิมพ์ PDF ที่รวมแล้วที่ร้านสะดวกซื้อ
  • ขอบและเส้นขอบเมื่อรวมหน้า: เคล็ดลับเพื่อความอ่านง่าย
  • แก้ปัญหา PDF ที่รวมแล้ว: ทิศทาง ลำดับ และข้อความเล็กจิ๋ว
