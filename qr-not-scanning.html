QRコードが読み取れないときの原因と対処法

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • 小さい・ぼやけている・余白がないが、よくある原因
  • 文字を減らし、色を濃くして、作り直す
  • 印刷したもので、試す

QRコードを作ったのに、スマホで読み取れない。原因は、いくつかに絞られます。QRコードを作成（URL・Wi-Fi） で作ったQRコードが読み取れないときの、確認の順番を説明します。

確認の順番

  1. 大きさ：小さすぎないか。
  2. 余白：まわりに、余白があるか。
  3. コントラスト：背景と、QRの色の差が、十分あるか。
  4. 画質：ぼやけたり、つぶれたりしていないか。
  5. 文字量：入れた文字が、多すぎないか。
  6. 内容：URLの入力に、誤りがないか。

1. 大きさ

印刷や画面で小さく表示すると、読み取れません。大きくします。「画像の大きさ」は大（2000px）にします。

2. 余白

QRの周りに、文字や線が接していると、読み取りにくくなります。余白を残します。

3. コントラスト

「色」は、黒、紺、ティール、えんじから選べます。薄い背景に置かないようにします。

4. 画質

画像を引き伸ばしたり、圧縮しすぎたりすると、ぼやけます。拡大して使うなら、SVGで保存します。

5. 文字量

文字が多いと、模様が細かくなります。「文字が多いので、模様が細かくなっています。」と表示されたら、短いURLにするか、読み取りの強さを下げます。

「文字が多すぎて、QRコードにできません。短くするか、読み取りの強さを下げてください。」と出たときも、同様に対処します。

6. 内容

URLに、打ち間違いがないか確認します。https:// が付いていないURLは、自動で付けます。

読み取りの強さ（誤り訂正）

  • 汚れや折れが心配なら、強めにします。
  • 文字が多いなら、弱めにして、模様を粗くします。

手順

  1. 画面で表示したQRコードを、別のスマホやカメラアプリで読み取ってみます。
  2. 読み取れれば、印刷の条件が原因です。
  3. 読み取れなければ、作り方（URL、文字量）が原因です。
使う前に、スマホのカメラで読み取って、正しく開くか確認してください。

つまずきやすい点

  • スマホによって読み取れたり読み取れなかったりする：大きさや余白に余裕がないかもしれません。
  • カメラアプリを使っていない：専用のアプリより、標準のカメラアプリが読み取りやすいことがあります。
  • 画面の反射：画面に光が反射していないか確認します。

よくある質問

Wi-FiのQRコードが読み取れません

SSIDとパスワード、暗号化の種類を確認します。

印刷したら読み取れない

大きくして、余白を確認し、濃い色にします。別の解説も参考になります。

まとめ

大きさ、余白、コントラスト、画質、文字量、内容の順に確認します。

QRコードを作成（URL・Wi-Fi）を使う（無料）

あわせて使えるツール

  • 画像を圧縮・サイズ変更：画像のファイルサイズを小さくします。大きさの変更もできます。
  • 画像の形式を変換（JPG・PNG・WebP）：画像をJPG・PNG・WebPに、まとめて変換します。
  • 写真をPDFに変換：複数の写真を、順番どおりに1つのPDFへ。回転、並べ替え、サイズ指定ができます。

Why a QR Code Won't Scan and What to Do

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Small, blurry or no margin are common causes
  • Reduce text, use a darker color and remake it
  • Test the printed copy

You made a QR code, but a phone cannot scan it. The causes narrow down to a few. Here is the order for checking when a QR code made with Create a QR Code (URL, Wi-Fi) will not scan.

The order to check

  1. Size: is it too small?
  2. Margin: is there a margin around it?
  3. Contrast: is there enough difference between the background and the QR colour?
  4. Image quality: is it blurred or crushed?
  5. Amount of text: is the text too long?
  6. Content: is the URL entered correctly?

1. Size

Shown small in print or on screen, it will not scan. Enlarge it. Set "Image size" to large (2000 px).

2. Margin

If text or lines touch the QR, it is harder to scan. Leave a margin.

3. Contrast

"Color" offers black, navy, teal and maroon. Do not place it on a pale background.

4. Image quality

Stretching the image or compressing it too much blurs it. If you will enlarge it, save as SVG.

5. Amount of text

A lot of text makes the pattern fine. If "The pattern is fine because there is a lot of text" appears, use a shorter URL or lower the error correction.

Handle it the same way when "Too much text to make a QR code. Shorten it or lower the error correction" appears.

6. Content

Check the URL for typos. A URL without https:// gets it added automatically.

Error correction

  • If you worry about dirt or creases, set it stronger.
  • If there is a lot of text, set it weaker to keep the pattern coarse.

Steps

  1. Try scanning the QR code shown on screen with another phone or camera app.
  2. If it scans, the printing conditions are the cause.
  3. If it does not, the way it was made (URL, amount of text) is the cause.
Before using it, scan it with a phone camera and check that it opens correctly.

Common stumbling blocks

  • It scans on some phones but not others: size or margin may have no spare room.
  • You are not using the camera app: the standard camera app can scan more easily than some dedicated apps.
  • Screen glare: check that light is not reflecting off the screen.

Frequently asked questions

A Wi-Fi QR code will not scan

Check the SSID, password and security type.

It will not scan once printed

Enlarge it, check the margins and use a dark colour. The other guide may help too.

Summary

Check in the order size, margin, contrast, image quality, amount of text and content.
