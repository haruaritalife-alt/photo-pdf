下書き・確認用の資料に「DRAFT」を入れる：版を間違えないコツ

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • 「DRAFT」「案」を全ページに入れる
  • ファイル名にも、版と日付を
  • 最終版には、透かしなしの元ファイルを使う

会議資料の第2版、契約書の下書き、報告書の確認用。版が複数あると、最新版か、最終版かが分からなくなり、事故につながります。PDFに透かし文字を入れる で「DRAFT」などの透かしを入れておくと、版の取り違えを防ぎやすくなります。

透かしで区別できること

  • 下書き（DRAFT）か、最終版か
  • 確認用か、提出用か
  • いつの版か（日付や版番号を入れる）

入れる文字の例

  • 「DRAFT」（ボタンで入る）
  • 「確認用」
  • 「第2版 2026/10/20」
  • 「修正前」「修正後」

最終版には、透かしを入れない、または「提出用」を入れる、と決めておくと、はっきり区別できます。

手順

  1. 下書きのPDFを、「PDFを選ぶ」で選びます。
  2. 「透かしの文字」で「DRAFT」ボタンを押すか、「確認用 第2版」などを入れます。
  3. 「入れ方」は「中央に大きく1つ」、「向き」は「斜め」、「色」は「赤」か「グレー」、「濃さ」は「薄い」にします。
  4. 「入れるページ」は「すべてのページ」にします。
  5. 「透かしを入れる」で確認して保存します。
最終版のPDFに、DRAFTの透かしが残っていないか、提出前に確認します。

ファイル名も合わせて

透かしだけでなく、ファイル名にも版を入れると、さらに確実です。

  • 報告書_v2_確認用.pdf
  • 報告書_最終版.pdf

版を間違えないコツ

  • 下書き用と最終用のフォルダを分ける
  • 古い版を、別のフォルダに移す
  • 日付や版番号を、ファイル名と透かしの両方に入れる
  • 提出前に、最終版かどうか、見て確認する

例

チームで確認する資料：赤、薄い、斜めで「確認用」を入れて共有。承認後、透かしなしの最終版を作る。

つまずきやすい点

  • 透かしのない元のファイルを探せない：下書き用の透かし入りは、元のファイルとは別名で保存します。
  • 最終版にDRAFTが残った：元のPDFから、作り直します。
  • 透かしが邪魔で読みにくい：薄いグレー、小さめにします。

よくある質問

透かしを後から消すには？

保存したPDFから消すのは難しいため、元のPDF（透かしを入れる前）を残しておきます。

複数人で共有するときは？

透かし入りを共有し、元のファイルは自分で保管します。

まとめ

下書きには「DRAFT」、最終版には何も入れない。ファイル名にも版を入れて、取り違えを防ぎましょう。

PDFに透かし文字を入れるを使う（無料）

あわせて使えるツール

  • PDFにページ番号を追加：PDFの各ページに、ページ番号を入れます。位置や形式を選べます。
  • PDFを圧縮：PDFを、指定したサイズ以下に小さくします。提出先の容量制限に合わせたいときに。
  • PDFを結合：複数のPDFを、順番を決めて1つのPDFにまとめます。

この解説が役に立ったら、応援してもらえるとうれしいです。

  • 透かし文字の例と使い分け：提出用・コピー・社外秘・見本・DRAFT
  • 身分証・契約書のコピーに透かしを入れる：悪用を防ぐ工夫
  • PDFの透かしでできること・できないこと

Marking Drafts and Review Copies with DRAFT to Avoid Version Mix-ups

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Put "DRAFT" or "Proposal" on every page
  • Put the version and date in the file name too
  • Use the unwatermarked original for the final

A second edition of meeting materials, a draft contract, a report for review. With multiple versions, it becomes unclear which is the latest or final one, which leads to accidents. Adding a watermark such as "DRAFT" with Add a Text Watermark to PDF makes it easier to avoid mixing up versions.

What a watermark can distinguish

  • Draft (DRAFT) or final version
  • For review or for submission
  • Which version it is (include a date or version number)

Examples of text

  • "DRAFT" (filled in by the button)
  • "For review"
  • "Edition 2, 2026/10/20"
  • "Before revision", "After revision"

If you decide that the final version gets no watermark, or "For submission", the distinction is clear.

Steps

  1. Choose the draft PDF with "Choose a PDF".
  2. In "Watermark text", press the "DRAFT" button, or enter something like "For review, edition 2".
  3. Set "Placement" to "One large in the centre", "Direction" to "Diagonal", "Color" to "Red" or "Gray" and "Strength" to "Light".
  4. Set "Pages" to "All pages".
  5. Check with "Add watermark" and save.
Before submitting, check that no DRAFT watermark remains on the final PDF.

Match it with the file name

Putting the version in the file name as well as the watermark is more reliable.

  • Report_v2_for_review.pdf
  • Report_final.pdf

Tips for not mixing up versions

  • Separate folders for drafts and finals
  • Move old versions to another folder
  • Put the date or version number in both the file name and the watermark
  • Check before submitting that it is the final version

Example

Material for team review: share it with "For review" in red, light, diagonal. After approval, make the final version without a watermark.

Common stumbling blocks

  • You cannot find the original without a watermark: save the watermarked draft under a different name from the original.
  • DRAFT remained on the final version: remake it from the original PDF.
  • The watermark gets in the way of reading: use light gray and smaller.

Frequently asked questions

How do I remove the watermark later?

It is hard to remove from a saved PDF, so keep the original PDF (before the watermark).

What about sharing with several people?

Share the watermarked one and keep the original yourself.

Summary
