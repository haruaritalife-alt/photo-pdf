Wi-FiのQRコードの作り方：パスワードを打たずに接続してもらう

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • Wi-Fiの名前とパスワードを入れる
  • 暗号化の種類を、ルーターの設定に合わせる
  • 来客用のWi-Fiを使うと、より安全

友だちが家に来たとき、お店でお客さんに、会議室で。Wi-Fiのパスワードを何度も伝えるのは大変です。QRコードにしておけば、スマホのカメラで読み取るだけで接続してもらえます。QRコードを作成（URL・Wi-Fi） の「Wi-Fi」で作れます。

手順

  1. 「何を入れますか」で「Wi-Fi」を選びます。
  2. 「Wi-Fiの名前（SSID）」を入れます。
  3. 「パスワード」を入れます。
  4. 「暗号化の種類」を選びます。「WPA / WPA2 / WPA3」「WEP」「なし / None」から選びます。
  5. 隠れたWi-Fiの場合は、「ステルス（非公開）」の「非公開のWi-Fi」を選びます。
  6. 「見た目・設定」を決めて、「QRコードを作る」を押します。
  7. プレビューを確認し、保存して、印刷するか、画面で見せます。
Wi-Fiの名前を入れないと、「Wi-Fiの名前（SSID）を入れてください。」と表示されます。

暗号化の種類の選び方

  • ルーターの設定画面や、本体のシールで、確認できます。
  • 最近のルーターは、ほとんどが「WPA / WPA2 / WPA3」です。
  • 古い機器は「WEP」の場合があります。
  • パスワードがないWi-Fiは「なし」。ただし、誰でも使えてしまうので、注意が必要です。

注意：印刷して貼るとき

パスワードがQRコードに含まれます。貼った場所に来た人は誰でも、そのWi-Fiに接続できます。

  • 来客専用のWi-Fi（ゲスト用）を使うと、安全です。
  • 家庭内のWi-Fiのパスワードを、貼り出すのは避けます。
  • パスワードを変えたら、QRコードも作り直します。

例

自宅の来客用Wi-Fi：名前（SSID）とパスワードを入れ、「WPA / WPA2 / WPA3」を選んで、A4に印刷して玄関に置く。

つまずきやすい点

  • 接続できない：SSIDやパスワードの大文字小文字、記号の間違いを確認します。
  • 暗号化の種類が違う：ルーターの設定で確認します。
  • 読み取れない：サイズや余白を確認します。別の解説で説明しています。

よくある質問

入力したパスワードは、送られますか？

送られません。ブラウザの中で処理されます。

使う前に確認が必要？

はい。自分のスマホで読み取って、接続できるか確認します。

まとめ

SSID、パスワード、暗号化の種類を入れるだけ。貼る場所と、ゲスト用Wi-Fiの使い分けに気をつけましょう。

Making a Wi-Fi QR Code So Guests Can Connect Without Typing

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Enter the Wi-Fi name and password
  • Match the security type to your router
  • A guest network is safer

When a friend visits, when customers come to your shop, in a meeting room. Telling people the Wi-Fi password again and again is tiring. If you turn it into a QR code, people can connect just by scanning it with a phone camera. You can make one with the "Wi-Fi" option of Create a QR Code (URL, Wi-Fi).

Steps

  1. Under "What to put in", choose "Wi-Fi".
  2. Enter the "Wi-Fi name (SSID)".
  3. Enter the "Password".
  4. Choose the "Security": "WPA / WPA2 / WPA3", "WEP" or "None".
  5. For a hidden Wi-Fi, choose "Hidden Wi-Fi" under "Stealth (hidden)".
  6. Decide the "Look and settings" and press "Make QR code".
  7. Check the preview, save, and print it or show it on a screen.
If you leave the Wi-Fi name empty, it says "Enter the Wi-Fi name (SSID)."

Choosing the security type

  • You can check it on the router's settings screen or the label on the unit.
  • Most recent routers use "WPA / WPA2 / WPA3".
  • Old equipment may use "WEP".
  • A Wi-Fi with no password is "None", but anyone can use it, so be careful.

Caution: when you print and stick it up

The password is contained in the QR code. Anyone who comes to the place where it is posted can connect to that Wi-Fi.

  • Using a guest-only Wi-Fi is safer.
  • Avoid posting the password for your home network.
  • If you change the password, make the QR code again.

Example

A home guest Wi-Fi: enter the name (SSID) and password, choose "WPA / WPA2 / WPA3", print on A4 and put it by the entrance.

Common stumbling blocks

  • It will not connect: check the SSID and password for capital letters and symbols.
  • The security type is wrong: check in the router's settings.
  • It will not scan: check the size and margins. Explained in a separate guide.

Frequently asked questions

Is the password I enter sent anywhere?

No. It is processed in the browser.

Do I need to check before using it?

Yes. Scan it with your own phone and check that it connects.

Summary

Just enter the SSID, password and security type. Take care where you post it, and separate guest Wi-Fi.
