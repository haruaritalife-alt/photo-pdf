写真をA4サイズのPDFにする方法

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • 提出先がA4指定なら、ページの大きさを「A4」にする
  • 写真は、A4の中に収まるよう自動で配置される
  • 余白は、読みやすさと文字の大きさのバランスで選ぶ

書類の提出では、「A4サイズのPDF」と指定されることがよくあります。写真から作るPDFも、設定ひとつでA4にそろえられます。

「A4」と「写真と同じ大きさ」の違い

  • A4：どの写真も、A4の用紙1枚に収まるように配置されます。縦横の比率が違う写真は、余白ができます。
  • 写真と同じ大きさ：写真のサイズがそのままページの大きさになります。ページごとに大きさが変わることがあります。

提出先が「A4」や「印刷して使う」と書いているなら、「A4」を選ぶのが安全です。

余白は「なし」か「少し」か

余白「なし」だと、写真をできるだけ大きく入れられるので、小さな文字も読みやすくなります。印刷されたときに端が切れるのが心配なら、「少し」を選びます。

手順

  1. 「写真をPDFにする」を開き、写真を選びます。
  2. ページの大きさで「A4」を選びます。
  3. 余白を選び、「PDFにする」を押して保存します。

提出前の確認

  • PDFを開いて、ページの大きさが揃っているか見る
  • 端の文字が欠けていないか見る
  • ファイルが重いときは、画質を「軽め」にするか、サイズを指定する
提出先に「A4・縦」などの細かい指定があるときは、その指定を優先してください。
写真をPDFに変換を使う（無料）

あわせて使えるツール

  • PDFを圧縮：PDFを、指定したサイズ以下に小さくします。提出先の容量制限に合わせたいときに。
  • PDFのページを回転・並べ替え：向きが違うページを直す、ページの順番を入れ替える、いらないページを消す。
  • PDFを結合：複数のPDFを、順番を決めて1つのPDFにまとめます。

How to Make a PDF from Photos at A4 Size

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • If A4 is required, set the page size to "A4"
  • Photos are placed automatically to fit inside A4
  • Choose margins by balancing readability and text size

When submitting documents, you are often asked for an "A4 PDF". A PDF made from photos can be set to A4 with one option.

"A4" vs "Same as photo"

  • A4: every photo is placed to fit on one A4 page. Photos with a different aspect ratio leave margins.
  • Same as photo: each page takes the size of its photo, so page sizes can differ.

If the recipient says "A4" or plans to print it, "A4" is the safe choice.

Margins: none or small

With "None" the photo can be as large as possible, which helps small text stay readable. If you worry about edges being cut when printed, choose "Small".

Steps

  1. Open "Photos to PDF" and choose your photos.
  2. Choose "A4" for the page size.
  3. Choose the margin, tap "Make PDF" and save.

Before submitting

  • Open the PDF and check that the pages are the same size
  • Make sure no text at the edges is cut off
  • If the file is heavy, set quality to "Small file" or set a size limit
If the recipient gives detailed rules such as "A4, portrait", follow them first.
