Convertire una tabella Markdown per Excel

Quando vuoi modificare una tabella Markdown in Excel.

Come usare

  1. Incolla una tabella Markdown nel campo in alto.
  2. Subito sotto compare una tabella pronta per Excel.
  3. Copia il risultato e incollalo in Excel o in Fogli Google.

Come funziona

  • La riga separatrice (---) di una tabella Markdown viene rimossa automaticamente.
  • Il risultato è separato da tabulazioni, quindi si divide in celle quando lo incolli.

Note

  • Un | scritto come \| dentro una cella viene trattato come un carattere.
  • Le righe con meno colonne vengono completate con celle vuote.
