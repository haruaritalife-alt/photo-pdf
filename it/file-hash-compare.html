Come verificare un file scaricato

Pubblicato: 19 ott 2026 | Aggiornato: 19 ott 2026 | Informazioni (in giapponese)

Punti chiave
  • Controlla
  • Incolla
  • Conferma

Sites that distribute software and files sometimes publish hash values so you can check that a downloaded file is correct. "Compare" in Check a File's Hash (SHA-256) can check them.

Passaggi

  1. With "Choose one file", choose the downloaded file.
  2. The hash (SHA-256) is displayed.
  3. Paste the value published by the distributor into "Value to compare".
  4. Premi «Confronta».
  5. If they match, it is the same file. If different, "No match" is shown.
Copy the distributor's value from the official page. Values from other sites may not be trustworthy.

Flow of comparison

  1. Find the SHA-256 value on the distributor's official page.
  2. Download the file.
  3. Choose the file in this tool.
  4. Paste the official value and press "Compare".

Causes of a mismatch

  • Incomplete download: the connection was cut partway. Download again.
  • Chose another file: check you haven't mixed up files with similar names.
  • Another version: the published value is for a different version.
  • Possible tampering: if you got it from somewhere other than the official source.
  • Different value format: comparing with a SHA-1 or MD5 value.

Cautions when pasting the value

  • Whether blanks got in before or after
  • Whether line breaks got in the middle
  • Case is not distinguished

What to do on a mismatch

  1. Download again and retry.
  2. If it still doesn't match, don't use that file.
  3. Contact the official support.

Esempio

Downloaded an OS installer file and compared it with the official SHA-256. It matched, so it could be used with peace of mind.

Common stumbling blocks

  • The official page and download source differ: even on mirror sites, the value should be the same.
  • Cannot find a value: if not published, it cannot be compared.

Frequently asked questions

If they match, is it safe?

It confirms it is the same file. But you must take care that the official value itself came from a trustworthy place.

Riepilogo

Paste the official value and compare. If it doesn't match, don't use it; fetch it again.
