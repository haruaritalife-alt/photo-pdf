Come mettere il titolo del documento su ogni pagina di un PDF

Pubblicato: 19 ott 2026 | Aggiornato: 19 ott 2026 | Informazioni (in giapponese)

Punti chiave
  • Scrivi il titolo nell'intestazione
  • Scegli una dimensione del testo
  • Salva

For a multi-page document, putting the document title on every page is kind, so that whichever page you look at, you can tell what document it is. Even if pages get separated, the original document is clear. With Add a Header and Footer to a PDF you can put the document title on every page.

Passaggi

  1. Scegli il PDF con «Scegli un PDF».
  2. Under "Decide the text", enter the document title at "Header (top left)".
  3. Choose the "Text size" and "Distance from edge".
  4. If needed, put the date or page number at other positions.
  5. Press "Add text and create PDF" and check the "Preview".
  6. Save with "Save PDF".
The added text goes in as an image (it cannot be selected or searched).

Examples of titles

  • Header (top left): "FY2026 Business Plan"
  • Header (top left): "Service Agreement (draft)"
  • Header (centre): "Report, 3rd edition"
  • Footer (bottom left): "X Co., Ltd."

Benefits of putting the title in

  • Even a single stray page shows what document it belongs to
  • Easy to sort when several documents get mixed
  • Prevents mix-ups when copying or faxing

Length of text

A long title may not fit the page width.

  • Keep it short and concise
  • If long, set the text size to "small"
  • Check in the preview that it does not overflow

Which position for what

Title: header (top left) is common. Page number: footer. Date: header (top right).

Not on the cover

If the title is already written large on the cover, choose "Not on page 1" under "Pages to skip".

Combining the title with a version

You can combine it with the date symbol, as in "Report, {date} edition".

Esempio

For a PDF combining several documents, you want the title only on the first page of each. → This tool puts the same text on all pages. Run it on a PDF split by document, then merge.

Common stumbling blocks

  • The title overflows: shorten the text or reduce the size.
  • It overlaps the body: increase the distance from the edge.
  • You want a different title per page: this tool uses text common to all pages. Run it per document.

Frequently asked questions

Can I use an English title?

Yes.

Can I change the title later?

Before saving, you can fix the text and make it again. For a saved PDF, start again from the original PDF.
