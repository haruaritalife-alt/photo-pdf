Comment ouvrir un ZIP sur téléphone (gratuit)

Publié le 19 oct. 2026 | Mis à jour le 19 oct. 2026 | À propos (en japonais)

Points clés
  • Choisissez
  • Regardez
  • Enregistrez

A ZIP file arrived on your phone but you don't know how to open it. Open a ZIP File (Unzip) lets you see inside a ZIP and extract the files you need. The ZIP's contents are opened inside this device. Nothing is sent anywhere.

Étapes

  1. Press "Choose one ZIP file" and choose the ZIP to open.
  2. "See contents" shows the list of files in the ZIP.
  3. Press "Save" next to the file you want to extract.
  4. To open another ZIP, press "Choose another ZIP".
Password-protected ZIPs are not supported. When a password is needed, open them with your OS's features or an app.

Convient pour

  • Opening a ZIP received on a phone
  • Viewing a set of materials from work or school
  • Extracting only the files you need
  • A computer with no unzip software

What a ZIP is

A file that bundles several files into one. The extension is ".zip". It is often used for email attachments and download distribution.

Using the extracted files

Saved files can be used as ordinary files. A PDF opens in a viewing app, a photo in the gallery.

Exemple

Event photos arrived on a phone as a ZIP. Choosing the ZIP showed 20 photos lined up. Saved only the three I liked.

Common stumbling blocks

  • "This ZIP is empty." appears: no files are inside the ZIP. Check with the sender.
  • "Could not extract this file." appears: the file may be corrupted.
  • File names are garbled: occurs with ZIPs made by old software. The contents are often not broken.

Frequently asked questions

Is the ZIP sent anywhere?

No. It is opened inside the browser.

Can I extract all files at once?

Save them one at a time from the list.

En résumé

Choose the ZIP and save the files you need. Open password-protected ones by another method.
