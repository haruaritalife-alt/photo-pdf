Créer un code QR

Transformez une URL ou des informations Wi-Fi en code QR. Enregistrez en PNG, SVG ou PDF.

Ce que vous saisissez n'est jamais téléversé. Le code QR est créé sur cet appareil.

Quoi encoder
Si une URL n'a pas de https://, comme « example.com », il est ajouté automatiquement.
Réseau masqué

Apparence et réglages

Inclus dans le PNG et le PDF, pas dans le SVG.
Terminé

🔒 Vos fichiers ne sont jamais envoyés à un serveur externe. Tout est traité en toute sécurité dans ce navigateur.

Mode d'emploi

  1. Choisissez « URL / texte » ou « Wi-Fi ».
  2. Saisissez l'URL ou le texte. Pour le Wi-Fi, saisissez le nom (SSID) et le mot de passe.
  3. Choisissez la couleur, la taille de l'image et la correction d'erreur. Dans le doute, laissez les valeurs par défaut.
  4. Touchez « Créer le code QR » et enregistrez en PNG, SVG ou PDF.
  5. Avant de l'utiliser, scannez-le avec l'appareil photo d'un téléphone pour vérifier.

Remarques

  • Attention aux fautes de frappe dans l'URL. Ouvrez d'abord l'URL pour la vérifier.
  • Un texte long rend le motif dense et plus difficile à scanner.
  • À l'impression, ne rognez pas la marge blanche autour.

FAQ

Ce que je saisis est-il téléversé quelque part ?

Non. Le code QR est créé uniquement dans le navigateur de votre appareil.

Expire-t-il ?

Non. Le code QR créé ici est simplement un motif de ce que vous avez saisi. Mais si la page liée disparaît, elle ne s'ouvrira plus.

Puis-je changer la couleur et le scanner quand même ?

Oui, si le fond est blanc et le motif foncé. Une couleur claire le rend difficile à scanner.
