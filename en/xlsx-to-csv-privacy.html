Is My Excel File Uploaded?

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Check
  • Use

Converting an Excel file you don't want to put outside, such as a customer list or pay table, is worrying. Convert Excel to CSV or JSON converts Excel files inside the browser without sending them outside.

How it works

  • The Excel file you choose is loaded only inside your browser.
  • The conversion also happens on your device.
  • Neither the file nor the result is sent to a server or stored.

Steps

  1. With "Choose one .xlsx Excel file", choose the file.
  2. Choose the "Sheet" and "Format".
  3. Use the result with "Copy result" or "Save as file".
The file is read inside this device. It is sent nowhere.

How to confirm

  • It can convert even with the connection cut (airplane mode).
  • Browser developer tools can confirm that no file is sent.

Still be careful about

  • The CSV or JSON made: a text file with no password. Mind where it's kept and how widely it's shared.
  • Shared computers: when finished, delete the files.
  • Cloud-synced folders: check that the save location isn't uploaded automatically.
  • Clipboard: copied content stays in the clipboard. When finished, overwrite it with other text.

When handling Excel with personal information

  • Narrow to only the needed columns before converting
  • Delete the converted file once the purpose is done
  • When sharing, use a password-protected ZIP or PDF

Excel passwords

Password-protected Excel files can't be opened with this tool. Remove the password before converting.

Uses it suits

  • Making data to import a customer list into a system
  • Processing in-house HR and pay data
  • Converting rosters containing personal information

Example

Wanted to turn a member roster Excel into CSV to import into another system. Did not want to upload it to an outside service, but since it is processed in the browser, it could be used with peace of mind.

Common stumbling blocks

  • The result disappeared when closing the page: by design nothing is saved. Save if needed.
  • Heavy with large Excel files: depends on the device's memory.
