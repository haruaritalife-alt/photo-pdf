How to use

  1. Tap "Choose an Excel file" and select an .xlsx file.
  2. Choose the sheet and the format (HTML table or Markdown table).
  3. Copy the result or save it as a file.

How it works

  • Turns an Excel sheet into an HTML table or a Markdown table.
  • Handy for pasting a table into a blog, a README or an email.
  • You can choose whether the first row is the header.

Notes

  • Old .xls files and password-protected files cannot be opened.
  • Colors and borders are not carried over. Only the text becomes the table.
  • Sheets with more than 5000 rows cannot be converted.

FAQ

Are my files uploaded anywhere?

No. Everything is processed inside the browser on your device.

What happens to merged cells?

In a merged cell only the top-left cell keeps its text; the others are left empty.
