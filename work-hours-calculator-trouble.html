うまくいかないときの対処法

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • ファイルを確認する
  • 大きさを確認する
  • 別の端末で試す

勤務時間の計算が、うまくいかない。勤務時間計算（休憩・給与の目安つき） で起こりやすい困りごとと、対処法をまとめます。

よくある困りごと

  • 「開始と終了の時刻を入れてください。」と出る：どちらかの時刻が未入力。両方を入れる。
  • 「休憩が勤務時間より長くなっています。」と出る：休憩の分数が、勤務時間（拘束時間）を超えている。
  • 勤務時間が、思ったより長い・短い：開始・終了の時刻、休憩の分数を見直す。午前と午後の入力ミスが多い。
  • 給与の目安が出ない：時給の欄が空、または0。
  • 日をまたぐ勤務で、おかしい：終了を開始より前の時刻にして入れる。24時間以上は対象外。

手順（うまくいかないとき）

  1. 開始時刻・終了時刻が、正しい時刻か確かめる（午前・午後、24時間表記）。
  2. 休憩の分数を、見直す。
  3. 時給が、数字だけか確かめる。
  4. 入れ直して、結果を確かめる。
時刻の入力は、時刻の選択画面から選ぶと、間違いが減ります。

午前・午後の確認

12時間表記の端末では、午前（AM）と午後（PM）を間違えやすいです。たとえば、「6:00」が午前か午後かで、結果が大きく変わります。

入力の例

  • 正しい：開始 09:00、終了 18:00、休憩 60、時給 1200
  • 正しくない：休憩 1時間（単位を付けている）
  • 正しくない：時給 1,200円（カンマと単位）

勤務時間が0になる

開始時刻と終了時刻が同じだと、0時間になります。24時間の勤務ではありません。

向いている使い方

  • トラブルの事前確認
  • 入力値の確認

例

勤務時間が、思ったより8時間短かった。終了時刻を、午前の「6:00」と入れていたが、午後の「18:00」だった。直すと、正しい時間になった。

つまずきやすい点

  • 全角の数字：半角で入れる。
  • 休憩に「1.5」と入れる：分で入れる（90）。

よくある質問

15分単位に丸めたいときは？

このツールは、丸めを行いません。職場のルールに合わせて、時刻を調整して入れてください。

まとめ

時刻・休憩・時給の3つを見直す。たいていの困りごとは、入力ミスが原因です。

  • 年齢・日数・日付を計算する：年齢や、日付のあいだの日数を計算します。
  • 消費税を計算する（税込・税抜）：税込・税抜の金額を、すぐに計算します。
  • 割合・割引・増減（%）を計算する：割合・割引・増減の%を、すぐに計算します。

What to Do When It Does Not Work

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Check the file
  • Check the size
  • Try another device

Working time calculation isn't working. Here are troubles that commonly occur with Work Hours Calculator (with break and pay) and how to handle them.

Common troubles

  • "Please enter start and end times." appears: one of the times is not entered. Enter both.
  • "The break is longer than the working time." appears: the break minutes exceed the working (on-site) time.
  • Working time is longer/shorter than expected: review start/end times and break minutes. AM/PM entry mistakes are common.
  • No pay estimate appears: the wage field is blank or 0.
  • Odd result for work crossing days: enter the end as a time earlier than the start. 24 hours or more is outside the tool.

Steps (when it doesn't go well)

  1. Check start and end times are the right times (AM/PM, 24-hour notation).
  2. Review the break minutes.
  3. Check the wage is digits only.
  4. Re-enter and check the result.
Choosing times from the time selection screen reduces mistakes.

Checking AM/PM

On devices with 12-hour notation, AM and PM are easy to mix up. For example, whether "6:00" is morning or evening changes the result greatly.

Input examples

  • Correct: start 09:00, end 18:00, break 60, wage 1200
  • Incorrect: break 1 hour (unit attached)
  • Incorrect: wage 1,200 yen (comma and unit)

Working time becomes 0

If start and end times are the same, it's 0 hours. It is not a 24-hour shift.

Uses it suits

  • Pre-checks before trouble
  • Checking input values

Example

Working time came out 8 hours shorter than expected. I had entered the end time as morning "6:00" but it was evening "18:00". Fixing it gave the correct time.

Common stumbling blocks

  • Full-width digits: enter in half-width.
  • Entering "1.5" for the break: enter in minutes (90).

Frequently asked questions

What if I want to round to 15-minute units?

This tool doesn't round. Adjust the times you enter to the workplace's rules.
