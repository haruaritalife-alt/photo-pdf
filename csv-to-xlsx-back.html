ExcelをCSVに戻すには

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • 使う

CSVをExcelにしたあと、やっぱりCSVに戻したくなることがあります。システムへの取り込みには、CSVが必要な場合などです。CSVをExcelファイルにする でつくったExcelは、「ExcelをCSV・JSONに変換」で戻せます。

手順

  1. このツールで、CSVをExcelにして保存し、Excelで編集します。
  2. 編集後のExcelを、「ExcelをCSV・JSONに変換」ツールで、開きます。
  3. 「シート」と「形式」（CSV）を選びます。
  4. 「結果をコピー」か「ファイルで保存」で、CSVにします。
どちらのツールも、ブラウザの中で処理します。データは外に送られません。

この往復が役立つ場面

  • CSVをExcelで編集して、再びCSVに戻して、システムに取り込む
  • 文字化けするCSVを、Excelで整えてから、CSVに戻す
  • 複数のCSVを、Excelでまとめて整える

戻すときの注意

  • 0で始まる数字：Excelで文字のまま保存されていれば、CSVでも保持される。
  • 日付：「2026-10-21」の形で出力される。
  • 計算式：計算結果の値で出力される。
  • 文字コード：システムが指定する文字コードを確認する。

システムが求める形式を確認

取り込み先のシステムが、特定の形式（文字コード、区切り、見出しの有無）を求める場合があります。仕様を確認してから、出力します。

編集のコツ

  • 見出し行は、そのまま残す
  • 不要な書式（色、結合セル）は、CSVに残らない
  • 列の順番や、数は、システムの指定に合わせる

向いている場面

  • 取り込み用データの作成
  • 他のソフトへの移行
  • 編集と確認を、Excelで行う

例

会員システムのCSVを、Excelで修正してから、システムに戻す必要があった。Excelに変換して修正し、再びCSVに変換して、取り込めた。

つまずきやすい点

  • 文字化けする：システム側の文字コードの指定を確認する。
  • 0で始まる数字が消える：Excelでの編集中に、数値に変えていないか確認。

よくある質問

元のCSVと、完全に同じになりますか？

値は同じですが、引用符や、改行コードなど、細かな点が異なる場合があります。

まとめ

CSV → Excel → 編集 → CSV の往復も、ブラウザの中で完結。取り込み先の形式を、確認しましょう。

Turning Excel Back into CSV

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Use

After turning a CSV into Excel, you may want to go back to CSV after all, for example when importing into a system requires CSV. Excel made with Convert CSV to Excel (.xlsx) can be converted back with "Excel to CSV/JSON".

Steps

  1. With this tool, turn the CSV into Excel, save and edit it in Excel.
  2. Open the edited Excel in the "Excel to CSV/JSON" tool.
  3. Choose the "Sheet" and "Format" (CSV).
  4. Make the CSV with "Copy result" or "Save as file".
Both tools process inside the browser. Data is not sent outside.

When this round trip helps

  • Edit a CSV in Excel, return it to CSV and import it into a system
  • Tidy a garbled CSV in Excel, then return it to CSV
  • Tidy several CSVs together in Excel

Cautions when going back

  • Numbers starting with 0: if stored as text in Excel, they are kept in the CSV too.
  • Dates: output in the form "2026-10-21".
  • Formulas: output as the calculated values.
  • Character encoding: check the encoding the system specifies.

Check the format the system requires

The destination system may require a particular format (encoding, delimiter, presence of headings). Check the specification before outputting.

Tips for editing

  • Leave the heading row as it is
  • Unneeded formatting (colours, merged cells) doesn't remain in the CSV
  • Match column order and count to the system's specification

Good for

  • Making data for import
  • Migrating to other software
  • Doing editing and checking in Excel

Example

Needed to fix a membership system's CSV in Excel and return it to the system. Converted to Excel, fixed it, converted back to CSV and could import.

Common stumbling blocks

  • Text garbles: check the system's encoding specification.
  • Numbers starting with 0 vanish: check you didn't turn them into numbers while editing in Excel.

Frequently asked questions

Will it be exactly identical to the original CSV?

The values are the same, but fine points such as quotes and line-break codes may differ.
