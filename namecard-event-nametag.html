イベントの名札・席札を、名簿からまとめて作る方法

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • 「名簿から作る」を選ぶ
  • 1行に1人、「氏名,肩書き」の形で入れる
  • A4で印刷して、名札ホルダーに入れる

参加者が多いイベントでは、名札があると、お互いの名前を覚えやすくなります。

作る手順

  1. 名刺・ネームカードを作成を開きます。
  2. サイズは、「名札（100×70mm）」がおすすめです。文字が大きく入ります。
  3. 「名簿から作る」を選びます。
  4. 上に入れる文字に、イベント名や、サークル名を入れます。
  5. 名簿の欄に、1行に1人ずつ、「氏名,肩書き」の形で入れます。

> 山田 太郎,代表

> 佐藤 花子,会計

> 鈴木 一郎

  1. 色、書体、飾りを選んで、「カードを作る」を押します。

枚数について

  • 1ページに、名札サイズで8枚並びます。
  • 名簿は、60人までです。60人なら、8ページになります。
  • 最後のページは、余った枠が空白になります。

名前の書き方

  • 同じ苗字の人がいるときは、下の名前も入れます。
  • 読みにくい名前には、「ふりがな」を使います（「同じカード」モードで、1枚ずつ作る場合）。

印刷と準備

  • 名札ホルダーに入れる場合は、ホルダーの大きさに合うかを、先に確認します。
  • 厚めの紙を使うと、折れにくくなります。

席札にも使える

折って、机に立てる席札にしたい場合は、中央そろえで作り、印刷したあとに、半分に折ります。

個人情報

名簿に載せるのは、名札に出していい情報だけにします。名札は、人の目に触れるので、メールアドレスなどは、入れないほうが安全です。

名刺・ネームカードを作成を使う（無料）

あわせて使えるツール

  • PDFを圧縮：PDFを、指定したサイズ以下に小さくします。提出先の容量制限に合わせたいときに。
  • 画像の切り抜き・回転：画像を、好きな範囲や比率で切り抜きます。回転もできます。
  • PDFを結合：複数のPDFを、順番を決めて1つのPDFにまとめます。

この解説が役に立ったら、応援してもらえるとうれしいです。

  • 名刺のサイズと、自宅・コンビニで印刷して切るコツ
  • 学生・サークルの名刺に書く内容と、載せすぎない注意点
  • 見やすい名刺デザインのコツ：文字の大きさ・色・余白

How to Make Event Name Tags in Bulk from a List

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Choose "From a list"
  • Enter one person per line as "name,title"
  • Print on A4 and put them in tag holders

At events with many participants, name tags help people remember each other's names.

Steps

  1. Open Create Business Cards / Name Cards.
  2. Choose the "Name tag (100×70 mm)" size. The text is larger.
  3. Choose "From a list".
  4. Enter the event or club name in the top text.
  5. In the list, enter one person per line as "name,title".

> Taro Yamada,President

> Hanako Sato,Treasurer

> Ichiro Suzuki

  1. Choose color, typeface and accent, then tap "Create cards".

About the count

  • 8 name tags fit on a page.
  • The list can have up to 60 people, which is 8 pages.
  • On the last page, leftover slots stay blank.

Writing names

  • If two people share a family name, include the given name too.
  • For hard-to-read names, use the reading field (in "Same card" mode, one card at a time).

Printing and preparing

  • If you use tag holders, check that the size fits first.
  • Thicker paper resists bending.

Also usable as place cards

To make a folded card that stands on a table, make it centered, print it and fold it in half.

Personal information

Put in the list only what is fine to show on a tag. Tags are seen by others, so it is safer not to include things like email addresses.
