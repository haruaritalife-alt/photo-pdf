Paano Kopyahin at Kunin ang Text mula sa PDF

Nailathala: Okt 19, 2026 | Na-update: Okt 19, 2026 | Tungkol (Japanese)

Mahahalagang punto
  • Pumili ng PDF at i-tap ang “Kumuha ng text”
  • Kopyahin ang text o i-save bilang .txt
  • Walang text na makukuha sa mga PDF na larawan lang

You want to copy the text from a PDF into a note or email. Some PDFs are hard to select from and it takes effort. Extract Text from PDF extracts the text contained in a PDF all at once, and lets you copy it or save it as a text file (.txt). Processing happens on your device and the PDF is never sent anywhere.

Mga hakbang

  1. With "Choose PDF", pick one PDF.
  2. Choose "Page separators": "Include" or "Do not include".
  3. Press "Extract text".
  4. The "Extracted text" appears.
  5. Press "Copy" to copy it, or save it with "Save as text file (.txt)".
Line breaks and order may differ from the original PDF. Check the content before using it.

PDFs it can and cannot read

  • Can extract: PDFs exported from Word or PowerPoint, which hold text as text. Web pages turned into PDFs.
  • Cannot extract: PDFs made by simply scanning paper (image PDFs). The text is also an image, so it cannot be extracted.

About "Page separators"

  • Include: a page-number separator is placed before each page, making it clear which page the text came from.
  • Do not include: the text runs together. Suits copying and using as it is.

When it is useful

  • You want to quote text from a document in a note or report
  • You want to run the PDF's content through search or translation
  • You want to save a long text as plain text
  • You want to paste the PDF's content into another app

Tidying afterwards

  • Line breaks may fall in unnatural places. Fix them if needed.
  • With tables or multiple columns, the order may be mixed up.
  • Headers and footers may come out together with the body.

Common stumbling blocks

  • No text comes out: it may be an image PDF. See the separate guide.
  • The text is garbled: depending on how the PDF holds its text, it may not be readable.
  • Password-protected PDF: not supported. Remove the password first.
