Paano gamitin

  1. Ilagay ang cell na gusto mong i-convert.
  2. Pumili ng format o isulat ang sarili mo.
  3. Kopyahin ang TEXT formula at i-paste ito sa isang cell.

Paano ito gumagana

  • Maaari kang pumili mula sa mga karaniwang format tulad ng petsa, oras, thousands separator at leading zero.
  • Maaari mo ring i-edit ang format code mismo.

Mga tala

  • Teksto ang resulta ng TEXT, kaya hindi ito direktang magagamit sa mga kalkulasyon.
  • Maaaring bahagyang magkaiba ang mga code tulad ng sa mga araw ng linggo sa pagitan ng Excel at Google Sheets.
