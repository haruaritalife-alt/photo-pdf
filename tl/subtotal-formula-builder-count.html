Pagbibilang ng mga nakikitang hilera

Nailathala: Okt 19, 2026 | Na-update: Okt 19, 2026 | Tungkol (Japanese)

Mahahalagang punto
  • Piliin ang COUNTA
  • Ilagay ang saklaw
  • Kopyahin

How many rows remain after filtering? To count visible rows, choose "COUNTA" or "COUNT" in Build a SUBTOTAL Formula.

Mga hakbang

  1. Choose "COUNTA" or "COUNT" in "Type".
  2. In "Range", enter the column to count.
  3. Copy the formula and paste.
COUNTA counts non-empty cells. COUNT counts only numeric cells.

Halimbawa

  • =SUBTOTAL(3,A2:A100): non-empty cells in visible rows (COUNTA)
  • =SUBTOTAL(2,B2:B100): numbers in visible rows (COUNT)

Averages and maxima too

  • AVERAGE: =SUBTOTAL(1,B2:B100)
  • MAX: =SUBTOTAL(4,B2:B100)
  • MIN: =SUBTOTAL(5,B2:B100)

Mabuti para sa

  • The matching count after narrowing
  • Showing "N hits"
  • The average score or top amount of filtered rows

Showing the count

Combine with text to display "N items".

  • Example: =SUBTOTAL(3,A2:A100)&" items"

Leave out the header row

Including the header (A1) in the range counts one extra. Start from the data rows.

Halimbawa

Filtered a roster and wanted to know how many people matched. COUNTA on the name column gave only the visible count.

Common stumbling blocks

  • The overall count appears: a plain COUNTA is used instead of SUBTOTAL.
  • Zero numbers: COUNT doesn't count text numbers. Use COUNTA.

Frequently asked questions

I want to count blank cells too

You can get the row count with ROWS, but it doesn't follow filters.

Buod

For the visible count, use SUBTOTAL(3,…).
