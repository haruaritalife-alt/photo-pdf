Paano Nananatili sa Device Mo ang mga File Mo

Kapag binuksan mo ang isang pahina, nilo-load sa browser mo ang program ng tool. Binabasa lang ang mga file na pipiliin mo sa memorya ng browser, doon kino-convert o ine-edit, at sine-save sa device mo. Sa buong prosesong ito, hindi kailanman ipinapadala sa server sa internet ang laman ng mga file mo. Kaya magagamit mo ito para sa mga dokumentong ayaw mong mawala sa iyong kamay, gaya ng résumé at mga sertipiko.

Nasa pahina ng Tungkol sa / Makipag-ugnayan ang mga detalye ng operator at contact (sa Japanese).

FAQ

Talaga bang hindi ina-upload ang mga file ko?

Oo. Sa loob lang ng browser mo tumatakbo ang conversion at pag-edit, at hindi ipinapadala ang mga file sa anumang server. Sa computer, maaari mong buksan ang tab na “Network” ng developer tools habang gumagamit ng tool para kumpirmahing walang request na may dala ng file mo.

Libre ba ito? Kailangan bang magparehistro?

Libre ang lahat at hindi kailangan ng pagpaparehistro o pag-log in. Magbukas lang ng pahina ng tool at gamitin ito.

Gumagana ba ito sa mga telepono (iPhone at Android)?

Oo. Buksan ito sa browser ng telepono mo (Safari, Chrome at iba pa), pumili ng mga file, magproseso at i-save. Ganito rin ito gumagana sa computer.

May limitasyon ba sa laki o bilang ng mga file?

Walang itinakdang limitasyon ang site, pero dahil sa device mo ginagawa ang pagproseso, nakadepende ito sa device mo. Bilang magaspang na gabay lang, sa telepono, karaniwang matatag ang mga PDF hanggang ilang sampung MB o mga pahina at mga 20–30 larawan nang sabay. Lampas pa roon, maaaring bumagal o huminto. Sa ganoong kaso, subukan muli sa ilang mas maliliit na batch.

Hindi ba nababago ang orihinal kong file?

Nananatili ang orihinal mong file. Sine-save ang resulta bilang bagong file. Ang paggamit ng compression o limitasyon sa laki ay maaaring magpababa ng kalidad o gawing hindi napipili ang text ng PDF.

Magagamit ko ba ang mga PDF na may password?

Hindi. Pakialis muna ang password.

Kailangan ko bang mag-tip para magamit ang mga tool?

Hindi. Libre at walang limitasyon ang lahat ng tool. Ganap na opsyonal ang tip (¥300), kung nakatulong lang sa iyo ang site.
