JPEGとPDFの違いと、どちらで提出すべきか

この記事のポイント
  • 複数ページの書類は、PDFが向いている
  • 提出先の指定があれば、それに従う
  • JPEGからPDFへは、ツールで変換できる

写真や書類を提出するとき、「JPEGでいいの？ PDFにするの？」と迷うことがあります。2つの違いと、選び方をまとめます。

JPEGとは

  • 写真などの画像を保存する形式で、1枚が1つのファイルになります。
  • スマホで撮った写真は、多くの場合、JPEG（または、それに近い形式）で保存されます。
  • 画像として開くので、手軽に見られます。

PDFとは

  • 書類を、見た目そのままで保存する形式です。
  • 複数のページを、1つのファイルにまとめられます。
  • パソコンやスマホが違っても、同じレイアウトで表示されやすいです。
  • 印刷や、提出に向いています。

違いのまとめ

JPEGPDF
ページ数1枚ずつ別のファイル複数ページを1つにまとめられる
向いている用途写真・画像の共有書類の提出・保管
複数枚の受け渡し枚数ぶんのファイルを送る1つのファイルで送れる

どちらで提出すべきか

  • 提出先がPDFを指定している：必ずPDFにする。
  • 複数ページの書類を出す：PDFにまとめると、1つのファイルで渡せる。
  • 写真1枚だけでよい（証明写真など）：JPEGなど、指定された形式に従う。

迷ったときは、提出先の案内を確認するのがいちばん確実です。

JPEG vs. PDF: Which Should You Submit?

Key points
  • PDF suits documents with several pages
  • If the recipient specifies a format, follow it
  • You can convert JPEG to PDF with a tool

When submitting photos or documents, you may wonder: "Is JPEG fine, or should I make a PDF?" Here are the differences and how to choose.

What is JPEG?

  • It is a format for saving images such as photos, and each image is its own file.
  • Photos taken with a phone are usually saved as JPEG (or something close to it).
  • It opens as an image, so it is easy to view.

What is PDF?

  • It is a format that saves a document looking exactly as it is.
  • It can combine several pages into one file.
  • It tends to display with the same layout on different computers and phones.
  • It suits printing and submission.

Summary of the differences

JPEGPDF
PagesSeparate file for each imageSeveral pages in one file
Best forSharing photos and imagesSubmitting and keeping documents
Sending severalOne file per imageOne file is enough

Which should you submit?

  • The recipient asks for PDF: Make it a PDF.
  • Submitting a multi-page document: Combine it into a PDF and hand over one file.
  • Only one photo is needed (such as an ID photo): Follow the specified format, such as JPEG.

When in doubt, checking the recipient's instructions is the surest way.
