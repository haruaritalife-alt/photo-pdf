PDFから文字が取り出せないときの原因（スキャンPDFとは）

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • 紙をスキャンしたPDFは、中身が画像で、文字データがない
  • 文字を選択できるかで見分けられる
  • 必要なら、文字認識（OCR）を使う

「文字が見つかりませんでした」と出たときは、次のことが考えられます。

原因：画像だけのPDF

プリンターのスキャンや、スマホのカメラで撮った書類は、PDFの中身が「画像」です。見た目は文字でも、文字データがないため、取り出せません。

見分け方

PDFを開いて、文字を指でなぞったり、マウスでドラッグしたりして、選択できるか試します。選択できなければ、画像のPDFです。

対処法

  • 元のファイルがあるとき：Wordなどの、元のファイルから、PDFを作り直す
  • どうしても文字が必要なとき：文字認識（OCR）という技術が必要です。このツールには、OCR機能はありません。

補足

OCRは、読み取りのミスが出ることがあります。使うときは、結果を、必ず目で確認してください。

PDFから文字を抜き出すを使う（無料）

あわせて使えるツール

  • PDFを画像に変換：PDFの各ページを、JPEGまたはPNGの画像として保存します。
  • PDFのページを抜き出し・削除：PDFから、必要なページだけを残す、または不要なページを消します。
  • PDFを圧縮：PDFを、指定したサイズ以下に小さくします。提出先の容量制限に合わせたいときに。

Why Text Can't Be Extracted from a PDF (Scanned PDFs)

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Scanned PDFs are images with no text data
  • Whether you can select text tells you which it is
  • Use OCR (text recognition) if needed

If you see "No text was found", the following may be the case.

Cause: an image-only PDF

Documents scanned on a printer or photographed with a phone camera have images inside the PDF. They look like text but have no text data, so it can't be extracted.

How to tell

Open the PDF and try selecting text by dragging a finger or the mouse. If you can't, it is an image PDF.

What to do

  • If you have the original file: remake the PDF from the original, such as in Word
  • If you really need the text: you need a technology called OCR (text recognition). This tool has no OCR feature.

Extra note

OCR can make reading errors. Always check results by eye.
