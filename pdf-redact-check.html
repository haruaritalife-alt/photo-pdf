黒塗りできたか確認する方法：選択・検索・別のソフトで開く

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • 黒塗りの上を、なぞって選択する
  • 隠した言葉を、検索する
  • 別のアプリでも開いて確かめる

黒塗りしたつもりでも、本当に消えているかは、見た目だけでは分かりません。PDFの一部を黒塗りする で保存したPDFを、確かめる方法をまとめました。

確認の4つの方法

1. 黒塗りした部分を、選択してみる

PDFを開いて、黒塗りした部分を、なぞって選択します（スマホは長押し）。文字が選択できれば、データが残っています。何も選択されなければ、文字データは残っていません。

2. 文字検索をする

PDFの検索機能で、隠したはずの言葉を検索します。ヒットしなければ成功です。

3. 全選択してコピーする

全文を選択して、コピーし、メモ帳などに貼り付けます。隠した言葉が出てこなければ成功です。

4. 別のソフトで開く

ブラウザ、PDFビューア、別の端末など、複数の環境で開いて確認します。

保存したら、開いて、黒塗りの下の文字が選択できないことを確認してください。

確認の手順

  1. 保存したPDFを開く。
  2. 黒塗りした全ページで、選択を試す。
  3. 隠した言葉で検索する。
  4. 全選択のコピーを、メモ帳に貼って確認する。
  5. 問題があれば、元のPDFから、黒塗りをやり直す。

黒塗りしていないページ

このツールは、黒塗りしていないページを、元のデータのまま残します。そのため、黒塗りしていないページには、文字が残っています。隠すべき情報が、黒塗りしていないページにないか確認します。

画質を確認する

黒塗りしたページは画像になるため、文字が少し粗く見えることがあります。読みにくければ、「きれい（200dpi）」で作り直します。

例

氏名を隠したPDFで、氏名を検索する：ヒット0件。選択してみる：選択できない。OKとする。

他に確認したいこと

  • ファイルのプロパティ：作成者名などが残っていないか。
  • ファイル名：氏名が入っていないか。
  • ほかのページ：同じ情報が、別の場所に入っていないか。

つまずきやすい点

  • 選択できてしまった：そのページに、黒塗りが適用されていません。範囲を確認します。
  • 検索でヒットした：黒塗りしていない場所に、同じ言葉があります。
  • 一部のページだけ確認した：全ページを確認します。

よくある質問

スマホでも確認できますか？

できます。長押しで選択を試すか、PDFの検索機能を使います。

確認のあと、元のPDFは？

元のPDFは、手元に残しておき、提出用とは別に保管します。

まとめ

選択、検索、コピー、別の環境で確認。4つの確認を済ませてから、送りましょう。

PDFの一部を黒塗りするを使う（無料）

あわせて使えるツール

  • PDFをグレースケール（白黒）にする：カラーのPDFを、グレースケールか白黒2値にします。白黒印刷や、コピー・FAXの前に。解像度も選べます。
  • PDFのページを抜き出し・削除：PDFから、必要なページだけを残す、または不要なページを消します。
  • PDFを圧縮：PDFを、指定したサイズ以下に小さくします。提出先の容量制限に合わせたいときに。

この解説が役に立ったら、応援してもらえるとうれしいです。

応援する（300円）ほしい物リストで応援

同じツールの、ほかの解説

  • PDFの一部を黒塗りする方法（無料・スマホでもOK）
  • 黒い四角を重ねただけでは危ない：PDFの黒塗りの正しいやり方
  • 提出する前に隠したい情報：PDFで黒塗りを考える場面
  • スキャンや写真のPDFを黒塗りする：画像のPDFの場合
  • 全ページの同じ場所を黒塗りする：ヘッダー・フッター・名前欄
  • PDFを共有する前のチェックリスト：黒塗り・ファイル名・ページ・サイズ

How to Check a Redaction Worked: Select, Search and Open in Another App

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Drag over the black area to select
  • Search for the words you hid
  • Open it in another app too

Even if you think you blacked it out, you cannot tell by looks alone whether it is really gone. Here is how to check a PDF saved with Black Out (Redact) Parts of a PDF.

Four ways to check

1. Try selecting the blacked-out part

Open the PDF and trace over the blacked-out part to select it (long-press on a phone). If text can be selected, data remains. If nothing is selected, no text data remains.

2. Search the text

Use the PDF's search function to look for the word you meant to hide. If it is not found, it worked.

3. Select all and copy

Select all the text, copy it and paste it into a notepad. If the hidden word does not appear, it worked.

4. Open it in other software

Check in several environments, such as a browser, a PDF viewer or another device.

After saving, open it and check that the text under the black cannot be selected.

Steps for checking

  1. Open the saved PDF.
  2. Try selecting on all blacked-out pages.
  3. Search for the hidden word.
  4. Paste a select-all copy into a notepad and check.
  5. If there is a problem, redo the blackout from the original PDF.

Pages you did not black out

This tool leaves pages you did not black out with their original data. So text remains on those pages. Check that the information to hide is not on a page you did not black out.

Check the image quality

Blacked-out pages become images, so the text may look a little coarse. If it is hard to read, remake it with "Fine (200 dpi)".

Example

In a PDF with a name hidden, search for the name: 0 hits. Try selecting: cannot select. Judged OK.

Other things to check

  • File properties: is the author name or similar still there?
  • File name: does it contain a name?
  • Other pages: is the same information in another place?

Common stumbling blocks

  • The text could be selected: the blackout was not applied on that page. Check the area.
  • The search found it: the same word is in a place you did not black out.
  • You only checked some pages: check all pages.

Frequently asked questions

Can I check on a phone?

Yes. Try selecting by long-press, or use the PDF's search function.

What about the original PDF after checking?

Keep the original PDF at hand, stored separately from the one for submission.

Summary

Check by selecting, searching, copying and opening in another environment. Finish these four checks before sending.
