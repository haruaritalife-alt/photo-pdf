繰り返す番号

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • REPEATを選ぶ
  • 繰り返す数を入れる
  • コピーする

1・2・3・4・1・2・3・4…と、決まった数で繰り返す番号がほしいことがあります。グループ分けや、交代制のシフト、4列の表示に使えます。連番の式を作る の「REPEAT」で作れます。

手順

  1. 「種類」で「REPEAT」を選ぶ。
  2. 「件数（REPEATは繰り返す数）」に、1から何まで繰り返すかを入れる。
  3. 式をコピーして貼る。
REPEATでは、「件数」が繰り返す数になります。4なら、1〜4を繰り返します。

例

1〜4を繰り返す場合です。

  • Google：=ARRAYFORMULA(MOD(ROW(A1:A100)-1,4)+1)
  • 1行ずつ：=MOD(ROW(A1)-1,4)+1

結果は、1, 2, 3, 4, 1, 2, 3, 4… と並びます。

仕組み

ROW(A1)は、行の番号（1, 2, 3…）を返します。1を引いて、繰り返す数で割った余りに、1を足しています。

向いている場面

  • 班分け（1〜4班に、順番に割り当てる）
  • 交代制の担当割り振り
  • 大量の項目を、4列に並べ替える

件数の範囲

ツールの式は、繰り返す数の10倍（最低100）の行まで作ります。足りなければ、「A1:A100」の部分を広げます。

例

名簿の順に、1〜5班へ割り振りたい。MODとROWを使った式で、5班を順番に繰り返す番号が振れた。

つまずきやすい点

  • 行がずれる：式を入れた行が、1行目でない場合は、ROWの部分で調整する。
  • 途中に行を挿入：ROWは行の位置で決まるため、番号が変わる。

よくある質問

同じ数を2回ずつ繰り返したい

INT関数と組み合わせます。

  • 例：=INT((ROW(A1)-1)/2)+1

1, 1, 2, 2, 3, 3… と並びます。

まとめ

繰り返す番号は、MODとROWの組み合わせです。

Repeating Numbers

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Choose REPEAT
  • Enter the cycle length
  • Copy it

Sometimes you want numbers that repeat in a fixed cycle: 1-2-3-4-1-2-3-4… Useful for group assignment, shift rotas and four-column layouts. "REPEAT" in Build a SEQUENCE Formula builds it.

Steps

  1. Choose "REPEAT" in "Type".
  2. In "Count (for REPEAT, the repeat length)", enter how high to cycle from 1.
  3. Copy the formula and paste.
In REPEAT, "Count" is the cycle length. With 4, it repeats 1 to 4.

Example

Repeating 1 to 4:

  • Google: =ARRAYFORMULA(MOD(ROW(A1:A100)-1,4)+1)
  • Row by row: =MOD(ROW(A1)-1,4)+1

The result is 1, 2, 3, 4, 1, 2, 3, 4…

How it works

ROW(A1) returns the row number (1, 2, 3…). It subtracts 1, takes the remainder by the cycle length, and adds 1.

Good for

  • Group assignment (assign people to groups 1–4 in turn)
  • Rotating duty assignments
  • Rearranging many items into four columns

The row range

The tool's formula covers rows up to 10× the cycle (at least 100). If that's not enough, widen the "A1:A100" part.

Example

Wanted to assign a roster in order to groups 1–5. A MOD and ROW formula gave numbers cycling through the five groups.

Common stumbling blocks

  • Rows shift: if the formula isn't in row 1, adjust the ROW part.
  • Inserted rows: ROW depends on position, so numbers change.

Frequently asked questions

I want each number twice

Combine with INT.

  • Example: =INT((ROW(A1)-1)/2)+1

It gives 1, 1, 2, 2, 3, 3…

Summary

Repeating numbers come from MOD combined with ROW.
