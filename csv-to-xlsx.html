使い方

  1. CSVファイルを選ぶか、内容を貼り付けます。
  2. 区切り文字、シートの名前などを決めます。
  3. 「Excelにして保存」を押し、保存します。

仕組み

  • CSVを、Excelで開ける .xlsx ファイルにします。
  • 区切り文字は、自動で判定できます。
  • 「数字は数値として入れる」にすると、Excelで計算に使えます。

注意

  • 「007」のように0で始まる数字は、文字のまま入れます。
  • 書式や計算式は付きません。値だけのシンプルなExcelファイルになります。

よくある質問

貼り付けた内容は外部に送信されますか？

いいえ。処理はすべて、お使いの端末のブラウザの中で行われます。

Excelで文字化けしませんか？

このツールでつくるExcelファイルは、日本語も正しく表示されます。

How to use

  1. Select a CSV file or paste its content.
  2. Set the delimiter, the sheet name and other options.
  3. Tap "Make Excel file and save" and save.

How it works

  • A CSV is turned into an .xlsx file that opens in Excel.
  • The delimiter can be detected automatically.
  • With "Store numbers as numbers" the values can be used in Excel calculations.

Notes

  • Numbers that start with 0, such as 007, are kept as text.
  • No formatting or formulas are added. It is a simple, values-only Excel file.

FAQ

Is the pasted content sent anywhere?

No. Everything is processed inside the browser on your device.

Will Japanese text be garbled in Excel?

Excel files made with this tool show Japanese text correctly.
