使い方

  1. 「PDFを選ぶ」で、小さくしたいPDFを選びます。
  2. 画質を選びます。上限が決まっているときは、「サイズを指定」で、1・2・5・10MBから選びます。
  3. 「圧縮する」を押し、「PDFを保存する」で保存します。

しくみと注意

  • 各ページを画像にして、画質を調整して、PDFに戻しています。そのため、文字の選択・コピー・検索はできなくなります。
  • 「サイズを指定」では、できるだけ高い画質のまま、上限に収まるように、自動で調整します。
  • 元のファイルのほうが小さい場合は、その旨を表示します。

よくある質問

PDFは外部に送信されますか？

いいえ。処理はすべて、お使いの端末のブラウザの中で行われます。

ページ数が多いと、時間がかかりますか？

はい。ページ数が多いほど、また、サイズ指定のときは調整を繰り返すため、時間がかかります。スマホでは、特に、ゆっくりになることがあります。

上限に収まらないときは？

ページ数を減らすか、上限を大きくしてください。ページを減らすには、「PDFのページを抜き出し・削除」が使えます。

How to use

  1. Tap "Choose a PDF" and select the PDF you want to shrink.
  2. Pick a quality. If there is a size limit, choose "Set a size limit" and pick 1, 2, 5 or 10 MB.
  3. Tap "Compress", then "Save PDF".

How it works, and a caution

  • Each page is turned into an image, its quality is adjusted, and it is put back into a PDF. As a result, you can no longer select, copy or search the text.
  • With "Set a size limit", the tool keeps the quality as high as it can while fitting under the limit.
  • If the original file is already smaller, the tool tells you.

FAQ

Is my PDF uploaded anywhere?

No. Everything is processed inside the browser on your device.

Does a long PDF take time?

Yes. More pages take longer, and a size limit repeats the adjustment several times. It can be slow on phones in particular.

What if it still doesn't fit?

Reduce the number of pages or raise the limit. The "Extract or Delete PDF Pages" tool can help you remove pages.
