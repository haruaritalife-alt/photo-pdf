使い方

  1. 「画像を選ぶ」で、画像を1枚選びます。
  2. 色を知りたい場所を、タップ（クリック）します。
  3. 「コピー」を押すと、色コード（#RRGGBB）をコピーできます。

仕組み

  • タップした場所の色を、16進数の色コードとRGBで表示します。
  • 「主な色を調べる」で、画像に多く使われている色を5色まで探します。

注意

  • 写真は、同じ場所でも少しずつ色が違います。
  • 画面の見え方によって、色は違って見えることがあります。
  • HEIC形式は、先に「HEIC→JPG変換」でJPGにしてください。

よくある質問

画像は外部に送信されますか？

いいえ。処理はすべて、お使いの端末のブラウザの中で行われます。

色コードは、何に使えますか？

ブログやスライド、デザインソフトで、同じ色を指定するときに使えます。

How to use

  1. Tap "Choose an image" and select one image.
  2. Tap (click) the spot whose color you want.
  3. Tap "Copy" to copy the color code (#RRGGBB).

How it works

  • The color at the spot is shown as a hex code and RGB.
  • "Find the main colors" finds up to five colors used most in the image.

Notes

  • Colors in a photo vary slightly even within one spot.
  • Colors can look different depending on your screen.
  • HEIC files must be converted to JPG first with the HEIC to JPG tool.

FAQ

Are my images uploaded anywhere?

No. Everything is processed inside the browser on your device.

What is the color code for?

Use it to specify the same color in blogs, slides or design software.
