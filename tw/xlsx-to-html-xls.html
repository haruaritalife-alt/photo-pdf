檔案是舊版 .xls 時

釋出日期：2026 年 10 月 19 日｜最後更新：2026 年 10 月 19 日｜關於（日文）

要點
  • 開啟
  • 重新儲存

You want to turn an old-format .xls file into an HTML or Markdown table. Convert an Excel Table to HTML or Markdown targets .xlsx files. A .xls file as it is may not be usable.

Supported formats

  • Supported: .xlsx
  • Not supported: .xls (old format)

How to turn .xls into .xlsx

  1. Open the .xls file in Excel.
  2. Choose "Save As".
  3. Set the file type to "Excel Workbook (.xlsx)" and save.
  4. Open the saved .xlsx in this tool.
Changing only the extension doesn't work. Always re-save in Excel.

Notes when re-saving

  • Keep the original .xls file as it is
  • Macros aren't stored in .xlsx
  • After saving, check that the table content is correct

Other methods

  • You can also select the table, copy it and paste directly into a web page or document (though formatting can get mixed in)
  • You can also save as CSV and use a conversion tool from CSV

For other formats

  • .xlsm (with macros): re-save as .xlsx, then use.
  • Google Sheets: download in Excel format, then use.

適合

  • Putting tables from old material on the web
  • Turning old system output into documentation

示例

Wanted to put a 5-year-old .xls price list on the site. Re-saved as .xlsx in Excel, turned it into an HTML table with this tool and pasted it.

Common stumbling blocks

  • "Cannot read" appears: may be .xls or a broken file.
  • Garbled text: re-saving sometimes fixes it.

Frequently asked questions

Can I just rename the extension to .xlsx?

No. The internal format differs, so it won't work.

小結

For .xls, re-save as .xlsx in Excel first.
