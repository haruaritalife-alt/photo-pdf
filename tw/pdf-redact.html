把 PDF 的一部分塗黑

把不想讓人看到的內容，確確實實地藏起來。

你的 PDF 不會被上傳。所有處理都只在這臺裝置上進行。

  1. 1選擇 PDF
  2. 2在要塗黑的部分上拖動
  3. 3儲存 PDF

塗黑頁面的畫質

塗黑的頁面會變成圖片，所以這些頁面的文字將無法再被選擇或搜尋。下面的文字也不會留在檔案裡。沒有塗黑的頁面保持原樣。

完成

使用方法

  1. 點選「選擇 PDF」，選取一個 PDF。
  2. 顯示一個頁面，用手指或滑鼠在想塗黑的部分上拖動。在手機上，請先點選「選擇範圍」。
  3. 在其他頁面上也這樣做。想給每一頁的同一位置塗黑，就點選「對所有頁面應用相同範圍」。
  4. 點選「塗黑並生成 PDF」，檢視預覽，並儲存 PDF。

注意事項

  • 塗黑的頁面會變成圖片。這些頁面的文字將無法再被選擇或搜尋。
  • 下面的文字不會留在檔案裡。沒有塗黑的頁面保持原樣。
  • 儲存後，開啟它，確認黑色方塊下面的文字無法被選取。
  • 不支援帶密碼的 PDF。

常見問題

我的 PDF 會被上傳到哪裡嗎？

不會。所有處理都在你裝置上的瀏覽器內完成。

我的原始 PDF 會被改動嗎？

不會。塗黑後的 PDF 會另外儲存。

可以撤銷塗黑嗎？

儲存之前，可以用「撤銷上一步」。已儲存的 PDF 裡的塗黑無法撤銷。請保留你的原始 PDF。
