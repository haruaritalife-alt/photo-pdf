如何一次糾正多張圖片的方向

釋出日期：2026 年 10 月 19 日｜最後更新：2026 年 10 月 19 日｜關於（日文）

要點
  • 選擇多張圖片
  • 選擇旋轉方式
  • 儲存為 ZIP

Dozens of travel or event photos are sideways. Fixing them one by one is tedious. Rotate and Flip Images can fix several images to the same orientation at once.

步驟

  1. With "Choose images", select together the images whose orientation you want to fix.
  2. Choose the "Rotate" (for example "90° right").
  3. If needed, choose the "Flip".
  4. Choose the "Format" (JPG or PNG).
  5. Press "Rotate/flip and save" and check the "Preview".
  6. Save them together with "Save ZIP".
The same rotation is applied to all images. Do not select images with different orientations together.

Processing by orientation

When photo orientations vary, process them in groups by orientation.

  1. Select only the photos lying sideways, apply the needed rotation and save.
  2. Select only the upside-down photos and save with 180°.
  3. Use already-correct photos as they are.

Tips for grouping

  • First sort photos by orientation in your photo app
  • On a phone, photos taken in the same orientation are easy to select together

示例

30 portrait photos appear sideways. Select them together, rotate "90° right" and save as a ZIP.

The saved ZIP

Unzipping gives the rotated images. Sorting by file name restores the original order.

Common stumbling blocks

  • Only some photos ended up the wrong way: photos of a different orientation were mixed in. Redo only that group.
  • The ZIP is large: set the format to JPG.
  • Processing stops partway: there may be too many. Process in parts.

Frequently asked questions

How many can be combined?

It depends on your device. If many, process in parts.

小結

Select photos of the same orientation together and rotate in bulk. If orientations vary, process by group.
