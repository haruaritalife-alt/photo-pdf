含有空格的工作表名稱

釋出日期：2026 年 10 月 19 日｜最後更新：2026 年 10 月 19 日｜關於（日文）

要點
  • 輸入工作表名稱
  • 檢視公式
  • 核對一下

When a sheet name contains spaces or symbols, IMPORTRANGE's syntax changes slightly. Build an IMPORTRANGE Formula adjusts this automatically.

Rules applied

  • Names of only alphanumerics and underscores: as is (e.g. Sheet1)
  • Others (with spaces, Japanese or symbols): enclosed in single quotes (e.g. 'Sales 2026')
  • Names containing a single quote: doubled (Tom's → Tom''s)

步驟

  1. Enter the original sheet name in "Sheet name".
  2. Check the "SheetName!Range" part of the formula.
  3. If it contains spaces or Japanese, check it is enclosed in quotes.
Don't add "!" to the sheet name; the tool adds it between name and range.

Examples

  • Sheet "Sheet1": Sheet1!A1:C10
  • Sheet "Sales 2026": 'Sales 2026'!A1:C10
  • Sheet "Tom's list": 'Tom''s list'!A1:C10

How it looks in the formula

Single quotes sit inside the formula's double quotes.

  • =IMPORTRANGE("https://docs.google.com/spreadsheets/d/(ID)","'Sales 2026'!A1:C10")

How to check the sheet name

  • Look at the tabs at the bottom of the source spreadsheet
  • Check there are no invisible spaces (such as trailing ones)
  • Match case and full-/half-width to the tab

適合

  • Japanese or space-containing sheet names
  • Names other than "Sheet1"
  • When #REF! might be caused by the sheet name

示例

The sheet was "FY2026 Sales". As is, it gave #REF!, but the tool's formula added single quotes and imported correctly.

Common stumbling blocks

  • Renamed the tab: rewrite the name inside the formula too.
  • Trailing space in the name: invisible, hard to notice. Check the tab name.

Frequently asked questions

Can the sheet name be omitted?

Omitting it targets the spreadsheet's first sheet. This tool is built to take a sheet name.

小結

Names with spaces or Japanese need quotes. The tool adds them automatically.
