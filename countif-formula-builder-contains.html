文字を含むセルを数える

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • CONTAINSを選ぶ
  • 探す文字を入れる
  • コピーする

「東京」を含む住所や、「請求書」と付くファイル名など、一部だけ一致するセルを数えたいことがあります。条件に合う数を数える式を作る では、ワイルドカードを使った COUNTIF の式を作れます。

ワイルドカードの考え方

COUNTIF の条件では、「*」が「0文字以上の何か」、「?」が「ちょうど1文字」を表します。

  • "*東京*"：どこかに「東京」を含む
  • "東京*"：「東京」で始まる
  • "*東京"：「東京」で終わる
  • "田?"：「田」の後ろにちょうど1文字

手順

  1. 範囲を入れます（例：A2:A100）。
  2. 探す文字を入れます（例：東京）。
  3. 「含む」「始まる」「終わる」から選びます。
  4. 式をコピーして貼り付けます。
探す文字を別のセルに書いたときは、"*"&E2&"*" のように「&」でつなぎます。

具体例

住所の列から、東京都内の人数を数えたいときは =COUNTIF(A2:A500,"東京都*") です。商品名に「限定」が付くものを数えるなら =COUNTIF(B2:B300,"*限定*") になります。

よくあるつまずき

  • 「*」や「?」そのものを探したい：直前に「~」を付けて "~*" と書きます。
  • 数字は対象外のことがある：ワイルドカードは文字のセルに使います。数字だけのセルは一致しないことがあるので、必要なら文字にそろえます。
  • 大文字と小文字は区別されない：「Tokyo」と「tokyo」は同じものとして数えられます。

よくある質問

2つの言葉のどちらかを含むものを数えたい

COUNTIF を2つ足します。両方を含む場合の重なりは、引いて調整してください。

正規表現は使えますか？

COUNTIF では使えません。複雑な一致は、別の方法を使います。

まとめ

一部だけ一致するなら、前後に「*」を付けた条件にします。別のセルを使うときは「&」でつなぐことを覚えておくと便利です。

Counting Cells with Text

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Choose CONTAINS
  • Enter the text to look for
  • Copy it

Sometimes you want to count cells that match only in part: addresses containing "Tokyo", or file names with "invoice" in them. With Build a COUNTIF Formula you can build COUNTIF formulas that use wildcards.

How wildcards work

In a COUNTIF condition, "*" stands for any run of zero or more characters, and "?" stands for exactly one character.

  • "*Tokyo*": contains "Tokyo" anywhere
  • "Tokyo*": starts with "Tokyo"
  • "*Tokyo": ends with "Tokyo"
  • "Ta?": "Ta" followed by exactly one character

Steps

  1. Enter the range (for example A2:A100).
  2. Enter the text to look for (for example Tokyo).
  3. Choose contains, starts with or ends with.
  4. Copy the formula and paste it.
If the text is written in another cell, join it with "&", as in "*"&E2&"*".

Examples

To count the people in Tokyo in an address column, use =COUNTIF(A2:A500,"Tokyo*"). To count product names containing "limited", use =COUNTIF(B2:B300,"*limited*").

Common stumbling blocks

  • Looking for "*" or "?" itself: put "~" in front, as in "~*".
  • Numbers may be skipped: wildcards work on text cells. Cells that hold only numbers may not match, so convert them to text if needed.
  • Case is ignored: "Tokyo" and "tokyo" are counted together.

Frequently asked questions

How do I count cells that contain either of two words?

Add two COUNTIF formulas. If a cell can contain both, subtract the overlap.

Can I use regular expressions?

Not in COUNTIF. Use another method for complex matching.

Summary

For a partial match, put "*" on both sides of the text. When the text is in another cell, join it with "&".
