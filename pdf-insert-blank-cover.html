PDFの先頭に白紙を入れる方法（表紙用）

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • PDFを選ぶ
  • 「0」を入力
  • 保存する

PDFの先頭に、白紙を1枚入れたい。表紙用のスペース、あとで表紙を貼るための空き、印刷時の見返しなど。PDFに白紙ページを挿入 では、ページ番号に「0」を指定すると、先頭に白紙が入ります。

手順

  1. 「PDFを選ぶ」で、PDFを選びます。
  2. 「入れ方」で、「指定したページの後ろに入れる」を選びます。
  3. 「ページ番号（例：2,5。0なら先頭）」に、「0」と入れます。
  4. 「白紙を入れてPDFを作る」を押します。
  5. 「プレビュー」で、先頭に白紙が入ったか確認します。
  6. 「PDFを保存する」で保存します。
「0」は、先頭（1ページ目の前）を表します。

先頭と他の位置を同時に

「0,5,10」のように入れると、先頭と、5ページ目の後ろ、10ページ目の後ろに入ります。

使う場面

  • 表紙を、あとで差し込みたい：先頭に白紙を入れておく。
  • 印刷して製本するとき：表紙の見返しとして。
  • 書き込みスペース：先頭に、メモ用の白紙。
  • 両面印刷で、最初の面を白紙にしたい：1ページ目を裏から始めたい場合に。

表紙を作るには

白紙を入れたあとで、表紙に必要な文字を、PDFに文字を書き込むツールで入れます。

  1. このツールで、先頭に白紙を入れる。
  2. 保存したPDFを、書き込みツールで開く。
  3. 1ページ目に、題名や日付、名前を入れる。

別の方法：表紙のPDFを結合

表紙を、別の文書で作った場合は、結合ツールで、表紙のPDFを先頭に結合する方法もあります。

例

10ページの資料の先頭に、白紙を1枚入れて11ページにする。そこに、題名を書き込んで、表紙にする。

白紙のサイズ

白紙のサイズは、前のページと同じ、先頭の場合は1ページ目と同じ大きさです。

つまずきやすい点

  • 「ページ番号は、数字とカンマで指定してください。」と出る：半角の数字とカンマで入れます。
  • 先頭ではなく、1ページ目の後ろに入った：「1」ではなく「0」を入れます。
  • ページ番号が1つずつずれる：先頭に白紙を入れると、元の1ページ目は2ページ目になります。ページ番号を付ける場合は、白紙を入れてから付けます。

よくある質問

先頭と末尾の両方に入れたい

先頭は「0」、末尾は最後のページ番号を入れます。例：10ページなら「0,10」。

複数枚入れたい

同じ位置に複数枚は、入れられません。複数回実行します。

まとめ

「0」で先頭に白紙。表紙にしたい場合は、書き込みツールで題名を入れましょう。

PDFに白紙ページを挿入を使う（無料）

あわせて使えるツール

  • PDFの不要なページを削除：PDFから、いらないページを選んで削除します。
  • PDFのページを回転・並べ替え：向きが違うページを直す、ページの順番を入れ替える、いらないページを消す。
  • PDFにページ番号を追加：PDFの各ページに、ページ番号を入れます。位置や形式を選べます。

How to Add a Blank Page at the Start of a PDF

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Choose a PDF
  • Enter "0"
  • Save

You want to insert one blank page at the start of a PDF: space for a cover, room to attach a cover later, an endpaper when printing. In Insert Blank Pages into a PDF, specifying "0" as the page number inserts a blank at the start.

Steps

  1. Choose the PDF with "Choose a PDF".
  2. In "How to insert", choose "Insert after specified pages".
  3. In "Page numbers (e.g. 2,5. 0 means the start)", enter "0".
  4. Press "Insert blanks and create PDF".
  5. In the "Preview", check that a blank was inserted at the start.
  6. Save with "Save PDF".
"0" means the start (before page 1).

Start and other positions at once

Entering "0,5,10" inserts at the start, after page 5 and after page 10.

When to use it

  • You want to insert a cover later: put a blank at the start.
  • Printing and binding: as an endpaper for the cover.
  • Writing space: a blank for notes at the start.
  • Double-sided printing where the first side should be blank: when you want page 1 to start on the back.

Making a cover

After inserting the blank, add the text you need for the cover with the tool that writes text onto a PDF.

  1. Insert a blank at the start with this tool.
  2. Open the saved PDF in the writing tool.
  3. On page 1, put the title, date and name.

Another method: merge a cover PDF

If you made the cover in another document, you can also merge the cover PDF at the front with the merge tool.

Example

Insert one blank at the start of a 10-page document to make 11 pages. Write the title on it to make a cover.

Size of the blank

The blank has the same size as the previous page; at the start, the same size as page 1.

Common stumbling blocks

  • "Specify page numbers with digits and commas" appears: use half-width digits and commas.
  • It went after page 1 instead of the start: enter "0", not "1".
  • Page numbers shift by one: inserting a blank at the start makes the original page 1 into page 2. If you add page numbers, add them after inserting the blank.

Frequently asked questions

I want a blank at both the start and the end

Enter "0" for the start and the last page number for the end. For example, for 10 pages, "0,10".

I want to insert several

You cannot insert several at the same position. Run it multiple times.

Summary

"0" inserts a blank at the start. To make it a cover, add a title with the writing tool.
