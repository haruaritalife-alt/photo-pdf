طريقة الاستخدام

  1. اختر «URL / نص» أو «Wi-Fi».
  2. أدخل URL أو نصًا. وبالنسبة لـWi-Fi أدخل الاسم (SSID) وكلمة المرور.
  3. اختر اللون وحجم الصورة وتصحيح الأخطاء. وإن لم تكن متأكدًا فاترك الإعدادات الافتراضية.
  4. اضغط «إنشاء رمز QR» واحفظ بصيغة PNG أو SVG أو PDF.
  5. قبل الاستخدام، امسحه بكاميرا الهاتف للتحقق.

ملاحظات

  • انتبه إلى الأخطاء الإملائية في URL. افتح URL أولًا للتحقق.
  • النص الطويل يجعل النمط كثيفًا وأصعب في المسح.
  • عند الطباعة، لا تقصّ الهامش الأبيض حوله.
