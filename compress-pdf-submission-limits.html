応募フォームのファイル容量の目安と、PDFを収めるコツ

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • 制限は、1〜10MBが多い
  • 上限の8割程度を目標にすると失敗しにくい
  • アップロード前に、ファイルの大きさを確認する

応募フォームやマイページには、アップロードできるファイルの容量に上限があります。

よくある制限

  • 1MB：写真のアップロードなど、厳しめのもの
  • 2〜3MB：履歴書・エントリーシートなど
  • 5MB：証明書類
  • 10MB：ポートフォリオなど

収めるコツ

  • 上限ちょうどを狙わず、8割ほどを目標にする（例：5MBなら4MB前後）
  • 「サイズを指定」で、上限より1段階小さい値を選ぶ
  • 写真が多いなら、必要な枚数だけにする

確認の方法

  • スマホ：ファイルアプリで、ファイルの情報（サイズ）を見る
  • パソコン：ファイルを右クリックして、プロパティ（Mac は情報）を見る

失敗したとき

アップロードが失敗するときは、容量のほか、ファイル名（全角や記号）、拡張子、ファイル形式（PDFのみなど）も確認してください。

PDFを圧縮を使う（無料）

あわせて使えるツール

  • PDFのページを抜き出し・削除：PDFから、必要なページだけを残す、または不要なページを消します。
  • PDFを結合：複数のPDFを、順番を決めて1つのPDFにまとめます。
  • PDFを分割：PDFを、1ページずつ、Nページごと、または範囲を決めて、複数のPDFに分けます。

Typical Upload Limits on Application Forms and How to Fit Within Them

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Limits are commonly 1–10 MB
  • Aim for about 80% of the limit to avoid failures
  • Check the file size before uploading

Application forms and account pages cap the size of files you can upload.

Common limits

  • 1 MB: strict ones, such as photo uploads
  • 2–3 MB: résumés, application forms
  • 5 MB: certificates
  • 10 MB: portfolios

Tips for fitting

  • Don't aim exactly at the limit; target about 80% (around 4 MB for a 5 MB limit)
  • Choose a value one step below the limit under "Set a size"
  • If you have many photos, keep only what is needed

How to check size

  • Phone: view the file's info (size) in the Files app
  • Computer: right-click the file and open Properties (Info on Mac)

If the upload fails

Besides size, also check the file name (full-width characters or symbols), extension and file type (PDF only, for example).

Use "Compress PDF" (free)

Tools that go well with this

  • Extract or Delete PDF Pages: Keep only the pages you need, or remove the pages you don't.
  • Merge PDFs: Combine several PDF files into one, in the order you choose.
  • Split PDF: Split a PDF into several files: one page each, every N pages, or by ranges.
