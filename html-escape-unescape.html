変換後の文字を元に戻す方法

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • 変換後の文字を入れる
  • 元に戻すを押す
  • 結果を見る

ソースコードや、データの中で、「&lt;」「&amp;」のような、意味の分からない文字を見たことはありませんか。これは、エスケープされた文字です。HTMLエスケープ・アンエスケープ の「元に戻す」で、読める形に戻せます。

手順

  1. 「文字列またはHTML」の欄に、エスケープされた文字を貼ります。
  2. 「元に戻す」を押します。
  3. 「変換結果」に、元の文字が出ます。
  4. 「結果をコピー」で、コピーします。
例：&lt;p&gt;こんにちは&lt;/p&gt; → <p>こんにちは</p>

戻せる文字

  • &amp; → &
  • &lt; → <
  • &gt; → >
  • &quot; → "
  • &#39; と &apos; → '
  • 数字の文字参照（&#169; や &#xA9; など）：対応する文字

数字の文字参照は、10進数（&#169;）でも、16進数（&#xA9;）でも、戻せます。

よく出てくる場面

  • Webページのソースを見たとき
  • APIのレスポンスに、エスケープされた文字が入っているとき
  • RSSやメールの、本文を読むとき
  • データベースに、エスケープされた状態で保存されているとき

向いている場面

  • 読みにくい文字列を、読める形にしたい
  • 誤ってエスケープした文字を、元に戻したい

例

RSSのタイトルが「A &amp; B」と表示されていた。「元に戻す」を押すと、「A & B」になった。

戻らないとき

  • 二重にエスケープされている：「&amp;lt;」のような形。1回戻すと「&lt;」になるので、もう一度戻す。
  • 名前付きの文字参照：「&copy;」「&nbsp;」などは、このツールでは戻らないことがある。

つまずきやすい点

  • 結果をHTMLに貼ると、タグとして動く：戻した結果は、そのままページに貼ると、HTMLとして働く。注意する。
  • セミコロンの欠落：「&lt」のように、末尾の「;」が無いと、戻らない。

よくある質問

戻したあと、安全に使えますか？

戻した結果には、タグやスクリプトが含まれることがあります。Webページに直接貼るのは、避けてください。

まとめ

エスケープされた文字は、「元に戻す」で読める形に。ただし、戻したあとの扱いに、注意しましょう。

Turning Escaped Characters Back

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Enter the escaped text
  • Press Unescape
  • See the result

In source code and data, have you seen incomprehensible characters like "&lt;" and "&amp;"? These are escaped characters. "Unescape" in HTML Escape and Unescape restores them to a readable form.

Steps

  1. Paste the escaped text in the "String or HTML" field.
  2. Press "Unescape".
  3. The original text appears in "Result".
  4. Copy with "Copy result".
Example: &lt;p&gt;Hello&lt;/p&gt; → <p>Hello</p>

Characters it restores

  • &amp; → &
  • &lt; → <
  • &gt; → >
  • &quot; → "
  • &#39; and &apos; → '
  • Numeric character references (such as &#169; or &#xA9;): the corresponding character

Numeric references are restored in decimal (&#169;) and hexadecimal (&#xA9;) alike.

Where it often appears

  • Viewing a web page's source
  • When an API response contains escaped characters
  • Reading the body of RSS or email
  • When data is stored escaped in a database

Good for

  • Making a hard-to-read string readable
  • Restoring text that was escaped by mistake

Example

An RSS title showed as "A &amp; B". Pressing "Unescape" made it "A & B".

When it doesn't restore

  • Escaped twice: a form like "&amp;lt;". One restoration gives "&lt;", so restore once more.
  • Named character references: ones like "&copy;" and "&nbsp;" may not be restored by this tool.

Common stumbling blocks

  • Pasting the result into HTML makes tags work: pasted directly into a page, the restored result acts as HTML. Take care.
  • Missing semicolon: without the trailing ";" as in "&lt", it doesn't restore.

Frequently asked questions

Is it safe to use after restoring?

The restored result may contain tags or scripts. Avoid pasting it directly into a web page.

Summary

Restore escaped text to a readable form with "Unescape". But take care in handling it afterwards.
