書類をPDFで提出する前のチェックリスト

この記事のポイント
  • 提出先の指定（形式・容量・ファイル名）を先に確認
  • ページ順・向き・読みやすさを自分の目で確認
  • 個人情報の写り込みに注意する

書類をPDFにして提出する前に、確認しておきたいことをまとめます。出し直しにならないよう、提出の前に、一通り見てください。

提出先の指定を確認する

  • ファイルの形式：PDFでよいか、ほかの形式の指定がないか
  • 容量の上限：何MBまでか（1ファイルあたりか、合計か）
  • ファイル名の決まり：氏名や番号を入れる指定がないか
  • ページ数・枚数の指定：上限や、決まった順番がないか

PDFの中身を確認する

  • ページの順番：書類の順番どおりになっているか
  • 向き：横向きになっているページがないか
  • 読みやすさ：小さな文字や、数字、日付が読めるか
  • 欠け：書類の端や、角が切れていないか
  • 影やぶれ：影でうまく読めない部分がないか

個人情報に気をつける

  • 背景に、ほかの書類や、関係のない情報が写っていないか
  • 提出する必要のないページが、まぎれていないか
  • メールで送るときは、宛先を間違えていないか

ファイル名と保存

  • ファイル名は、中身がわかる名前にしておく（例：「申請書_山田.pdf」）。
  • 提出したファイルは、手元にも、控えとして残しておく。

最後に

保存したPDFを、いちど最初から最後まで、自分の目で開いて確認しましょう。作ったあとの確認が、いちばんのミス防止になります。

Checklist Before Submitting Documents as a PDF

Key points
  • Check the recipient's requirements (format, size, file name) first
  • Check page order, orientation and legibility yourself
  • Watch for personal information in the shot

Here is what to check before submitting a PDF made from documents. Run through it before you send, so you don't have to resubmit.

Check the recipient's requirements

  • File format: Is PDF accepted, or is another format specified?
  • Size limit: How many MB? Per file, or in total?
  • File name rules: Do they ask for your name or a number in it?
  • Page count: Is there a limit or a required order?

Check the contents of the PDF

  • Page order: Do the pages follow the order of the documents?
  • Orientation: Is any page sideways?
  • Legibility: Can you read small text, numbers and dates?
  • Cropping: Are the edges or corners of the documents cut off?
  • Shadows and blur: Is any part unreadable because of them?

Be careful with personal information

  • Do other documents or unrelated information appear in the background?
  • Has any page slipped in that you don't need to submit?
  • If sending by email, is the address correct?

File name and saving

  • Give the file a name that shows what it is (for example "Application_Yamada.pdf").
  • Keep a copy of what you submitted for yourself.

Finally

Open the saved PDF and look through it from start to finish yourself. Checking after you make it is the best way to prevent mistakes.
