PDFの全ページに日付を入れる方法

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • 右上か右下の欄に入力
  • {date} と書く
  • 保存する

書類の全ページに、日付を入れたい。提出日、作成日、印刷日。PDFにヘッダー・フッターを入れる では、{date} と入力すると、今日の日付が、全ページに入ります。

書き方

文字の欄に、{date} を入れます。

  • 「{date}」→ 今日の日付
  • 「作成日：{date}」→「作成日：（今日の日付）」
  • 「{date} 提出」→「（今日の日付） 提出」

手順

  1. 「PDFを選ぶ」で、PDFを選びます。
  2. 「入れる文字を決める」で、「ヘッダー（右上）」などの位置に、「{date}」と入力します。
  3. 「文字の大きさ」と「端からの距離」を選びます。
  4. 「文字を入れてPDFを作る」を押して、「プレビュー」を確認します。
  5. 「PDFを保存する」で保存します。
入るのは、お使いの端末の「今日の日付」です。端末の日付が正しいか、確認してください。

日付の形式について

{date} で入る日付の形式は、このツールが決めた形式です。形式を指定したい場合は、日付を自分で入力します。

  • 例：「2026年10月20日」と、文字をそのまま入力する。

今日の日付を使う場面

  • 提出日を明記したい
  • 印刷した日を、紙に残したい
  • 書類の版を、日付で区別したい

固定の日付を入れる場面

  • 作成日を固定したい（あとで開いても、変わらないように）
  • 過去の日付を入れたい

これらの場合は、{date} ではなく、日付の文字を直接入力します。

位置の使い分け

  • ヘッダー（右上）：日付の定位置。
  • フッター（右下）：控えめに。

他の記号と組み合わせる

「{date}　{n} / {total}」のように入れると、日付とページ番号を、1つの欄に入れられます。

例

契約書の案に、ヘッダー（右上）で「{date}」。ヘッダー（左上）で「契約書（案）」。フッター（中央）で「{n} / {total}」。

つまずきやすい点

  • 「{date}」がそのまま表示される：波かっこを、半角で入力します。
  • 日付が違う：端末の日付設定を確認します。
  • 日付を固定したい：日付の文字を、直接入力します。

よくある質問

保存したPDFを、別の日に開くと日付は変わりますか？

変わりません。作成した時点の日付が、画像として入ります。

日付だけを入れて、他は入れなくてもよい？

はい。他の位置は、空欄でかまいません。

まとめ

{date} と入れるだけで、今日の日付が全ページに入ります。固定の日付は、直接入力します。

PDFにヘッダー・フッターを入れるを使う（無料）

あわせて使えるツール

  • PDFにページ番号を追加：PDFの各ページに、ページ番号を入れます。位置や形式を選べます。
  • PDFに透かし文字を入れる：「提出用」「コピー」「社外秘」などの文字を、PDFの全ページに薄く入れます。位置・色・濃さを選べます。
  • PDFに文字・日付・署名を書き込む：PDFの好きな場所に、文字・日付・チェック・○×・手書きの署名・画像（ハンコ）を書き込みます。

How to Put a Date on Every Page of a PDF

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Type in a right-hand box
  • Write {date}
  • Save

You want a date on every page of a document: the submission date, creation date or print date. In Add a Header and Footer to a PDF, entering {date} puts today's date on every page.

How to write it

Put {date} in the text field.

  • "{date}" → today's date
  • "Created: {date}" → "Created: (today's date)"
  • "{date} submitted" → "(today's date) submitted"

Steps

  1. Choose the PDF with "Choose a PDF".
  2. Under "Decide the text", enter "{date}" at a position such as "Header (top right)".
  3. Choose the "Text size" and "Distance from edge".
  4. Press "Add text and create PDF" and check the "Preview".
  5. Save with "Save PDF".
What goes in is "today's date" on your device. Check that the device's date is correct.

About the date format

The date format inserted by {date} is the one this tool decides. If you want to specify a format, type the date yourself.

  • Example: type "October 20, 2026" as plain text.

When to use today's date

  • You want to state the submission date
  • You want to leave the print date on the paper
  • You want to tell document versions apart by date

When to use a fixed date

  • You want to fix the creation date (so it does not change when opened later)
  • You want to put in a past date

In these cases, type the date text directly instead of {date}.

Which position for what

  • Header (top right): the usual place for a date.
  • Footer (bottom right): discreetly.

Combining with other symbols

Entering "{date}　{n} / {total}" puts the date and page number in one field.

Example

For a contract draft, "{date}" in the header (top right), "Contract (draft)" in the header (top left) and "{n} / {total}" in the footer (centre).

Common stumbling blocks

  • "{date}" is shown as it is: enter the curly braces in half-width.
  • The date is wrong: check the device's date setting.
  • You want a fixed date: type the date text directly.

Frequently asked questions

If I open the saved PDF on another day, does the date change?

No. The date at the time of creation is put in as an image.

May I enter only the date and nothing else?

Yes. The other positions can be left empty.

Summary

Just enter {date} to put today's date on every page. For a fixed date, type it directly.
