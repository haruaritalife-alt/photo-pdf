月ごとのExcelを、年間のデータにまとめる

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • 12か月分を選ぶ
  • 「最初のシート」にする
  • CSVを保存する

1月から12月まで、月ごとに別のExcelで管理していた売上。年間の集計をしたいときに、1つずつコピー＆貼り付けるのは大変です。複数のExcelを1つのCSVにまとめる なら、12個のExcelを、まとめて1つのCSVにできます。

手順

  1. 「Excelファイルを選びます」で、12か月分のExcelを、すべて選ぶ。
  2. 「対象のシート」で「各ファイルの最初のシート」を選ぶ。
  3. 「1行目は見出し（1つだけ残す）」にチェックを入れる。
  4. 「『元のファイル』『シート名』の列を足す」にチェックを入れる。
  5. 「まとめてCSVで保存」を押して、保存する。
「元のファイル」列を足すと、各データが何月のファイルから来たのか、あとで分かります。

事前の準備

  • 12個のファイルの、列の並びを、そろえる
  • ファイル名を「2026-01.xlsx」のように、月が分かる名前にする
  • 見出しの名前を、そろえる

結果の使い方

  1. できたCSVを、Excelで開く（文字化けする場合は、BOM付きで保存し直す）。
  2. ピボットテーブルで、月別・商品別に集計する。
  3. グラフにして、傾向を見る。

「元のファイル」列の活用

この列を使えば、ファイル名から月を取り出して、月別集計ができます。ファイル名に、月が入っていることが前提です。

向いている場面

  • 月次データを年次にまとめる
  • 四半期ごとのExcelを、半期にまとめる
  • 年度をまたいだ、複数年のデータ結合

注意

  • 計算式のセルは、保存されている値だけが使われる
  • 書式（色や罫線）は、引き継がれない
  • 空の行は、そのまま含まれることがある

例

月ごとの売上Excelを12個集めて、年間の1つのCSVにした。ピボットテーブルで、月別・商品別に集計できた。

つまずきやすい点

  • 月によって列が違う：事前に、列をそろえる。
  • 見出しが重なる：「1行目は見出し」にチェックを入れていない。

よくある質問

ファイルの順番は、どうなりますか？

選んだ順につながります。月順に選ぶと、月順のCSVになります。

まとめ

Combining Monthly Excel Files into a Yearly Dataset

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Choose the 12 monthly files
  • Use "First sheet"
  • Save the CSV

Sales managed in separate Excel files from January to December. When you want annual totals, copy-pasting one by one is tough. With Merge Several Excel Files into One CSV you can combine the 12 Excel files into one CSV at once.

Steps

  1. With "Choose Excel files", choose all 12 months' files.
  2. Under "Target sheet", choose "First sheet of each file".
  3. Tick "First row is a header (keep only one)".
  4. Tick "Add 'Source file' and 'Sheet name' columns".
  5. Press "Combine and save as CSV" and save.
Adding the "Source file" column lets you tell later which month's file each row came from.

Preparation

  • Align the column order of the 12 files
  • Name files so the month is clear, like "2026-01.xlsx"
  • Make header names consistent

Using the result

  1. Open the resulting CSV in Excel (if garbled, re-save with BOM).
  2. Total by month and product with a pivot table.
  3. Make a chart to see trends.

Using the "Source file" column

With this column you can extract the month from the file name and total by month. It assumes the month is in the file name.

Good for

  • Combining monthly data into annual
  • Combining quarterly Excel files into half-year
  • Combining multi-year data across fiscal years

Notes

  • For formula cells, only the stored values are used
  • Formatting (colours, borders) is not carried over
  • Empty rows may be included as they are

Example

Gathered 12 monthly sales Excel files into one annual CSV. A pivot table gave totals by month and product.

Common stumbling blocks

  • Columns differ by month: align the columns beforehand.
  • Headers overlap: "First row is a header" wasn't ticked.

Frequently asked questions

What order do the files go in?

They connect in the order chosen. Choosing in month order gives a month-ordered CSV.

Monthly Excel files into one CSV. Adding the file-name column enables monthly totals too.
