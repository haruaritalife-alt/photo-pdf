パスワード付きのZIPについて

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • 確かめる

パスワード付きのZIPを受け取った場合、ZIPを開く（解凍） では、開けません。このツールは、パスワード付きのZIPには対応していません。また、パスワードを推測したり、解読したりする機能もありません。

なぜ対応していないのか

パスワード付きのZIPは、暗号化されています。このツールは、暗号化されていないZIPを開くための、シンプルなツールです。

パスワード付きのZIPを開くには

お使いのOSの機能や、解凍アプリを使います。

  • パソコン：OSの標準機能や、対応する解凍ソフト
  • スマホ：ファイル管理アプリや、解凍アプリ

開くときに、パスワードの入力を求められます。

パスワードが分からないとき

  1. 送り主に確認する：メール、電話、チャットなど、別の連絡手段で聞く。
  2. メールを見直す：パスワードが、別のメールで届いていないか。
  3. ルールを確認する：会社や取引先で、決まった形式がないか。

パスワードを推測して開く行為は、許可のない場合、問題になることがあります。

手順（暗号化されていないZIPの場合）

  1. 「ZIPファイルを1つ選ぶ」で、ZIPを選びます。
  2. 「中身を見る」で、一覧を確認します。
  3. 必要なファイルの「保存」を押します。
パスワード付きかどうかが分からないときは、このツールで開いてみてください。開けない場合は、パスワード付きの可能性があります。

パスワード付きのZIPを送る側へ

パスワード付きのZIPを使う場合は、パスワードを別の経路で伝えましょう。相手の環境で開けるかも、確認しておくと親切です。重要な書類は、PDFにパスワードをかける方法もあります。

つまずきやすい点

  • パスワードを入れる欄がない：このツールには、ありません。
  • 開けないのは、壊れているから？：パスワード付きの場合も、壊れている場合もある。

About Password-Protected ZIPs

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Check

If you receive a password-protected ZIP, it cannot be opened with Open a ZIP File (Unzip). This tool does not support password-protected ZIPs. It also has no feature to guess or crack passwords.

Why it is not supported

Password-protected ZIPs are encrypted. This tool is a simple one for opening ZIPs that are not encrypted.

How to open a password-protected ZIP

Use your OS's features or an unzip app.

  • Computer: the OS's standard feature or compatible unzip software
  • Phone: a file manager app or unzip app

When opening, you are asked to enter the password.

When you don't know the password

  1. Check with the sender: ask by another means of contact, such as email, phone or chat.
  2. Review your email: whether the password arrived in a separate email.
  3. Check the rules: whether your company or partner has a set format.

Guessing a password to open a ZIP without permission can be a problem.

Steps (for ZIPs that are not encrypted)

  1. With "Choose one ZIP file", choose the ZIP.
  2. Check the list with "See contents".
  3. Press "Save" for the files you need.
If you are unsure whether it is password-protected, try opening it with this tool. If it will not open, it may be password-protected.

For those sending password-protected ZIPs

If you use a password-protected ZIP, convey the password by another route. It is also kind to check that the recipient's environment can open it. For important documents, putting a password on the PDF is another method.

Example

A ZIP from a business partner could not be opened with this tool. It turned out to be password-protected; after checking with them it was opened in another app.

Common stumbling blocks

  • There is no field to enter a password: this tool has none.
  • Does it not open because it is corrupted?: it can be password protection or corruption.

Frequently asked questions

Is there a tool to remove a ZIP password?

This site has no feature to remove ZIP passwords.

Summary

Open password-protected ZIPs with the OS or an app. Check the password with the sender.
