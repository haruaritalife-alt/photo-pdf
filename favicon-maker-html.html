ファビコンをサイトに設定する方法（HTMLタグ）

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • ZIPを展開
  • ファイルをサイトに置く
  • タグを貼る

ファビコンを作ったら、サイトに設定します。ファビコン（サイトのアイコン）を作る のZIPには、貼り付けるタグが書かれた html-tags.txt が入っています。

手順

  1. 「画像を選ぶ」で画像を選び、「ファビコンを作る」で作ります。
  2. 「ZIPを保存する」で保存し、展開（解凍）します。
  3. 中のファイル（PNG・favicon.ico）を、サイトのフォルダ（公開する場所）にアップロードします。
  4. html-tags.txt を開き、中のタグをコピーします。
  5. サイトの各ページの の中に、貼り付けます。
  6. サイトを開いて、タブにアイコンが出るか確認します。
ZIPの中の html-tags.txt を、サイトのに貼り付けます。ファイルを置いた場所に合わせて、パスを確認します。

タグの例

html-tags.txt には、次のような内容が入っています。

  • アイコンを指定する のタグ
  • スマホのホーム画面用の のタグ

サイズごとに、行が分かれています。

ファイルを置く場所

一番多いのは、サイトの一番上（ルート）のフォルダです。そこに置けば、パスは「/favicon.ico」のように書けます。

パスの確認

タグの中の、ファイルの場所（href）が、実際に置いた場所と合っているか確認します。合っていないと、表示されません。

設置後の確認

  1. サイトを開く。
  2. タブの端に、アイコンが出るか見る。
  3. 出ない場合は、ページを再読み込みする。
  4. それでも出ない場合は、ブラウザのキャッシュが原因のことがある。別の解説で説明しています。

ブログサービスを使っている場合

WordPressなどのサービスでは、設定画面から、画像をアップロードするだけでよい場合があります。別の解説で説明しています。

例

自分で作ったサイトの、ルートに、favicon.icoとPNGを置き、各ページのに、html-tags.txtのタグを貼った。

つまずきやすい点

  • タグを貼ったのに、出ない：パスが違う、またはキャッシュです。
  • 一部のページだけ出ない：すべてのページのに、タグが必要です。
  • スマホのアイコンが違う：apple-touch-iconのタグを確認します。

How to Add a Favicon to Your Site (HTML Tags)

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Unzip
  • Upload the files
  • Paste the tags

Once you have made a favicon, set it up on your site. The ZIP from Make a Favicon (Site Icon) contains html-tags.txt with the tags to paste.

Steps

  1. Choose an image with "Choose images" and make it with "Make favicon".
  2. Save with "Save ZIP" and unzip it.
  3. Upload the files inside (PNGs and favicon.ico) to your site's folder (the public location).
  4. Open html-tags.txt and copy the tags inside.
  5. Paste them into the of each page of your site.
  6. Open the site and check that the icon appears in the tab.
Paste html-tags.txt from the ZIP into the site's . Check the paths against where you placed the files.

Example of the tags

html-tags.txt contains things like:

  • A tag specifying the icon
  • A tag for the phone home screen

There is a line for each size.

Where to put the files

Most commonly in the site's top (root) folder. Put them there and the path can be written like "/favicon.ico".

Checking paths

Check that the file location (href) in the tags matches where you actually placed them. If not, it will not appear.

Checking after setup

  1. Open the site.
  2. See whether the icon appears at the edge of the tab.
  3. If not, reload the page.
  4. If it still does not appear, the browser cache may be the cause. Explained in a separate guide.

If you use a blog service

On services such as WordPress, you may only need to upload the image in the settings screen. Explained in a separate guide.

Example

Placed favicon.ico and the PNGs in the root of a self-made site and pasted the tags from html-tags.txt into each page's .

Common stumbling blocks

  • Pasted the tags but it does not appear: wrong path, or cache.
  • Appears only on some pages: the tags are needed in the of every page.
  • The phone icon is different: check the apple-touch-icon tag.
