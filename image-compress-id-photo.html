証明写真・顔写真の容量とサイズの調整方法

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • 指定のpx（縦×横）と容量の上限を、先に確認する
  • 大きさを下げて容量を合わせる
  • 比率が違うときは、切り抜きで整える

証明写真や、顔写真を、オンラインの申請フォームにアップロードするとき、「容量は◯KB以下」「縦横は◯px」と指定されることがあります。画像を圧縮・サイズ変更 で、写真を、指定に近づける方法を説明します。

まず、指定を確認する

  • ファイルの容量の上限（KB、MB）
  • 画像の大きさ（縦横のピクセル数）の指定
  • 形式（JPEGのみ、など）
  • 背景の色や、写り方の決まり

このツールで、できること

  • 画質を下げて、ファイルの容量を小さくする
  • 長いほうの辺を、2000、1600、1200、800pxのどれかに、縮小する
  • JPEGか、WebPかを、選ぶ

縦横の比率は変わらないため、ぴったり、指定のピクセル数にそろえたいときは、切り抜きや、サイズ指定のツールを使います。

手順

  1. 「画像を選ぶ」で、写真を選びます。
  2. 「形式」を、JPEGにします。
  3. 「大きさ（長いほうの辺）」を、「1200px」から、試します。
  4. 「画質」を、「ふつう」にします。
  5. 「圧縮する」を押して、容量を確認します。
  6. 上限を超えるときは、「800px」や「軽め」に、下げます。
顔が、はっきり見えることが、いちばん大事です。小さくしすぎて、目鼻立ちが、ぼやけないよう、確認します。

容量の目安

  • 100KB以下：「800px」＋「ふつう」から試す
  • 200KB以下：「1200px」＋「ふつう」
  • 500KB以下：「1600px」＋「ふつう」

気をつけたい点

  • 顔が、ぼやけていないか：拡大して、目、鼻、口が、くっきりしているか確認します。
  • 背景や、影：圧縮では、直せません。撮り直しが必要です。
  • 縦横の比率：指定がある場合は、先に、切り抜きで整えます。

切り抜きと、組み合わせる

  1. 切り抜きのツールで、指定の縦横の比率に合わせる
  2. このツールで、容量を、指定以下にする

この順番だと、余計な部分を、先に外せるため、効率がよくなります。

つまずきやすい点

  • 指定の容量に、収まらない：さらに、大きさを下げます。
  • 指定のピクセル数に、ならない：このツールは、長いほうの辺を、5段階から選びます。ピクセル数の指定には、サイズ変更のツールを使います。
  • 提出後に、不鮮明と言われた：指定の下限より、小さくしていないか、確認します。

よくある質問

提出する写真は、何を撮るのがいいですか？

フォームの案内に、従ってください。このツールは、容量と大きさを、調整するだけです。

圧縮で、顔が変わりませんか？

見た目に影響の少ない範囲で、調整されます。極端に下げると、ぼやけます。

まとめ

容量の上限に合わせて、大きさと画質を、段階的に下げます。顔がはっきり見えるかを、いつも確認しましょう。

画像を圧縮・サイズ変更を使う（無料）

あわせて使えるツール

  • 画像の切り抜き・回転：画像を、好きな範囲や比率で切り抜きます。回転もできます。
  • 画像の形式を変換（JPG・PNG・WebP）：画像をJPG・PNG・WebPに、まとめて変換します。
  • 写真をPDFに変換：複数の写真を、順番どおりに1つのPDFへ。回転、並べ替え、サイズ指定ができます。

Adjusting File Size and Dimensions of ID and Portrait Photos

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Check the required pixel size and file limit first
  • Reduce dimensions to fit the size
  • If the ratio differs, crop to adjust

When you upload an ID or portrait photo to an online application form, it may say "size up to X KB" or "dimensions X px". Here is how to bring a photo close to the specification with Compress & Resize Images.

First, check the specification

  • The file size limit (KB, MB)
  • Any requirement for image dimensions (pixels, width and height)
  • The format (JPEG only, for example)
  • Rules about background colour and how the subject appears

What this tool can do

  • Lower the quality to reduce the file size
  • Shrink the longer side to one of 2000, 1600, 1200 or 800 px
  • Choose JPEG or WebP

The aspect ratio does not change, so to match exact pixel dimensions use the cropping or sizing tool.

Steps

  1. With "Choose images", select the photo.
  2. Set "Format" to JPEG.
  3. Start with "Size (longer side)" at "1200px".
  4. Set "Quality" to "Normal".
  5. Press "Compress" and check the file size.
  6. If it exceeds the limit, lower it to "800px" or "Small file".
Having the face clearly visible matters most. Make sure the features do not blur from making it too small.

Size guides

  • Under 100 KB: try "800px" plus "Normal"
  • Under 200 KB: "1200px" plus "Normal"
  • Under 500 KB: "1600px" plus "Normal"

Things to watch

  • Is the face blurry?: zoom in and check that the eyes, nose and mouth are crisp.
  • Background and shadows: compression cannot fix them. You would need to retake the photo.
  • Aspect ratio: if one is specified, set it first by cropping.

Combining with cropping

  1. Use the cropping tool to match the required aspect ratio
  2. Use this tool to bring the size under the limit

In this order you remove unneeded parts first, which is more efficient.

Common stumbling blocks

  • It does not fit the specified size: lower the dimensions further.
  • It does not reach the specified pixel count: this tool offers five choices for the longer side. For pixel specifications, use the resizing tool.
  • You were told it is unclear after submitting: check you did not go below the specified minimum.

Frequently asked questions

What kind of photo should I submit?

Follow the form's guidance. This tool only adjusts file size and dimensions.

Does compression change the face?

It adjusts within a range that barely affects the look. Lowering it too far makes it blurry.

Summary

Lower the dimensions and quality step by step to meet the limit. Always check that the face is clearly visible.
