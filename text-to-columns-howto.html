文字を区切り文字で列に分けるやり方（無料）

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • 文字を貼る
  • 区切りを入れる
  • コピーする

1つのセルに「東京,大阪,名古屋」のように、まとめて入ってしまった文字。これを列に分けたい。文字を区切り文字で列に分ける は、区切り文字で文字を分けて、Excelに貼れる表にするツールです。入力は、この端末の中で処理され、外には送られません。

手順

  1. 「分けたい文字」の欄に、文字を貼り付けます。
  2. 「区切り文字（, や ; など）」に、区切りの文字を入れます。
  3. 「列に分けた表」に、結果が表示されます。
  4. 「結果をコピー」を押して、Excelに貼り付けます。
結果の下に「行×列」が表示されます（例：2×3）。

区切り文字の例

  • カンマ：,
  • セミコロン：;
  • 縦棒：|
  • スラッシュ：/
  • 2文字以上でも可（例：「 - 」）

仕組み

1行ごとに、区切り文字で分けます。複数行を貼ると、行ごとに処理されます。

  • 例：「A,80,東京」→ 3列（A、80、東京）

向いている場面

  • 1つのセルにまとまった文字を、列に分けたい
  • カンマ区切りのデータを、表にしたい
  • ExcelやスプレッドシートのCSVを、整えたい

例

「A,80,東京」「B,92,大阪」の2行を、カンマで分けると、2行3列の表になった。

つまずきやすい点

  • 「区切り文字を入れてください。」と出る：区切り文字の欄が空。
  • 区切りが見つからない：全体が1列のままになる。

タブで区切りたいときは？

タブそのものを、区切り文字の欄に貼り付けます。

まとめ

How to Split Text into Columns by a Delimiter (Free)

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Paste the text
  • Enter the delimiter
  • Copy it

Text crammed into one cell like "Tokyo,Osaka,Nagoya". You want it in columns. Split Text into Columns by a Delimiter splits text by a delimiter into a table Excel can take. Input is processed inside this device and not sent outside.

Steps

  1. Paste text into "Text to split".
  2. Enter the separator in "Delimiter (such as , or ;)".
  3. The result appears in "Table split into columns".
  4. Press "Copy result" and paste into Excel.
Below the result, "Rows × columns" is shown (e.g. 2×3).

Delimiter examples

  • Comma: ,
  • Semicolon: ;
  • Vertical bar: |
  • Slash: /
  • Two or more characters work too (e.g. " - ")

How it works

Each line is split by the delimiter. If you paste several lines, each is processed.

  • Example: "A,80,Tokyo" → 3 columns (A, 80, Tokyo)

Good for

  • Splitting text packed into one cell into columns
  • Turning comma-separated data into a table
  • Tidying CSV from Excel or spreadsheets

Example

Splitting the two lines "A,80,Tokyo" and "B,92,Osaka" by comma gave a 2-row, 3-column table.

Common stumbling blocks

  • "Please enter a delimiter." appears: the delimiter field is empty.
  • The delimiter isn't found: everything stays in one column.

Frequently asked questions

What if I want to split by tab?

Paste the tab itself into the delimiter field.
