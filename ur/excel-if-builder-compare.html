موازنے کی علامتیں

IF conditions are written with comparison operators, like "A2>=60". Here is what the six operators selectable in "Comparison" in Build an IF Formula mean.

The six operators

  • >=: or more (includes the right-hand value)
  • >: greater than (excludes the right-hand value)
  • <=: or less (includes the right-hand value)
  • <: less than (excludes the right-hand value)
  • =: equal
  • <>: not equal

مراحل

  1. Enter the cell to judge in "Cell to test".
  2. Choose an operator in "Comparison".
  3. Enter the threshold in "Value to compare".
  4. Check the condition part of the formula.
"Or more" and "greater than" differ in whether the boundary value is included.

Mapping to plain language

  • 60 or more → A2>=60
  • greater than 60 → A2>60
  • 60 or less → A2<=60
  • less than 60 → A2<60
  • same as 60 → A2=60
  • not 60 → A2<>60

Forms of the value to compare

  • Numbers: 60
  • Text: entering "Tokyo" adds quotes automatically
  • Other cells: entering "B2" compares with that cell

Examples

  • "Order" if stock is 10 or less: =IF(A2<=10,"Order","")
  • "Target" if region is "Tokyo": =IF(A2="Tokyo","Target","")
  • "Incomplete" if status isn't "Done": =IF(A2<>"Done","Incomplete","Done")

ان کے لیے موزوں

  • Comparing with a passing line
  • Comparing with deadlines or targets
  • Comparing with other cells' values

Comparing with other cells

Entering "B2" as the value gives "A2>=B2", a comparison between cell values. Using a target cell means you needn't edit the formula when the threshold changes.

Common stumbling blocks

  • Writing ">=" as "=>": "=>" errors. Write ">=".
  • Comparing text size: text compares in dictionary order, differing from numbers.
  • Number as text: if "60" is text, it can't be compared with the number 60.

Frequently asked questions

Is case distinguished?

Not with "=". To distinguish, use the EXACT function.
