白紙ページを削除できないときの対処

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • パスワードを確認
  • すべては削除できない
  • 別のブラウザで試す

白紙の削除がうまくいかない。白紙が見つからない、全部選ばれる、保存できない。PDFの白紙ページを自動で見つけて削除 で起こりやすい困りごとと、対処法です。

1. 白紙が見つからない

  • 「白紙と見なす基準」を「ゆるめ」にする。
  • 影、汚れ、裏写りがないか確認する。
  • タップで、白紙のページを選ぶ。

2. 文字があるページが選ばれる

  • 基準を「きびしい」にする。
  • 選ばれたページをタップして、選びを外す。

3. 全部のページが選ばれた

  • 「選択をすべて外す」を押して、必要なページだけ選ぶ。
  • スキャンが全体に薄いPDFでは、基準を「きびしい」にする。

4. 保存してもページ数が減らない

  • 「選んだページを削除してPDFを作る」を押す前に、選択されているか確認する。
  • 保存したPDFを、開き直して確認する。

5. 削除したのに、白紙が残る

  • 白紙と判定されなかったページです。基準を変えるか、手動で選びます。

6. 処理が遅い

  • ページ数が多いと、時間がかかります。しばらく待ちます。
  • 非常に多い場合は、PDFを分けて処理します。

7. パスワード付きのPDFで、開けない

先にパスワードを解除します。

8. 必要なページを消してしまった

保存したPDFからは戻せません。元のPDFからやり直します。

確認の順番

  1. 基準を確認する。
  2. 選ばれたページを目で確認する。
  3. プレビューでページ数を確認する。
  4. 保存して、開き直す。
元のPDFは、別の名前で残しておきます。

つまずきやすい点

  • スマホで重い：ページ数が多いと、端末の性能に影響します。分けて処理します。
  • 選択の画面が崩れる：画面を再読み込みして、やり直します。

よくある質問

白紙以外を、誤って選んでも安全ですか？

元のPDFは変わりません。保存前なら、選び直せます。

まとめ

基準を変えて試し、選ばれたページを目で確認。元のPDFは必ず残しましょう。

What to Do If You Can't Remove Blank Pages

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Check for a password
  • You can't delete every page
  • Try another browser

Removing blanks is not going well: no blanks are found, everything is selected, or it will not save. These are the problems that commonly occur with Find and Remove Blank Pages in a PDF and how to deal with them.

1. No blanks are found

  • Set the "Standard for treating a page as blank" to "Loose".
  • Check for shadows, dirt and show-through.
  • Tap to select the blank pages.

2. Pages with text are selected

  • Set the standard to "Strict".
  • Tap the selected pages to deselect them.

3. All pages were selected

  • Press "Clear all" and select only the pages you need.
  • For PDFs whose scan is faint overall, set the standard to "Strict".

4. The page count does not drop after saving

  • Before pressing "Delete selected pages and make PDF", check that pages are selected.
  • Reopen the saved PDF and check.

5. Blanks remain after deleting

Those pages were not judged blank. Change the standard or select them manually.

6. Processing is slow

  • Many pages take time. Wait a while.
  • For very many pages, split the PDF and process in parts.

7. A password-protected PDF cannot be opened

Remove the password first.

8. You deleted a page you needed

It cannot be restored from the saved PDF. Start again from the original PDF.

Order of checking

  1. Check the standard.
  2. Check the selected pages by eye.
  3. Check the page count in the preview.
  4. Save and reopen.
Keep the original PDF under a different name.

Common stumbling blocks

  • Heavy on a phone: many pages affect device performance. Process in parts.
  • The selection screen breaks: reload the screen and start again.

Frequently asked questions

Is it safe if I select a non-blank page by mistake?

The original PDF does not change. Before saving, you can reselect.

Summary

Try changing the standard and check selected pages by eye. Always keep the original PDF.
