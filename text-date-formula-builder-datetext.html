日付を文字にする

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • DATETEXTを選ぶ
  • セルを入れる
  • コピーする

日付を、「2026-10-01」のような文字にしたい。ファイル名に使う、他のシステムに渡す、数字の桁を保つ。そんなときは、TEXT関数で文字にします。文字を日付や数に変える式を作る の「DATETEXT」と「TEXTNUM」で作れます。

手順

  1. 「種類」で「DATETEXT」か「TEXTNUM」を選ぶ。
  2. 「変えるセル」を入れる。
  3. 式をコピーして貼る。
結果は文字になるため、そのままでは日付として計算できません。

例

  • DATETEXT：=TEXT(A2,"yyyy-mm-dd")　→ 2026-10-01
  • TEXTNUM：=TEXT(A2,"0")　→ 数値を、桁の揃った文字に

書式の例

TEXT関数の、2つ目の引数を書き換えると、いろいろな形になります。

  • "yyyy/m/d"：2026/10/1
  • "yyyymmdd"：20261001
  • "yyyy年m月d日"：2026年10月1日
  • "m/d"：10/1
  • "00000"：5桁に、先頭を0で埋める

先頭の0を保つ

郵便番号や、社員番号の先頭の0は、数値のままだと消えます。TEXTNUMで、文字にしておきます。

  • 例：=TEXT(A2,"0000000")

向いている場面

  • 日付を含むファイル名や、ID
  • 他のシステムに渡すデータの形式
  • 文字のつなぎ（「期限：」と日付を、つなぐ）

文章に日付を入れる

文章の中に日付を入れると、数字（46296）になってしまいます。TEXTで包みます。

  • 例：="期限：" & TEXT(A2,"yyyy/m/d")

例

「2026-10-01_報告書」のような、日付付きのファイル名を、表から作りたかった。DATETEXTで日付を文字にして、「_報告書」をつなげた。

つまずきやすい点

  • 書式の文字は環境で違う：言語設定により、「yyyy」が「jjjj」などになる場合がある。
  • Googleスプレッドシート：書式の文字は、概ね同じ。

よくある質問

「DATEVALUE」を使います。

Turning a Date into Text

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Choose DATETEXT
  • Enter the cell
  • Copy it

You want a date as text like "2026-10-01": for file names, handing to other systems, or keeping digit widths. Convert with TEXT. "DATETEXT" and "TEXTNUM" in Build a Text to Date Formula build these.

Steps

  1. Choose "DATETEXT" or "TEXTNUM" in "Type".
  2. Enter the "Cell to convert".
  3. Copy the formula and paste.
The result is text, so it can't be calculated as a date as is.

Examples

  • DATETEXT: =TEXT(A2,"yyyy-mm-dd") → 2026-10-01
  • TEXTNUM: =TEXT(A2,"0") → a number as text with fixed digits

Format examples

Rewriting TEXT's second argument gives various shapes.

  • "yyyy/m/d": 2026/10/1
  • "yyyymmdd": 20261001
  • "yyyy年m月d日": 2026年10月1日
  • "m/d": 10/1
  • "00000": zero-padded to 5 digits

Keeping leading zeros

Leading zeros in postal codes or employee numbers vanish if left numeric. Make them text with TEXTNUM.

  • Example: =TEXT(A2,"0000000")

Good for

  • File names and IDs containing dates
  • Data formats handed to other systems
  • Joining text ("Due: " plus a date)

Putting dates in sentences

A date in a sentence turns into a number (46296). Wrap with TEXT.

  • Example: ="Due: " & TEXT(A2,"yyyy/m/d")

Example

Wanted dated file names like "2026-10-01_report" built from a table. DATETEXT made the date text, then "_report" was appended.

Common stumbling blocks

  • Format letters vary by environment: language settings may turn "yyyy" into "jjjj" and the like.
  • Google Sheets: format letters are broadly the same.
