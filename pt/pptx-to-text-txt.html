Salvar o texto dos slides como arquivo .txt

Publicado em: 19 out 2026 | Atualizado em: 19 out 2026 | Sobre (em japonês)

Pontos principais
  • Escolher
  • Salvar

You want to save the text of PowerPoint slides as a plain text file (.txt) without formatting. "Save as text" in Extract Text from PowerPoint turns the extracted text into a text file.

Passos

  1. With "Choose one .pptx file", choose the file.
  2. If needed, tick "Include speaker notes".
  3. Check the "Extracted text".
  4. Press "Save as text" to save.
Only text is saved. Images, formatting and animations are not included.

Benefits of a text file

  • Opens on any device
  • Small size
  • No broken formatting
  • Easy to search and import into documents
  • Suited to long-term storage

Bom para

  • Backing up the contents of material
  • Analysing the material's text in other software
  • Storing in a searchable form
  • Material for reviewing or proofreading text

Conferir depois de salvar

  • Whether Japanese is garbled
  • Whether slide breaks are clear
  • If notes are included, whether the notes' positions are appropriate

About character encoding

The saved text is in the common UTF-8 form. Opening it with old software may garble it. In that case choose the encoding in the software's settings or open it in other software.

Nome do arquivo

The file name saved is decided by the browser's settings or at saving. Change it later to something clear (for example "FY2026_training_material.txt").

Keep it with the original material

Text alone doesn't keep the contents of figures and images. For important material, keep the original PowerPoint too.

Exemplo

Wanted to make the text of 30 past training materials searchable. Extracted text one file at a time and saved as text. Searching within the folder let me find materials by keyword.

Common stumbling blocks

  • Too much text to handle: headings are attached per slide, so use them to divide.
  • Figure explanations are missing: text inside figures and images isn't included.

Frequently asked questions

Can the saved text be returned to PowerPoint?

It can't be returned to the original slides. Only the text is saved.
