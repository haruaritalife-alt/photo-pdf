    Cómo se usa

    1. Pulsa «Elegir un PDF» y selecciona un PDF. Sus páginas aparecen como imágenes pequeñas.
    2. Usa Antes / Después para cambiar el orden, Girar para corregir la dirección y Eliminar para quitar una página.
    3. Pulsa «Crear el PDF» y guárdalo.

    Cuándo resulta útil

    • Algunas páginas de un PDF escaneado están de lado
    • Quieres cambiar el orden de las páginas
    • Quieres quitar páginas en blanco

    Preguntas frecuentes

    ¿Se sube mi PDF a algún sitio?

    No. Todo se procesa dentro del navegador de tu dispositivo.

    ¿Baja la calidad?

    No. El contenido de las páginas no cambia; solo cambian la dirección y el orden.

    ¿Puedo usar un PDF protegido con contraseña?

    No. Quita primero la contraseña.
