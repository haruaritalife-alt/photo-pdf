セルの場所を文字で出す

公開日：2026年10月19日｜最終更新：2026年10月19日｜運営者情報

この記事のポイント
  • ADDRESSを選ぶ
  • 行と列の番号を入れる
  • コピーする

行番号と列番号から、「B3」のようなセルの場所を文字で出したい。それがADDRESSです。INDIRECTの式を作る の「ADDRESS」で作れます。

手順

  1. 「種類」で「ADDRESS」を選ぶ。
  2. 「行のずらし方」に行番号、「列のずらし方」に列番号を入れる。
  3. 式をコピーして貼る。
この種類では、2つの数が、そのまま行番号と列番号になります。

例

3行目、2列目の場所です。

  • =INDIRECT(ADDRESS(3,2))

これは、B3の値を返します。

別の書き方の式

2つ目は、場所そのものを文字で出す式です。

  • =ADDRESS(3,2,4)

結果は「B3」の文字です。最後の4は、$を付けない相対参照の指定です。

表示形式の指定

ADDRESSの3つ目の数で、$の付き方を選べます。

  • 1：$B$3（行も列も固定）
  • 2：B$3（行だけ固定）
  • 3：$B3（列だけ固定）
  • 4：B3（固定しない）

向いている場面

  • 最大値のある場所を、文字で出す
  • 場所を文字として、別のセルに残したい
  • 行・列の番号から、値を読む

場所を文字で出す

最後の行の場所を調べる、といった使い方に便利です。

  • 例：=ADDRESS(MATCH(MAX(B:B),B:B,0),2,4)

例

最大の売上がどのセルにあるか、場所を知りたかった。MATCHで行番号を出し、ADDRESSで「B15」のように表示できた。

つまずきやすい点

  • 「入力の形が正しくありません。」：行と列が、整数でない。
  • 0以下の数：行や列は、1以上。

よくある質問

ADDRESSだけで値が読めますか？

ADDRESSは、場所の文字を出すだけです。値を読むには、INDIRECTと組み合わせます。

まとめ

番号から場所を出すなら、ADDRESS。値を読むなら、INDIRECTと組み合わせる。

INDIRECTの式を作るを使う（無料）

  • IMPORTRANGEの式を作る：IMPORTRANGEの式を作ります。

Showing a Cell Location as Text

Published: Oct 19, 2026 | Updated: Oct 19, 2026 | About (Japanese)

Key points
  • Choose ADDRESS
  • Enter the row and column numbers
  • Copy it

You want a location like "B3" as text from row and column numbers. That's ADDRESS. "ADDRESS" in Build an INDIRECT Formula builds it.

Steps

  1. Choose "ADDRESS" in "Type".
  2. Enter the row number in "Row offset" and the column number in "Column offset".
  3. Copy the formula and paste.
In this type the two numbers are used directly as the row and column numbers.

Example

The location at row 3, column 2:

  • =INDIRECT(ADDRESS(3,2))

This returns B3's value.

The alternative formula

The second gives the location itself as text.

  • =ADDRESS(3,2,4)

The result is the text "B3". The trailing 4 specifies relative reference without $.

Choosing the reference style

ADDRESS's third number chooses how $ appears.

  • 1: $B$3 (row and column fixed)
  • 2: B$3 (row fixed)
  • 3: $B3 (column fixed)
  • 4: B3 (nothing fixed)

Good for

  • Showing as text where the maximum is
  • Keeping a location as text in another cell
  • Reading a value from row and column numbers

Showing the location as text

Handy for finding where, say, the last row is.

  • Example: =ADDRESS(MATCH(MAX(B:B),B:B,0),2,4)

Example

Wanted to know which cell holds the top sales. MATCH gave the row number and ADDRESS displayed it like "B15".

Common stumbling blocks

  • "The input is not valid.": row or column isn't an integer.
  • Zero or below: rows and columns are 1 or greater.

Frequently asked questions

Can ADDRESS alone read a value?

ADDRESS only outputs the location text. To read the value, combine with INDIRECT.

Summary

To get a location from numbers, use ADDRESS; to read the value, combine with INDIRECT.
