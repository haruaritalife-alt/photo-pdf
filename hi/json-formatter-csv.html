JSON और CSV के बीच बदलना

प्रकाशित: 19 अक्तू॰ 2026 | अपडेट: 19 अक्तू॰ 2026 | परिचय (जापानी)

मुख्य बातें
  • फ़ॉर्मैट
  • बदलें

JSON is convenient for programs but a table suits people totalling things. Conversely, table data needs to be JSON to be handed to a program. Here is how to combine JSON formatted with Format and Validate JSON and the CSV conversion tool.

Flow (JSON → table)

  1. Format the JSON with this tool and check it's correct.
  2. Paste the tidy JSON into "JSON → CSV" of the CSV/JSON conversion tool.
  3. Convert to CSV, save and open in Excel.

Flow (table → JSON)

  1. Copy the Excel table and convert it with "CSV → JSON" in the CSV/JSON conversion tool.
  2. Format the resulting JSON with this tool and check it's correct.
  3. If needed, compress with "Make one line".
Checking that the JSON syntax is correct before converting prevents conversion errors.

JSON shapes that can be converted

A form where data with the same items is lined up is easy to convert to a table. Nested parts, when converted to a table, go into one cell as text.

Benefits of combining

  • Conversion errors can be prevented in advance
  • You can understand the data's structure through formatting before converting
  • The converted JSON can be formatted at once

इनके लिए अच्छा

  • Totalling API results in Excel
  • Turning Excel data into web app data
  • Managing configuration data as a table

Cautions

  • What a table can handle is flat structures. Flatten deep nesting first, or extract the needed parts.
  • The distinction between numbers and strings can change in conversion.

उदाहरण

Formatted JSON from an API with this tool to see its structure. Finding that the needed items were outside the nesting, it converted straight to CSV and could be totalled in Excel.

Common stumbling blocks

  • Nested items go into one cell: reshape first.
  • Date and number formats change: set the format on the Excel side.
  • Garbled text: specify the encoding when opening in Excel.

Frequently asked questions

Which tool comes first?

On receiving JSON, first format and check. Then convert.

सारांश
