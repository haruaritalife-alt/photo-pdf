IMPORTRANGE कैसे लिखें (अपने आप बनता है, मुफ़्त)

प्रकाशित: 19 अक्तू॰ 2026 | अपडेट: 19 अक्तू॰ 2026 | परिचय (जापानी)

मुख्य बातें
  • URL पेस्ट करें
  • रेंज दर्ज करें
  • फ़ॉर्मूला कॉपी करें

You want to bring data from another Google spreadsheet into the current one. The function for that is IMPORTRANGE. Build an IMPORTRANGE Formula builds that formula from just the spreadsheet URL, sheet name and range. Input is processed inside this device and not sent outside.

चरण

  1. Paste the source spreadsheet's URL in "Spreadsheet URL".
  2. Enter the source sheet's name in "Sheet name".
  3. Enter the range to import in "Range (such as A1:C10)".
  4. The "IMPORTRANGE formula" and the "formula that blanks on error" appear. Press "Copy the first" or "Copy the second".
Only the spreadsheet ID is extracted from the URL automatically.

उदाहरण

Importing A1:C10 of the source sheet "Sales".

  • First: =IMPORTRANGE("https://docs.google.com/spreadsheets/d/(ID)","Sales!A1:C10")
  • Second: =IFERROR(IMPORTRANGE(...),"")

IMPORTRANGE's two arguments

  1. The spreadsheet URL (or ID)
  2. Text in the form "SheetName!Range"

इनके लिए अच्छा

  • Gathering per-department spreadsheets in one place
  • Using another file's data in summaries
  • Always using shared source data in its latest form

First use

After pasting, "#REF!" appears with an "Allow access" button. Allowing it displays the data.

Common stumbling blocks

  • "The input is not valid." appears: no ID is found in the URL, the sheet name or range is empty, or the range form is wrong.
  • #REF! appears: access isn't allowed yet, or the source sheet name or range is wrong.

Frequently asked questions

Do changes to the source data carry over?

Yes. When the source updates, it reflects automatically.
