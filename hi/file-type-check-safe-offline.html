फ़ाइल अपलोड किए बिना उसका प्रकार जाँचना

प्रकाशित: 19 अक्तू॰ 2026 | अपडेट: 19 अक्तू॰ 2026 | परिचय (जापानी)

मुख्य बातें
  • फ़ाइलें चुनें
  • नतीजा देखें
  • नतीजे का इस्तेमाल करें

A file of unknown identity may be a work document or a personal photo: something important. Uploading it to an outside service to check is worrying. Check a File's Real Type (Extension vs Contents) identifies types inside the browser without sending files outside.

यह कैसे काम करता है

  • The file you choose is loaded only inside your browser.
  • Only the beginning part of the file is used for identification.
  • Neither the file nor the verdict is sent to a server or stored.

चरण

  1. Choose files with "Choose files".
  2. नतीजा जाँचें।
  3. If needed, copy with "Copy result".
Files are processed inside this device. They are sent nowhere.

How to confirm

  • It works even with the connection cut (airplane mode).
  • Browser developer tools can confirm that no file is sent.

Still be careful about

  • Files of unknown origin: even if the type is known, it isn't necessarily safe. Don't open carelessly.
  • Shared computers: when finished, delete the files.
  • Copied results: if file names contain personal information, take care where you paste.
  • Limits of identification: this tool does not scan for viruses.

Uses it suits

  • Pre-checking received files
  • Finding the type of confidential files
  • Organising family photos and documents

उदाहरण

A company shared folder had many extensionless files. Didn't want to upload them to an outside service, but since it's processed in the browser, I could check with peace of mind.

Common stumbling blocks

  • The result disappeared when closing the page: by design nothing is saved. Copy it if needed.
  • Heavy with many files: reduce the number to check.

Frequently asked questions

Can the operator see the files?

No. Files are not sent outside.

सारांश

Files are not sent outside. Even if the type is known, check safety separately.

“फ़ाइल का असली प्रकार जाँचें (एक्सटेंशन बनाम सामग्री)” इस्तेमाल करें (मुफ़्त)

इसके साथ काम आने वाले टूल

  • फ़ाइल का हैश (SHA-256) जाँचें: फ़ाइल का हैश निकालें और उसकी तुलना करें।
  • ZIP फ़ाइल खोलें (अनज़िप): देखें कि ZIP फ़ाइल में क्या है और ज़रूरी फ़ाइलें निकालें।
  • टेक्स्ट एन्कोडिंग बदलें (बिगड़े अक्षर ठीक करें): अक्षर बिगड़ने की समस्या ठीक करने के लिए टेक्स्ट फ़ाइलों को Shift_JIS, UTF-8, EUC-JP आदि के बीच बदलें।

अगर यह गाइड काम आया हो, तो एक छोटी टिप हमारे लिए बहुत मायने रखेगी।

टिप भेजें (¥300)उपहार भेजें (Amazon विशलिस्ट)

इस टूल के और गाइड

  • फ़ाइल का असली प्रकार कैसे जानें (एक्सटेंशन बनाम सामग्री)
  • जो फ़ाइल नहीं खुलती वह असल में क्या है, यह पता करना
  • एक्सटेंशन और सामग्री अलग हों तो किन बातों का ध्यान रखें
  • docx, xlsx और pptx में फ़र्क करना
  • जाँचना कि न खुलने वाली फ़ोटो HEIC है या नहीं
  • कौन से प्रकार पहचाने जा सकते हैं और सीमाएँ क्या हैं
