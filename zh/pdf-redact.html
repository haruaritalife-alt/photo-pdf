把 PDF 的一部分涂黑

把不想让人看到的内容，确确实实地藏起来。

你的 PDF 不会被上传。所有处理都只在这台设备上进行。

  1. 1选择 PDF
  2. 2在要涂黑的部分上拖动
  3. 3保存 PDF

使用方法

  1. 点击“选择 PDF”，选中一个 PDF。
  2. 显示一个页面，用手指或鼠标在想涂黑的部分上拖动。在手机上，请先点击“选择范围”。
  3. 在其他页面上也这样做。想给每一页的同一位置涂黑，就点击“对所有页面应用相同范围”。
  4. 点击“涂黑并生成 PDF”，查看预览，并保存 PDF。

注意事项

  • 涂黑的页面会变成图片。这些页面的文字将无法再被选择或搜索。
  • 下面的文字不会留在文件里。没有涂黑的页面保持原样。
  • 保存后，打开它，确认黑色方块下面的文字无法被选中。
  • 不支持带密码的 PDF。

常见问题

我的 PDF 会被上传到哪里吗？

不会。所有处理都在你设备上的浏览器内完成。

我的原始 PDF 会被改动吗？

不会。涂黑后的 PDF 会另外保存。

可以撤销涂黑吗？

保存之前，可以用“撤销上一步”。已保存的 PDF 里的涂黑无法撤销。请保留你的原始 PDF。
