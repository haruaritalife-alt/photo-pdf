给 PDF 添加页眉和页脚

每一页都加上标题、日期和页码。

你的 PDF 不会被上传。所有处理都只在这台设备上进行。

  1. 1选择 PDF
  2. 2输入文字
  3. 3保存 PDF

使用方法

  1. 点击“选择 PDF”，选中一个 PDF。
  2. 在想放的位置对应的栏里输入文字（页眉＝上方，页脚＝下方）。
  3. 选择文字大小、不加的页面，以及距离边缘的距离。
  4. 点“添加文字并生成 PDF”，查看预览后保存。

工作原理

  • 写上 {n} 就会插入页码。{total} 是总页数，{date} 是今天的日期。
  • 文字会以图片的形式叠加到每一页上。

注意事项

  • 添加的文字无法选择或搜索。
  • 保存之后无法撤销所添加的内容，所以请保留原始 PDF。
  • 不支持带密码的 PDF。

常见问题

我的 PDF 会被上传到哪里吗？

不会。所有处理都在你设备上的浏览器内完成。

可以添加日文文字吗？

可以。文字是用你设备上的字体绘制的，所以日文也没问题。

只想要页码怎么办？

用“给 PDF 添加页码”更简单。这个工具还能添加文件名称或日期。
