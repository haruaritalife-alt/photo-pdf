@@ filter-formula-builder
## Before you build a FILTER formula
### When it helps
- You want to pull only the rows that match a condition from a table
- You want the extracted rows sorted from smallest to largest
- You want only the matching data on another sheet
### How the formula is built
- Enter the range of data to extract
- Enter the column to test, the comparison and the value to compare with
- A formula with SORT, which sorts from smallest first, is built at the same time
### Things to know
If you leave the "if nothing found" display empty, that argument is not added. FILTER works in recent Excel and in Google Sheets.

@@ google-calendar-link
## Before you make a calendar link
### When it helps
- You want people to add a meeting or event to their calendar in one click
- You want to put an event link in an email or on a web page
- You want to hand out an event as an ICS file
### How it works
Opening the link shows the Google Calendar screen for adding the event. If you save the ICS file, it can also be imported into Apple Calendar, Outlook and others.
### Things to know
- If the end time is earlier than or equal to the start, it is treated as a time on the next day
- Times are shown in the time zone of the calendar of whoever opens the link

@@ google-drive-direct-link
## Before you convert Drive links to direct links
### When it helps
- You want to use a Drive file directly in a blog or email
- You want to show an image on a page
- You want a download to start as soon as the link is opened
### How it works
It takes the file ID out of the share link and builds a link that downloads directly. The image link is for showing an image on a page.
### Things to know
- Links only open if the file's sharing setting is "Anyone with the link"
- Folder links are not supported. Use a link to a file

@@ google-export-link
## Before you make an export link
### When it helps
- You want people to save a Google file as PDF or Office format right away
- You want the other person to make their own copy

@@ heic-to-jpg
## Before you convert HEIC
### What is HEIC?
It is the default photo format on iPhone. Files are small and quality stays high. But Windows PCs, Android and many sign-up sites may not open it or accept it as an upload. As JPG it works almost everywhere.
### When it helps
- A photo will not upload to an application form
- An iPhone photo will not open on a Windows PC
- You want to put photos into a PDF
### Good to know
- You can select several at once. With several, you can also save them together as a ZIP
- Converted images do not contain the shooting date or location data (Exif)
- You can also make the iPhone shoot in JPG from the start (Settings, Camera, Formats, Most Compatible)

@@ html-escape
## Before you escape HTML
### When it helps
- You want to show HTML code on screen as it is
- You want to turn escaped code back into readable form
- You want to put code in a blog or document
### How it works
It changes the five characters that have a special meaning in HTML into a form that is safe to display. The converted code can be turned back to the original. Numeric character references (such as the copyright sign) can also be turned back.
### Things to know
Escaping is a conversion for display. Also check security measures in the system where you use it.

@@ id-photo
## Before you make an ID photo
### Available sizes
- 30 x 40 mm (Japanese résumé)
- 35 x 45 mm (passport and My Number card)
- 30 x 24 mm (driver's licence)
### Tips for a clean result
- Choose a photo where the face is clearly visible
- Take it in a bright place against a plain wall
- Use zoom, left-right and up-down to adjust the size and position of the face
### Printing and notes
- Choose "Arrange on L size (89 x 127 mm)" to make printing at a convenience store or photo shop easier. Print at 100%, without scaling
- The background colour cannot be changed. Take the photo against a plain wall
- Check whether the place you submit to has rules for size or background colour

@@ image-color-picker
## Before you pick colours from an image

@@ image-compress
## Before you compress an image
### When it helps
- You need to meet the size limit of an application form
- You want to send a large photo by email or chat
- You want to make images on a website lighter
### Tips for making it smaller
- For photos, setting the longer side to about 1600 px alone makes the file much smaller
- Try "Normal" quality first, and use "Light" only if the file is still large
- Screenshots and diagrams can get blurry text as JPEG. Check before you use them
### Choosing a format
JPEG turns transparent areas white. WebP cannot be created in some browsers such as Safari, and then PNG is saved instead.
### Good to know
Your original image is not changed. A new file is saved. Rebuilt images do not contain the shooting date or location data (Exif).

@@ image-convert
## Before you convert image formats
### Choosing a format
- JPG: for photos. Files are small. Transparency is not kept
- PNG: for diagrams and text. Keeps transparency. Files are larger
- WebP: small and clean. But some places you submit to, and old software, may not support it
### When it helps
- An application form accepts only JPG
- You want to keep a logo with a transparent background as PNG
- You want to make website images lighter with WebP
### Good to know
- You can select up to 60 images at a time
- iPhone HEIC images can be converted in browsers that can open HEIC, such as Safari. In other browsers they show as "images that could not be loaded"
- When saved as JPG, transparent areas become white

@@ image-crop
## Before you crop an image
### When it helps
- You want to cut away unwanted parts of a photo
- You want a square (1:1) image, such as for a social media icon
- A photo came out sideways and you want to rotate it
### Tips
- Drag over the image to make an area. Drag the corners to resize and drag inside to move
- Choose a ratio (1:1, 4:3 and so on) to lock the area to that ratio
- If the orientation is wrong, fix it first with "Rotate"
### About quality
The cropped area is saved with its original pixels. Only when saving as JPG is it slightly compressed. Your original is not changed. A new file is saved.

@@ image-exif-remove
## Before you remove location data
### Why remove it
Phone cameras may automatically record where and when a photo was taken (GPS) inside the photo. If you post it as is on social media, your home location and more can become known.
### When it helps
- Before posting a photo on social media or a blog
- Before listing photos of an item on a flea market app
- Before sending a photo to someone you do not know
### Good to know
- The image is redrawn and saved, so the location, date and time, camera name and so on are all removed
- Because it is recompressed when saved, quality may change slightly
- Some social networks remove it on upload, but this is not guaranteed. It is safer to remove it beforehand

@@ image-filter
## Before you edit images with filters
### When it helps
- You want scanned documents to be easier to read
- You want a photo in black and white or sepia
- You want to apply the same effect to several images
### Document mode
Choose "Document (crisp black and white)" to convert to black and white and then strengthen the contrast so text is easier to read. It suits scanned documents and photos of documents.
### Things to know
- The colours of a photo cannot be restored. Keep the original image
- For HEIC files, first convert to JPG with <a href="/heic-to-jpg.html">HEIC to JPG</a>
- When you select several images, they are all processed with the same settings

@@ image-mosaic
## Before you use mosaic or blur
### When it helps
- You want to hide things that appear in the background before posting on social media
- You want to hide a licence plate or a nameplate
- You want to hide personal information in a screenshot
### Which to choose
Blacking out is the most reliable. If the mosaic is weak, the original text can sometimes still be read. With mosaic or blur, the original can sometimes be guessed under some conditions, so use "Black out" for important information.
### Tips
- On a phone, tap "Draw mode" and then draw. Tap again to scroll
- If you draw by mistake, use "Undo one" or "Clear all"
- The original picture under the hidden part is not kept in the saved image. Keep your original image

@@ image-resize
## Before you resize an image
### When it helps
- You want images to be the same pixel size for submission
- You want to shrink images for a website or social media
- You want several images at the same size
### How size works
Images are enlarged or reduced keeping the aspect ratio. A big enlargement makes the image coarse. Reducing the number of pixels often reduces the file size too. To go smaller still, use <a href="/image-compress.html">Compress or resize images</a>.
### Good to know
- Several images are converted together with the same settings and saved as a ZIP
- For HEIC files, first convert to JPG with <a href="/heic-to-jpg.html">HEIC to JPG</a>
- The orientation of a photo does not change. It is saved the way it looks

@@ image-split
## Before you split an image
### When it helps
- You want to post a tiled image on social media (such as a 3-way split)
- You want to cut a large image into equal pieces
- You want to divide an image into several sheets for printing
### Tip for a 3-way split
Set 3 across and 1 down, then save. When posting to social media, post in descending order of number (from the right) so they line up neatly. Numbers run from the top left to the right, then downward.
### Good to know
- The image is divided into equal pieces across and down. When there are two or more pieces, they are saved together in a ZIP
- If the image is small, each piece after splitting is smaller still
- For HEIC files, first convert to JPG with <a href="/heic-to-jpg.html">HEIC to JPG</a>

@@ image-stitch
## Before you stitch images together
### When it helps
- You want to join screenshots vertically into one image
- You want to line up several photos side by side
- You want to combine step-by-step images into one
### Stitching rules
- When joining vertically, widths are matched to the narrowest image
- When joining side by side, heights are matched to the shortest image
- Images are joined in the order you selected them. To change the order, select them again
### Good to know
- Joining many images makes a large image
- For HEIC files, first convert to JPG with <a href="/heic-to-jpg.html">HEIC to JPG</a>
