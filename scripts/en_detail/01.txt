@@ age-calculator
## Before you use the age calculator
### When it helps
- You want to know someone's age, or how many days old they are, right now
- You want to know the age on a date in the future or the past
- You want to double-check the age field on a form
### How age is counted
- Age here is the completed years: it goes up by one on the birthday
- Change the reference date to see the age on any past or future day
- In the traditional East Asian "counted" age, add one or two to the completed age as a rough guide
### Things to know
- The reference date cannot be earlier than the date of birth
- For people born on February 29, some systems treat March 1 as the birthday in non-leap years

@@ audio-trim
## Before you trim audio
### When it helps
- You only need one part of a recording
- You want to shorten a meeting or lecture recording
- You want a short clip, for example for a ringtone
### Tips
- Listen while you decide, then enter the start and end of the part you keep, in seconds
- Choosing mono halves the file size
### Things to know
- The output is WAV. It keeps full quality, but files are larger than MP3 (about 10 MB per minute)
- Files up to 150 MB are supported
- The sound track of some video files cannot be read

@@ base64-text
## Before you convert text to Base64
### When it helps
- You want to turn text into Base64
- You received Base64 and want to read it as text
- You need to convert non-English text as UTF-8
### Base64 is not encryption
It only represents data with letters, digits and a few symbols. Anyone can reverse it, so never rely on it to protect secrets. Decoding gives readable text only if the original data was text.
### Files
This tool is for text. For files, use <a href="/file-base64.html">File to Base64</a>.

@@ bmi-calculator
## Before you use the BMI calculator
### How it is calculated
- BMI is weight (kg) divided by height (m) squared
- Under the Japan Society for the Study of Obesity criteria, below 18.5 is underweight and 18.5 to under 25 is normal weight
- Standard weight is the weight at BMI 22, which is said to carry the lowest risk of illness
### When it helps
- You want a quick BMI estimate
- You want a rough idea of your standard weight
### Things to know
BMI is only a guide. It does not account for muscle mass, age and so on. Please talk to a doctor about your health or treatment.

@@ char-counter
## Before you use the character counter
### When it helps
- You need to check the length of an application essay or personal statement
- You must meet a character limit for a report or assignment
- You want to know how many Japanese manuscript sheets (400 characters each) the text fills
### Counting rules differ
It shows both "with line breaks and spaces" and "without". Which one counts depends on where you submit, so check their instructions and read the matching number.
### Good to know
- Emoji and similar characters count as one character
- The text you enter is never saved or sent anywhere
- Enter a target length to see how many characters remain

@@ charset-convert
## Before you convert character encoding
### Why text turns into garbage
An encoding is the rule for turning characters into data. Opening a file with the wrong rule produces garbled text. "Auto-detect" can tell UTF-8, Shift_JIS, EUC-JP and others apart.
### When it helps
- A CSV opened in Excel shows garbled text (convert it to "UTF-8 with BOM, for Excel")
- You want to read a file exported from an old system
- You need to match the encoding a system requires
### Things to know
- When converting to Shift_JIS and similar, characters it cannot represent (such as emoji) become "?"
- Files that are not plain text, such as images or PDFs, cannot be converted
- Your original file is not changed. A new file is saved

@@ color-converter
## Before you convert colour codes
### Three formats
- HEX: a 6-digit code such as #2d6cdf (3 digits also work)
- RGB: the strength of red, green and blue (0 to 255)
- HSL: hue, saturation and lightness
### When it helps
- You want to rewrite a web colour in another format
- Your design software and your CSS use different formats
- You want to check the brightness contrast between text and background
### Things to know
Transparency (alpha) is not handled. For rgba() and hsla(), only the colour part is read. The contrast with white or black is a rough guide to how readable text will be.

@@ column-stats
## Before you summarize numbers
### When it helps
- You want quick totals without opening a spreadsheet
- You copied a column from Excel and want its sum or average
### What you get
Count, sum, average, median, minimum and maximum appear right below.
### Pasting rules
- One number per line, or numbers separated by commas or tabs, are all read
- Numbers with thousands separators such as 1,200 are read as numbers
- Anything that is not a number is skipped

@@ compress-pdf
## Before you compress a PDF
### When it helps
- A form or school portal says "PDF up to 1 MB" or "up to 5 MB"
- An email attachment is too large to send
- A PDF made from scans or photos has become too heavy
### When it does not help
- PDFs where you need to select, copy or search text: compression turns each page into an image, so text can no longer be selected
- PDFs that are already small: they will not shrink, and the tool tells you the original is smaller
- Password-protected PDFs: they are not supported
### Choosing quality
Try "Normal" first, and switch to "High" if it is hard to read. When the upload limit is fixed, use "Set a size limit". It adjusts automatically to keep the highest quality that still fits.
### How it differs from other services
Most PDF compression services send your file to a server. This tool works only inside your own device, which makes it easier to use for documents such as résumés and contracts. The trade-off is that long PDFs take longer, especially on phones.

@@ countif-formula-builder
## Before you build a counting formula
### When it helps
- You want to count the rows that match a condition
- You want to know how many cells are empty or filled
- You want a count that ignores duplicates
### Choosing a type
- COUNTIF counts cells that match a condition. COUNTIFS counts cells that match two conditions
- COUNTBLANK counts empty cells. COUNTA counts filled cells
- CONTAINS counts cells that include some text. UNIQUE counts distinct values
### Things to know
When there are empty cells, use the second formula for UNIQUE.

@@ csv-json
## Before you convert between CSV and JSON
### When it helps
- You want table data as JSON for a program
- You want JSON data as a CSV that opens in Excel
- You want to change the delimiter (comma, tab or semicolon)
### Conversion rules
- JSON to CSV turns an array of objects into a table
- Nested JSON stays as text inside the cell
- When saving as CSV, a marker is added at the start so Excel does not garble the text
### Good to know
Very large data can make the page slow. The data you paste is never sent outside your device.

@@ csv-to-xlsx
## Before you convert CSV to Excel
### When it helps
- You want to open a CSV in Excel as it is
- A CSV shows garbled text and you want a proper Excel file
- You want to turn pasted data into Excel right away
### Settings tips
- The delimiter can be detected automatically
- Choose "Enter numbers as numbers" to use them in calculations in Excel
- Numbers that start with 0, such as 007, are kept as text
### Good to know
Formatting and formulas are not included. You get a simple Excel file with values only. Non-English text, including Japanese, displays correctly in the file this tool creates.
