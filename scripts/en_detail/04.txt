@@ image-to-gif
## Before you make an animated GIF
### When it helps
- You want to make a flip-book style animation
- You want to show the steps of a procedure with images in order
- You want a short moving image for social media or a blog
### Settings tips
- Display time per image: the larger it is, the slower the animation
- Width: a smaller width gives a lighter file
- You can change the order with the up arrow
### Good to know
- GIF has at most 256 colours, so photos look a little coarse
- When images differ in size, they are matched with white margins
- GIFs cannot be made from video. Many images or large images take longer

@@ image-to-word
## Before you turn images into Word
### When it helps
- You want to gather images into a Word document
- You want to put each photo on its own page
- You want to prepare images first for pasting into a report
### What you get
- A Word file (.docx) with each selected image on its own page
- Images are automatically sized to fit the page
- You can choose portrait or landscape paper
### Good to know
- Images go in the order you selected them. To change the order, select them again
- Transparent areas become white
- For HEIC files, first convert to JPG with <a href="/heic-to-jpg.html">HEIC to JPG</a>

@@ image-watermark
## Before you add a watermark to an image
### When it helps
- You want to write the purpose, such as "for submission", on a photo of an ID
- You want to make it harder for a photo to be used without permission
- You want the same watermark on several images
### Settings tips
- You can choose position, size, opacity and colour
- If it is hard to see, set the opacity to "Strong" or change the colour
- Several images get the same watermark and are saved as a ZIP
### Things to know
A watermark cannot be removed after saving, so keep the original image. A watermark makes unauthorized use harder, but it cannot prevent it completely.

@@ index-match-builder
## Before you build an INDEX and MATCH formula
### When it helps
- You need a column to the left, which VLOOKUP cannot return
- You want to find a value by both row and column (pulling from a table)
- You want a formula that survives inserted columns
### How the formula works
INDEX returns the value, and MATCH finds its position. Ranges are anchored with $, so the formula does not shift when copied down. A version that shows blank when nothing is found is built too.
### Match types
- EXACT: exact match
- LESS: the closest value that is less than or equal
- GREATER: the closest value that is greater than or equal

@@ json-formatter
## Before you format JSON
### When it helps
- You want to make hard-to-read one-line JSON easy to read
- You want to check whether the JSON is written correctly
- You want to remove extra spaces to make it shorter
### Common causes of errors
- Keys and strings must both be in double quotes (")
- Comments and a trailing comma cannot be used in JSON
- Missing commas or quotes
### Tips
You can choose indentation of two spaces, four spaces or a tab. If there is a mistake, the approximate line is shown.

@@ line-break-remover
## Before you clean up line breaks
### When it helps
- You want to remove mid-sentence line breaks in text copied from a PDF
- You want to tidy unnecessary line breaks in an email or note
- You want to join the text before translating or searching
### Choosing how to clean
- Remove all line breaks: makes one long text
- Keep paragraphs (blank lines): keeps paragraphs and removes only line breaks inside a paragraph
### Good to know
Text copied from a PDF often breaks in the middle of a line, and cleaning it up makes it easier to read. Removing line breaks may change the character count. The text you enter is never sent outside your device.

@@ line-sort-dedupe
## Before you remove duplicate lines or sort
### When it helps
- You want to remove duplicates from a list of names or email addresses
- You want to sort a list in alphabetical or Japanese syllabary order
- You want to remove blank lines and tidy a list
### Sort types
You can sort alphabetically (and in Japanese syllabary order), by shortest first and more. The alphabetical option sorts Japanese by reading.
### Good to know
- Paste one item per line
- Duplicates are judged by whether the lines are exactly the same. If needed, turn on the case-insensitive setting
- The text you enter is never saved or sent

@@ markdown-table-to-excel
## Before you paste a Markdown table into Excel
### When it helps
- You want to edit a Markdown table in Excel
- You want to move a table from a README into a spreadsheet
### How it works
The separator row of the Markdown table (---) is removed automatically. The result is tab-separated, so it splits into cells when pasted.
### Things to know
- A | inside a cell is treated as text if it is written as \|
- Rows with fewer columns are padded with empty cells

@@ markdown-to-html
## Before you convert Markdown to HTML
### When it helps
- You want to turn text written in Markdown into HTML
- You want to paste HTML into a blog or email draft
- You want to check the result in a preview
### Supported syntax
- "#" for headings, "-" and "1." for lists
- "**" for bold, ">" for quotes and "```" for code
### Things to know
- HTML tags you write in the text are not run. They are shown as text
- Tables and nested lists are not supported

@@ merge-pdf
## Before you merge PDFs
### When it helps
- You are asked to submit an application and its attachments as a single PDF
- You want to send documents made separately as one file
- You want to combine scanned PDFs into one in order
### Check before you start
- Merge order: you can reorder with the up and down arrows
- Password-protected PDFs cannot be merged. Remove the password first
- Bookmarks (table of contents) and links in the original PDFs may not be kept
### After merging
If the merged file is large, shrink it with <a href="/compress-pdf.html">Compress a PDF</a>. To add page numbers, use <a href="/pdf-page-numbers.html">Add page numbers to a PDF</a>.
### Why you can use it with confidence
Your PDFs are never sent outside your device. You can merge documents without handing their contents to a server.

@@ namecard-maker
## Before you make business cards or name tags
### Sizes
- Business card: 91 x 55 mm
- Larger name tag: 100 x 70 mm
### Ways to make them
- Same card repeated: lays out your own business cards together on A4
- From a list: enter one person per line to make a name tag for each person
### Things to know
- Enter only your own information. Do not make cards that pass you off as someone else or another organization
- If you scale when printing, the card size will be off. Print at A4 and actual size
- Include an address or phone number only when needed

@@ ocr-text
## Before you read text with OCR
### When it helps
- You want to copy and use the text from a scanned document
- You want to turn text in a photo into plain text
- You want to turn paper material into searchable text data
### Tips for good results
- The larger and brighter the text in the image, the better it is read
- Take the photo from directly above, with no tilt or shadows
- Choose the language (Japanese or English) to match the image
### Things to know
- Results can contain mistakes. Always review important documents
- It does not make a searchable PDF. It is for copying the text or saving it as text
- The first time you use it, the recognition data (about 2 MB for Japanese) is loaded

@@ office-image-extract
## Before you extract images from Office files
### When it helps
- You want only the photos and logos inside a document
- You want to reuse images from Word or slides at original quality
- You want to check which images a file contains
### How it works
Images inside the file are extracted at their original quality. Opening the ZIP shows the images one by one.
### What cannot be extracted
- Shapes and charts are not stored as images, so they cannot be extracted
- Frames and cropping applied to an image are not reflected in the original image
- The old .doc, .xls and .ppt formats cannot be opened

@@ office-metadata-remove
## Before you remove author information
### When it helps
- You want to remove names and so on before giving a file to someone outside
- You want to check that your company or personal name is not left in the file
- You want to clean a Word, Excel or PowerPoint file before sending it
### What can and cannot be removed
- Can be removed: author, last modified by, company name and similar details. Word comments can also be removed if you tick the option
- Cannot be removed: names written in the body, tables or images. Tracked changes and hidden text are also not removed by this tool
### How to check
Your original file is not changed, and a new file is saved with _clean at the end of its name. To check that names are gone, select the saved file in this tool again.

@@ password-generator
## Before you generate a password
### When it helps
- When you sign up for a new service
- When you want to replace a current password with a stronger one
- When you need a long password for something like Wi-Fi
### Guide to a strong password
- Longer is stronger. You can choose from 4 to 64 characters
- Mix uppercase, lowercase, digits and symbols
- You can also exclude confusing characters (0 and O, 1 and l and so on)
### When using it
- The generated password is not saved. Keep a note in a password manager or similar
- Do not reuse the same password across several services
- It uses the browser's secure random number generator. Nothing is sent outside your device

@@ pdf-blank-remove
## Before you remove blank pages
### When it helps
- You want to remove blank backs mixed in by double-sided scanning
- You want to remove blank pages all at once
- You want to cut the page count to reduce file size
### How blank pages are found
- It measures how much text or drawing is on a page and treats pages with almost nothing as blank
- You can choose the threshold: loose, normal or strict
- If a blank page is not selected, there may be smudges or shadows. Choose "loose" or tap the page to select it by hand
### Things to know
Pages with only faint text may be treated as blank. Always check the thumbnails. The change cannot be undone after saving, so keep your original PDF.

@@ pdf-booklet
## Before you make a booklet
### When it helps
- You want a booklet you only need to print and fold
- You want a portable booklet from a document
- You want to make an event programme or notice into a booklet
### Printing steps
- Print the saved PDF double-sided (flip on short edge)
- In the printer settings, choose "double-sided" and "flip on short edge"
- Fold the printed sheets in half
### Good to know
- Four pages fit on the front and back of one sheet
- If the page count is not a multiple of 4, blank pages are added at the end
- A right-bound book is also possible. With many pages, the stacked folded sheets make it thick

@@ pdf-bookmarks
## Before you add bookmarks (a table of contents)
### When it helps
- You want to add jump links from a table of contents to a long PDF
- You want to see what bookmarks a PDF has now as a list
- You want to save the bookmarks as text
### How to add them
Choose "Add", then enter one line per bookmark as "page number title". With bookmarks, a PDF viewer lets you jump from the headings. You can also add them to a PDF that has none.
### Things to know
- Nested (hierarchical) bookmarks are display only. When you add bookmarks they are one level
- Adding bookmarks replaces the existing ones
- Password-protected PDFs are not supported
