CSV কেন বিকৃত দেখায় এবং কীভাবে ঠিক করবেন

মূল বিষয়

  • প্রিভিউ দেখে নিন
  • UTF-8 বা Shift_JIS-এ রূপান্তর করুন

You opened a CSV in Excel and Japanese was garbled. This is common, and the cause is mostly a difference in character encoding. Use Convert Text Encoding (Fix Garbled Text) to find out how to fix it.

কারণ

  • The CSV is saved as UTF-8 but Excel opens it assuming Shift_JIS
  • Conversely, it is saved as Shift_JIS but opened as UTF-8

CSVs output from web services and programs are often UTF-8 and can garble when opened in Japanese Excel.

Steps to fix

  1. Choose the garbled CSV with "Choose a text file".
  2. Look at "Content read (beginning)". If garbled, change "Current encoding".
  3. Once readable, choose "UTF-8 (with BOM, for Excel)" under "Convert to".
  4. Press "Convert and save" and open the saved file in Excel.
The "Current encoding" at which the text reads correctly is the file's true encoding.

Hints from the garbling

  • Characters like "縺ゅ縺": UTF-8 being read as Shift_JIS
  • Characters like "繧ゅ": the same
  • "????" or "□": the characters may already be lost

If it isn't fixed

  • Try "Current encoding" options in turn
  • Check the original file wasn't already damaged by other software
  • Respecify the encoding at the original source

যেসবের জন্য ভালো

  • Data downloaded from web systems is garbled
  • CSVs from overseas systems are garbled
  • Making old files readable

উদাহরণ

An online shop's order-data CSV was garbled in Excel. In this tool, I set "Current encoding" to UTF-8 to check the content, converted for Excel and saved; it was fixed.

Common stumbling blocks

  • Still garbled after converting: the "Current encoding" choice is wrong.
  • "????" mixed in: the original data has already been lost.

Frequently asked questions

Will re-opening and saving in Excel fix it?

Saving while garbled makes it impossible to restore. Use this tool first.

সারসংক্ষেপ

CSV garbling is fixed by matching the encoding. For Excel, UTF-8 with BOM.

“টেক্সট এনকোডিং রূপান্তর (বিকৃত অক্ষর ঠিক করুন)” ব্যবহার করুন (বিনামূল্যে)

এর সঙ্গে ভালো মানায় এমন টুল

  • CSV ও JSON রূপান্তর: CSV ও JSON-এর মধ্যে মুহূর্তে রূপান্তর করুন।
  • CSV থেকে এক্সেল (.xlsx) রূপান্তর: CSV-কে এক্সেল (.xlsx) ফাইলে রূপান্তর করুন।
  • টেক্সটের লাইন ব্রেক সরান ও গুছিয়ে নিন: PDF ও অন্যান্য জায়গা থেকে কপি করা টেক্সটের লাইন ব্রেক গুছিয়ে নিন।

এই টুলের আরও গাইড

  • টেক্সট ফাইলের এনকোডিং কীভাবে বদলাবেন (বিনামূল্যে, ফোনে চলে)
  • Excel-এ UTF-8 CSV খোলা (BOM-সহ UTF-8-এ রূপান্তর)

  • লাইন-এন্ডিং (CRLF ও LF) কীভাবে মেলাবেন
  • এনকোডিং অটো-ডিটেক্ট কীভাবে কাজ করে এবং ব্যর্থ হলে কী করবেন
