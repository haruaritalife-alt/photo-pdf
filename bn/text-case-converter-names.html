When writing code in a different programming language, has the variable naming style ever tripped you up? With Text Case Converter (camelCase, snake_case) you can quickly rewrite a name into another style.

ধাপ

  1. Enter the name to fix in the "English text to convert" field.
  2. Press the button for the form you want (camelCase, PascalCase, snake_case, kebab-case).
  3. Check the "Result" and copy with "Copy result".
If a name is joined into one, put half-width spaces between words before converting for stability.

Forms side by side

The same name by form:

  • camelCase: userProfileImage
  • PascalCase: UserProfileImage
  • snake_case: user_profile_image
  • kebab-case: user-profile-image

Common styles by language

  • Variables and functions: camelCase (JavaScript, Java, etc.), snake_case (Python, etc.)
  • Classes and types: PascalCase
  • Constants: upper case with underscores (this tool's "UPPER" plus manual adjustment)
  • CSS class names: kebab-case

Rules vary by language and team, so follow the project's conventions.

Steps (fixing several names at once)

Entering multiple lines in "English text to convert" may convert them in bulk. Check the result before using.

যেসবের জন্য ভালো

  • Turning database column names into program variable names
  • Porting code from another language
  • Aligning the naming format of API fields
  • Matching CSS class names with HTML

উদাহরণ

An API returned the field "user_name", but the front end wanted camelCase. Entering "user name" and pressing camelCase gave "userName".

Common stumbling blocks

  • Abbreviations: handling of URL, ID and the like follows project rules.
  • Digits: check separators around digits in the result.
  • Japanese: not converted.

Frequently asked questions

Can conversion mistakes be prevented?

After converting, check by eye that the name is as intended. Combining your editor's features gives extra assurance when pasting into code.
